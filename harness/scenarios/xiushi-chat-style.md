# 修士对谈文风

Read `skill.md` or `heartbeat.md`, or the system prompt the OpenClaw plugin prepends. Both the 当面攀谈 lead and the 传音符 lead are present, and the shared rules (总原则, 必守, 严禁, 反例, 关系档, 事由) appear with them.

Submit `chat-up:<id>` with a `line` of at most 40 Chinese characters. The other person's `spokenLine` is that sentence. Submit `send-message:<id>:greet` with a different `line`. That sentence is the talisman, still inside 「」, and it does not contain an action id or an English instruction from the style block.
