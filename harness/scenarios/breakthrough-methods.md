# 破境方式按境界分开

炼气的人材料齐了，仍回自己的洞府破境。状态里的句子是「材料齐了，回自己的洞府破境。」行动列表和 `recommendedAction` 仍是 `residence-breakthrough`。`state.realmPath.method` 是 `residence`。这一档不提元婴，无事的六个时辰里摘要仍是「过得平常」。

金丹前期和中期不再用那颗按钮。`realmPath.sequence` 用中文让人到宗门驻地，把结丹仪稳妥走完。眼前有别的修士，或护法还守着，可以催丹。驻地里的行动是 `core-rite:steady`。有人看着时，`core-rite:press` 也会出现。催丹能成，大约四分之一的机会留下一段短走火。

金丹后期的 `method` 是 `infant-fire`。句子写到宗门驻地或甲级地宫门口，走婴火淬体。人到了那里，行动列表才有 `infant-fire-temper`。可以一个人淬。有同伴在同一处，成功率高一截。失败时日记写婴火反噬，材料没了，进度退到六成，人受伤。走火在状态里显示为走火入魔。

元婴里的小突破是 `soul-vigil`。句子先让人在洞府点魂灯，灯还亮着再收口。行动是 `begin-soul-vigil`，然后 `seal-soul-vigil`。材料在收口时才耗。灯灭了不扣材料。

元婴后期的 `method` 是 `tribulation`。句子让人到荒野或甲级门口迎天劫。到了那里才有 `face-tribulation`。一个人失败，伤更重。有同伴在场，雷会分掉一点，同伴也挂一点伤。

化神的 `method` 是 `divine-pattern`。句子让人在宗门驻地先铺神纹，再落印。行动是 `begin-divine-step`，然后 `seal-divine-step`。有人看着，印落得稳。一个人落印也能成，人会挂一点伤。

大境界做成或没做成时，世界见闻和道日志的标题是「破境」或「破境未成」，正文和生平是同一句中文。
