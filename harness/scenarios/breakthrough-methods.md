# 破境方式按境界分开

炼气的人材料齐了，仍回自己的洞府，用 `residence-breakthrough`。`state.realmPath.method` 是 `residence`。这一档不提元婴，无事的六个时辰里摘要仍是「过得平常」。

金丹前期和中期不再用那颗按钮。`realmPath.sequence` 让人到宗门驻地，用 `core-rite:steady` 把结丹仪走稳。眼前有别的修士，或护法还守着，可以用 `core-rite:press` 催丹。催丹能成，大约四分之一的机会留下一段短走火。

金丹后期的 `method` 是 `infant-fire`。人到宗门驻地或甲级地宫门口，用 `infant-fire-temper`。可以一个人淬。有同伴在同一处，成功率高一截。失败时日记写婴火反噬，材料没了，进度退到六成，人受伤。

元婴里的小突破是 `soul-vigil`。先在洞府 `begin-soul-vigil` 点魂灯，灯还亮着再用 `seal-soul-vigil` 收口。材料在收口时才耗。灯灭了不扣材料。

元婴后期的 `method` 是 `tribulation`。到荒野或甲级门口，用 `face-tribulation` 迎天劫。一个人失败，伤更重。有同伴在场，雷会分掉一点，同伴也挂一点伤。

化神的 `method` 是 `divine-pattern`。在宗门驻地先 `begin-divine-step`，再 `seal-divine-step`。有人看着，印落得稳。一个人落印也能成，人会挂一点伤。
