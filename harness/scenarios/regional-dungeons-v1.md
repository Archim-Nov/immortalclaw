# 九州各有一处秘境

筑基站在青州主城，读 `state.regionalDungeons`。青岚药窟开着，`enter-regional:qinglan-herb-cave` 在行动里。散修旧洞也在。游商暗仓还关着，原因写着得到金丹。换到扬州，青岚药窟不在列表里，听潮钟窟在。潮开的前八刻进得去，第八刻以后 `lockReason` 写潮退了。

进青岚药窟以后，行动里只有探路这一步，加上退出。等露、割藤、拔根、旁边的石窝和更里面都不列出。直接去收会被拒绝，露芯不进袋子，人还停在探路。走完探路才看见露虫。走完露虫以后，岔路才是等露、割藤、拔根。一个人选等露，袋子里多一枚青岚露芯，游记和 digest 里有一句见闻。再进会被冷却挡住。两人同队时，探路、露虫和等露都要超过一半才锁。一边不够数不会提前结束。两人都选等露才锁，露芯只在队长袋子里，同伴的 `lastReport` 引用同一句。

进门以后空等过了期限，人仍停在探路，露芯不进袋子。走完探路和露虫以后再空等两刻，才自动等露。探到一半用 `leave-regional` 退出，句子是瓶子是空的，和走完那句不一样。茶桥旧席的第二步是半盏冷茶。同队两人都把茶让出去，会记下「把席上的茶让给我」，旧茶纹仍要等入席。期限到了也不跳过这半盏茶。散修旧洞、游商暗仓、古修闭关室没有这两步，进门就能选收束。

沧州元婴后期进盐风沉舶，先看盐壳、绕开盐蟹，再选暗舱。灵石少，人挂伤，没有盐纹晶，结果是失败。宗门驻地的古修闭关室只容一个人。坐下当时没有灰，时辰坐满才有闭关灰。中途 `leave-regional` 起来，灰不留，气血少一截。

丙级门口的 `rankYieldHints` 仍是原来的层。advice 末尾多一句，说这一州的秘境不在这几层里。闭关先用丹霞露、养魂砂、神纹尘。没有的时候，才用袋子里对得上境界的那一份。云栈纤维用在洞府炼制上，这一炉少两成灵石。
