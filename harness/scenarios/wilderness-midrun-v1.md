# 荒野层里的两步

人走到青岚坡，走进那一层。行动里先是三个中文做法，加上撤出。再探先不出现。选了割药藤，袋子里多一份矿，游记和 digest 都有一句青岚坡的见闻。摘要从你选了起头。

这一步还开着的时候，把时辰往前推过这一层能撑的刻数。人仍停在露蛛这一步，矿和灵石都没有因为这一步变多。再探交上去会被拒绝。自己撤出来，句子仍是从青岚坡退出来，不另扣灵石。

第一步走完，再过两刻，才是洒了的露。旁边有人并把露拢回去，会记下把洒了的露拢给我。这一步开着时再往前推，灵石也不会自己进来。

焦林野的第一步写雷雀、焦木和焚灼，并写明不是雷泽残阵。做法和青岚坡不同。

旁边的人各自有自己的进度。一个人选了，另一个人的岔路还在。八荒仍是荒尘驿、断碑原、无灯壑，不走这套岔路。
