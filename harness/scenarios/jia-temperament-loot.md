# 甲级带出按气质分池

金丹站在 `qingzhou:dungeon-a`，甲级已经开过。

1. 一层撤出，袋子和 `lastReport.secondaryDropCards` 都是一份丹霞余砂。摘要写着中途撤出。丹霞露仍在，份数和袋子一致。金灵花为 0 时摘要不写带回金灵花。
2. 二层撤出是火毒凝滴，三层撤出是阵纹残片。中途的闲事只从这一层那一池里抽。
3. 一层走完是两份丹霞余砂，摘要写着走完、旁支更满。四层走完是三份，句子里是婴火莲池。七层走完是四份，句子里是神纹天隙。
4. 一层中途选险，撤出时是两份丹霞余砂。选帮，换成一份火毒凝滴。选走，丹霞余砂不加，身上有伤就按下去两刻。
5. 乙级撤出不带这三件。

领域回归在 `packages/domain/src/jia-temperament.test.ts`。
