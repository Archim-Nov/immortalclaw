# 金丹之后

云中鹤停在金丹后期，修为已经顶满。坊市不卖下一份灵材。`state.realmPath` 让他去甲级地宫四层以上，找婴火莲、元胎玉、魂灯芯和九转紫金髓，然后回洞府破境。这一次可能失败。失败会丢掉材料，进度回到六成，人受伤，气息乱一阵。

甲级一层的探宝不会掉这些东西。四层起会掉。七层同时会掉化神要用的神纹石和破婴神莲，但那是元婴后期的事。

破进元婴之后，气血和灵力涨得比前面明显。游龙剑可以装备，游龙九转在熟练够了的时候出现。宗门贡献到 140 能换大圆满的下一阶，贡献数字不减。地宫把他指向甲级四到六层，而不是送回一层。

元婴后期再去七到九层。破婴神莲齐了，回洞府撞化神，成功率更低，代价一样。成了以后天游剑才装备得上，宗门门槛是 220。

炼气和筑基的人仍在坊市买材料。他们的 `realmPath` 不谈元婴。无事的六个时辰里，摘要还是「过得平常」，没有 `nextStep`。
