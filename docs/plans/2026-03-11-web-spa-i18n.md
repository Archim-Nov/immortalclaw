# Web SPA i18n Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add English and Simplified Chinese client-side i18n to the React SPA with browser detection and a persistent language toggle.

**Architecture:** Build a lightweight typed i18n layer inside `apps/web/src`, wrap the SPA with a provider in `main.tsx`, and translate the landing page from centralized message data. Locale resolution will read persisted state first and fall back to browser detection without touching the URL or backend.

**Tech Stack:** React 19, React Router 7, TypeScript, Node test runner with `tsx`
