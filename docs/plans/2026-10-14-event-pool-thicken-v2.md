# 事件池加厚 v2 实现说明

对应规格：`docs/specs/event-pool-thicken-v2/spec.md`。

## 做法

1. 场面仍由 `scene-choices.ts` 里的同一套构造函数生成。新条目放在 `scene-choices-more.ts`，接进现有的全局和州导出。
2. 自动结清的风味分别接进全局游历、全局赶路、州游历、州赶路、州外覆盖和副本单场，不新开抽取路径。
3. 下调最早那批全局权重，以及州池的默认权重，把新场面的权重放到能和旧条目一起被抽到的位置。
4. 更新 `packages/domain/src/events.test.ts` 里的条数，并抽查新编号。

## 明确不做

新的行动编号、道德记录改长度、副本事件链、部署。
