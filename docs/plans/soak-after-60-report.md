# 试玩 #60 之后的结算和表面

对应 `docs/specs/soak-after-60-report/spec.md`。

主材料只计真正入包的那一种。同一档破境池里的其他灵材留在旁支，用自己的名字和份数。撤出或走完时补发的丹霞露和来源物，先加进进度再写 `lastReport`。

甲级中途的 choose-event 从 `jia-scene-choices.ts` 里抽，骨架仍是走、帮、取、险。街巷池里的「你好叶子」改成「药叶子」。

同一人有多张未读字条时，标签加上六字以内的节选；节选相同时再加序号。己方占着边寨、寨名又以仇家宗名开头时，边衅改说「这座边寨」。

`actionFailureBody` 把失败原因同时放进 `error` 和 `summary`。世界服务的错误响应走这个结果。
