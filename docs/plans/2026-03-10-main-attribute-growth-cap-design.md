# Main-Attribute Growth Cap Design

**Date:** 2026-03-10

**Decision:** Remove the hard growth cap from main attributes.

**Why:** Main attributes, like five-element attributes, are intended to be permanent long-term growth values that quantify player power. A fixed `1-100` cap would make the core attribute panel feel like an early-stage onboarding panel instead of a late-game-compatible progression system.

**Scope:**
- Keep the new-character total of `400` unchanged.
- Keep the initial single-attribute recommendation of `30-70` unchanged.
- Keep `50` as the new-character initial average-line reference.
- Update wording so the existing ranges are treated as initial references, not permanent caps.
- Replace stale references to attribute caps with growth-oriented wording.

**Out of Scope:**
- Rebalancing attribute formulas
- Changing detailed attributes
- Changing five-element formulas
- Defining post-100 growth brackets
- Implementing code changes

**Approved Approach:** Consistency update. Remove hard-cap wording and update adjacent language that would otherwise still imply capped main-attribute growth.
