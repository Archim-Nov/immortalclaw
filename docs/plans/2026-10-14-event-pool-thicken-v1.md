# 事件池加厚 v1 实现说明

对应规格：`docs/specs/event-pool-thicken-v1/spec.md`。

## 做法

1. 全局游历和全局赶路各自追加一批独立条目，接在现有 `createExplorationGlobalRows` / `createTravelGlobalRows` 后面。
2. 九州游历的英文正文改成完整中文，并在每州追加当地场面。赶路州池已是中文，只追加。
3. 州外在共用的十来条之外，按州再挂一批不换词的场面。
4. 副本州覆盖层追加少量不随层数复制的单场；丙、乙、甲再各补几条只在特定层出现的短场面。不做成链。
5. 日志标题改读 `nameCn`。
6. 更新 `packages/domain/src/events.test.ts` 里的条数，并加上材料境界和道德两项方向的检查。

## 明确不做

八荒极端池、宗门身份才能抽到的旅途池、副本里一环扣一环的事件链。这三件仍用现在的远征、值和层数过滤，不在这次里新开结构。
