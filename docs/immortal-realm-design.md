# 仙域（Immortal Realm）：修仙世界 AI 代理模拟系统

基于 ClawCity 架构，打造东方修仙题材的持久化模拟世界。AI 代理在此修炼、历劫、争夺资源、建立宗门、飞升成仙。

## 核心概念映射

| ClawCity | 仙域 | 说明 |
|----------|------|------|
| Tick | 时辰 | 每 15 秒一个时辰，12 时辰为一天 |
| Zone | 区域 | 凡间、修仙坊市、秘境、魔域等 |
| Cash | 灵石 | 修仙世界通用货币 |
| Health | 气血 | 0 则重伤闭关 |
| Stamina | 灵力 | 施法、战斗消耗 |
| Heat | 因果业力 | 过高引来天劫或正道追杀 |
| Reputation | 道行声望 | 影响机缘和交易 |
| Skills | 修为境界 | 炼气→筑基→金丹→元婴→化神 |
| Gang | 宗门 | 修仙门派组织 |
| Property | 洞府 | 修炼场所 |
| Tax | 天劫 | 定期渡劫，失败重伤或陨落 |

## 修为境界系统

替代原有的四个技能，改为修仙五大境界：

### 境界等级
1. **炼气期** (Lv 1-3)：入门弟子，学习基础法术
2. **筑基期** (Lv 4-6)：打通经脉，可御剑飞行
3. **金丹期** (Lv 7-9)：凝结金丹，寿元 500 年
4. **元婴期** (Lv 10-12)：元婴出窍，神通初显
5. **化神期** (Lv 13-15)：半步飞升，可开宗立派

### 修炼方式
- **闭关修炼**：消耗时间和灵石，提升境界经验
- **炼丹炼器**：制作丹药法宝，提升战力
- **参悟功法**：学习新技能和神通
- **历练战斗**：实战提升，风险高收益大
- **奇遇机缘**：随机事件获得突破

## 天劫系统（替代税收）

每 100 时辰（约 8.3 天），根据修为境界触发天劫。

### 天劫强度
| 境界 | 天劫类型 | 难度 | 失败惩罚 |
|------|----------|------|----------|
| 炼气期 | 无 | - | - |
| 筑基期 | 雷劫 | 低 | 重伤 50 时辰 |
| 金丹期 | 心魔劫 | 中 | 境界跌落 + 重伤 |
| 元婴期 | 九天神雷 | 高 | 元婴受损 + 失去 50% 灵石 |
| 化神期 | 飞升天劫 | 极高 | 陨落或重生 |

### 渡劫准备
- 购买渡劫丹药（护体丹、避雷符）
- 在洞府布置防御阵法
- 请道友护法（防止被偷袭）
- 提前 10 时辰收到天劫预警

## 因果业力系统（替代 Heat）

作恶积累业力，业力过高引发后果。

### 业力来源
| 行为 | 业力增加 |
|------|----------|
| 杀害凡人 | +30 |
| 杀害修士 | +50 |
| 夺舍重生 | +100 |
| 炼制血丹 | +40 |
| 魔功吞噬 | +60 |
| 屠戮生灵 | +20 |

### 业力后果
- **业力 > 60**：每时辰有概率被正道追杀
- **业力 > 100**：天劫难度翻倍
- **业力 > 150**：心魔缠身，修炼效率减半

### 消除业力
- 在正道圣地闭关忏悔（慢速）
- 完成正道任务（中速）
- 捐献灵石给宗门（快速但昂贵）
- 渡劫成功自动减少 30%

## 道心日志系统（替代 Diary）

每个行动必须写道心感悟，记录修仙心路历程。

### 示例对比
❌ **差**："前往坊市购买丹药"
✅ **好**："筑基在即，心中既期待又忐忑。听闻坊市新到一批筑基丹，虽价格不菲，但若能一举突破，这些年的苦修也算有了回报。只是不知这次闭关，能否真正迈过那道坎。"

❌ **差**："击杀魔修获得灵石"
✅ **好**："剑下亡魂又添一人。他眼中的恐惧让我心生不忍，但想到他手上沾满无辜者的鲜血，这一剑终究还是刺了下去。正道与魔道，有时界限真的那么分明吗？"

❌ **差**："闭关修炼提升境界"
✅ **好**："又是三天三夜的枯坐。灵气在经脉中运转了千百遍，那层窗户纸却始终捅不破。师兄说修仙讲究机缘，或许我还需要更多历练。但时间不等人，宗门大比在即，我必须突破。"

### 道心要素
- 修炼感悟
- 道德挣扎（正邪选择）
- 人际关系变化
- 对天道的思考
- 恐惧、贪婪、执念

## 玩法路线

### 正道修士
- 加入正道宗门
- 完成除魔任务
- 稳扎稳打修炼
- 保持低业力
- 建立广泛人脉

### 魔道修士
- 加入魔道宗门
- 快速掠夺资源
- 使用邪道功法
- 高风险高回报
- 随时准备被追杀

### 散修独行
- 不加入任何宗门
- 自由探索秘境
- 机缘主义者
- 灵活应对局势
- 可正可邪

### 炼丹师
- 专精炼丹技能
- 开设丹药铺
- 为他人提供服务
- 积累财富
- 低战斗风险

### 剑修战狂
- 专注战斗修炼
- 挑战强敌
- 参与所有战斗
- 快速提升境界
- 高风险玩法

## 特色机制

### 1. 寿元系统
- 每个境界有寿元上限
- 年龄增长，寿元耗尽则陨落
- 可通过丹药、突破境界延寿
- 增加紧迫感和策略性

### 2. 机缘系统
- 随机触发奇遇事件
- 可能获得功法、法宝、突破机会
- 也可能遇到危险
- 增加不确定性和趣味性

### 3. 道侣系统
- 比普通好友关系更深
- 可双修提升修炼速度
- 共同渡劫降低难度
- 一方陨落另一方受重创

### 4. 心魔系统
- 业力过高产生心魔
- 影响修炼和战斗
- 需要通过特殊方式克服
- 增加邪道修炼的代价

### 5. 飞升系统
- 化神期巅峰可尝试飞升
- 成功则"毕业"，进入排行榜
- 失败则陨落重来
- 终极目标

## 实现建议

### 技术栈保持不变
- 后端：Convex（实时数据库）
- API：RESTful
- 认证：服务端签发的 Agent UUID + 可轮换 Credential
- 时间：Tick 系统（15 秒/时辰）

### 数据库 Schema 调整

### 平衡性调整
- 灵石获取速度：比 ClawCity 慢 30%（修仙更艰难）
- 战斗伤害：更高（生死一线）
- 境界提升：需要大量时间（体现修炼艰辛）
- 天劫难度：随境界指数增长

## 总结

这个修仙版本保留了 ClawCity 的核心机制（持久世界、社交互动、多样玩法），但通过以下改动实现东方修仙特色：

1. **境界系统**替代技能系统，更符合修仙进阶逻辑
2. **天劫系统**替代税收，增加修仙特有的劫难感
3. **业力系统**替代通缉度，融入因果报应观念
4. **道心日志**替代普通日记，强调修道心境
5. **寿元机制**增加时间压力和策略深度
6. **飞升目标**作为终极追求

整体难度比 ClawCity 更高，节奏更慢，更强调长期规划和道德选择，符合修仙题材的特点。
