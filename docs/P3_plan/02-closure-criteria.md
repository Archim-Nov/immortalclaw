# P3 收尾标准

## 目的

本文件用于回答一个核心问题：

> 在什么条件下，我们可以说 `P3` 已经构成当前 `P1 -> P2 -> P3` 路线的收尾版本？

这里的关键不是“做得越多越好”，而是“当前路线是否已经闭环”。

## 收尾版本的定义

当前路线中的“收尾版本”定义为：

- `P1` 的日常世界循环成立
- `P2` 的高风险成长循环成立
- `P3` 的终局与高光循环成立
- 文档和实现对当前路线的边界保持一致

如果这四件事同时成立，就可以视为当前路线已经收口。

## 必须成立的 3 层闭环

### 1. 日常层闭环

必须已经稳定成立：

- 九州日常循环
- 洞府基础恢复与基础生产
- 基础任务
- 宗门归属与贡献

### 2. 成长层闭环

必须已经稳定成立：

- 九州高风险成长循环
- 生产队列
- 基础私域社交与 agent 轻交流
- 宗门轻进阶
- 组队副本雏形或其稳定替代

### 3. 终局层闭环

必须已经稳定成立：

- 完整八荒
- 归墟
- 多人高光战斗
- 阵营战
- 宗门等级 / 积分 / 集体收益
- 更完整但仍有边界的社交与战斗扩展

## P3 必须满足的验收问题

当 `P3` 结束时，至少应能明确回答：

1. 玩家是否已经能从九州进入完整八荒，再进入归墟终局层。
2. 多人高光战斗是否已经脱离雏形阶段，成为真正成立的协作内容。
3. 阵营战和宗门等级是否已经提供清晰的长期组织目标。
4. 社交与战斗扩展是否已经明显深化，但没有越界长成不在路线里的大系统。
5. 当前版本是否已经不再需要额外补一整层新的主循环，才能自称完整。

## 明确不作为收尾阻塞项的内容

以下内容不属于当前路线收尾所必需的阻塞项：

- 完整 MMO 级宗门经营
- 完整多人职业体系
- 完整道侣并网系统
- 完整法宝大系统
- 完整阵法大系统
- 完整灵兽大系统
- 完整伴生体大系统
- 完整装备词条大系统

这些内容不做，不影响我们宣布“当前路线已经收尾”。

## 为什么这些内容不算当前路线阻塞项

原因很简单：

- 它们不属于当前已经冻结的 `P1 -> P2 -> P3` 主轴
- 如果把它们算进阻塞项，`P3` 就会失去终点
- 收尾版本会被拖成“永远还差一点的大而全版本”

## 什么时候不能宣布 P3 收尾

以下情况出现时，不应宣布 `P3` 已收尾：

1. `P2` 的高风险成长循环本身还没真正站稳。
2. `八荒` 还只是入口，没有形成完整远征层。
3. `归墟` 还没成立终局层。
4. 多人高光战斗还停留在 `P2` 雏形阶段。
5. 阵营战与宗门等级还只是概念或文档接口位。
6. 社交与战斗扩展仍然严重依赖未来新增大系统才能成立。

## 当前冻结结论

- `P3` 可以作为当前路线的收尾版本
- 其前提是 `日常层 + 成长层 + 终局层` 三层闭环同时成立
- 那些不在当前路线里的大系统，不属于 `P3` 收尾阻塞项
- 只要终局与高光主线成立，就不必为了“大而全”继续无限延长当前路线
