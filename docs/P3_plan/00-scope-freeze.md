# P3 范围冻结

## 目标

`P3` 的任务不是继续横向扩张玩法，而是把当前路线中尚未完成的终局层与高光层收束成一个可作为“当前版本收尾”的第三阶段。

一句话定义：

> 在 `P2` 的高风险成长循环已经成立的前提下，补完整 `八荒 -> 归墟 -> 阵营战 / 宗门等级 -> 更完整的多人与社交高光` 这条终局链。

## P3 与前两阶段的关系

`P1` 冻结的是：

- 完整九州日常循环
- 洞府基础恢复与基础生产
- 基础任务
- 宗门归属与贡献

`P2` 冻结的是：

- 九州高风险成长循环
- 生产队列
- 基础私域社交与 agent 轻交流
- 宗门轻进阶
- 组队副本雏形
- 八荒最小扩展层

因此 `P3` 要做的不是重写这些内容，而是把它们继续拉向：

- 终局地图层
- 高光组织层
- 更完整的多人协作层
- 更完整但仍有边界的社交与战斗扩展

## P3 启动前提

`P3` 默认建立在以下前提上：

- `P1` 的日常主循环稳定可玩
- `P2` 的高风险成长循环已经成立
- `P2` 旧壳清理已经完成，不再需要绕着旧污染做设计
- `P2` 的社交、生产、事件和宗门轻进阶已经接上统一主循环

如果这些前提没成立，`P3` 很容易退化成“用终局内容掩盖中层没做完”。

## P3 的核心方向

### 1. 完成 `八荒`

`P2` 只允许把 `八荒` 当作扩展层或最小入口。

因此 `P3` 的第一主方向，是把 `八荒` 从“摸到边”升级为“完整成立的高风险远征层”。

这意味着：

- `八荒` 要有更完整的区域玩法
- 要有更完整的风险与撤离逻辑
- 要有专属极端事件池
- 要真正承担高价值远征内容的职责

### 2. 接入 `归墟`

`归墟` 在当前路线里属于明确的终局层。

因此 `P3` 的第二主方向，是让 `归墟` 作为终局节点开拓层正式成立。

它的职责不是复制 `九州` 或 `八荒`，而是：

- 提供更终局的节点目标
- 提供唯一性或共享性内容
- 承担真正的终局推进感

### 3. 完成更完整的多人高光战斗

`P2` 只验证组队副本雏形。

因此 `P3` 的第三主方向，是把多人协作战斗从“能跑”升级到“真正构成高光体验”。

这里的重点是：

- 更完整的组队副本
- 更复杂的 Boss 压力与协作机制
- 更清晰的队伍构筑价值
- 继续复用统一战斗底层

### 4. 让 `势` 进入高光组织层

`P2` 中的宗门还停留在轻进阶段。

因此 `P3` 的第四主方向，是让 `势` 正式接入：

- 阵营战
- 宗门积分
- 宗门等级
- 全员加成
- 更强组织目标

但这里仍然要守住边界：

- 做组织高光
- 不做 MMO 级宗门经营模拟

### 5. 完成更完整的社交与战斗扩展

当前 spec 对 `P3` 的描述里，明确保留了“更完整的社交与战斗扩展”。

因此 `P3` 的第五主方向，是把 `P2` 的轻量社交和战斗扩展继续拉深一层。

这里的正确理解是：

- 做更深一层的私域黏性
- 做更强一层的协作和高光战斗

而不是：

- 自动引入那些不在当前路线中的大系统

## P3 明确不纳入当前路线的内容

以下内容不应因为曾在旧讨论或宽泛 non-goal 里出现，就被自动写入当前 `P3` 路线：

- 完整 MMO 级宗门经营
- 完整多人职业体系
- 完整道侣并网系统
- 完整法宝大系统
- 完整阵法大系统
- 完整灵兽大系统
- 完整伴生体大系统
- 完整装备词条大系统

这些内容在当前口径里，最多只能视为更远期的可选想象，不属于现在的 `P1-P3` 执行路线。

## P3 必做与不做

### P3 必做方向

- 完整 `八荒`
- 正式接入 `归墟`
- 更完整的组队副本和多人高光战斗
- 阵营战与宗门等级 / 宗门积分 / 集体收益
- 更完整但仍然有边界的社交与战斗扩展

### P3 暂不做

- 完整 MMO 级宗门经营
- 完整多人职业体系
- 完整道侣并网系统
- 完整法宝 / 阵法 / 灵兽 / 伴生体 / 装备词条大系统
- 任何脱离当前 `P1-P3` 主路线的新大类玩法

## P3 的结构理解

从执行角度，当前最适合把 `P3` 理解成下面这条线：

`完成八荒 -> 接入归墟 -> 完成多人高光战斗 -> 打开阵营战与宗门等级 -> 补完整社交与战斗延展 -> 形成当前路线收尾`

## P3 验收方向

当 `P3` 进入验收时，至少应能回答：

1. `八荒` 是否已从扩展层变成完整成立的高风险远征层。
2. `归墟` 是否已作为终局节点层成立。
3. 组队副本和多人高光战斗是否已经脱离“雏形”阶段。
4. 阵营战与宗门等级是否已经成为真实长期目标。
5. 更完整的社交与战斗扩展是否已经成立，但没有越界成长为不在路线里的大系统。
6. 当前版本是否已经能作为 `P1 -> P2 -> P3` 这条路线的收尾版本。

## 当前冻结结论

- `P3` 的本质是 `终局与组织高光循环收尾`
- `P3` 建立在 `P2` 已成立的前提上，不负责补救未完成的 `P2`
- `P3` 的主轴是 `八荒完成 + 归墟接入 + 阵营战 / 宗门等级 + 更完整多人与社交高光`
- 那些不在当前路线里的大系统，不自动进入 `P3`
