# 任务与宗门表

## 目的

本文件负责把 P1 的 `遇 + 势` 整理成真正可配置的任务模板和宗门规则。

## 任务板基础规则

### 1. 节点承载

- 州主城：`5 个` 基础任务位
- 州辅镇：`3 个` 基础任务位
- 山门 / 宗门据点：`2 个` 宗门任务位

### 2. 刷新规则

P1 统一按简单规则处理：

- 基础任务板每 `12 ticks` 刷新一次
- 宗门任务板每 `12 ticks` 刷新一次
- 高风险节点不依赖任务板刷新，作为固定入口存在

### 3. 持有上限

- 同时最多持有 `2 个` 基础任务
- 同时最多持有 `1 个` 宗门任务
- 高风险挑战按动作发起，不占任务栏

### 4. 放弃规则

- 放弃基础任务：`0` 奖励，无额外惩罚
- 放弃宗门任务：`0` 贡献，无额外扣分
- P1 不做复杂信誉惩罚，但会留下日志

## 5 类寻常任务模板

| 模板 | 来源节点 | 建议时长 | 推荐准备度 | 核心目标 | 建议奖励 | 失败成本 |

| 采集委托 | 主城 / 辅镇 | 3 ticks | stable | 去州外采集并回交 | 灵石 90-130 + 基础材料 | 时间浪费 |
| 跑腿递送 | 主城 / 辅镇 | 2 ticks | poor / stable | 在节点间递送物资或消息 | 灵石 80-120 + 轻声望 | 时间浪费 |
| 坊市打工 | 主城 | 2 ticks | poor | 稳定打工赚灵石 | 灵石 100-140 | 几乎无额外成本 |
| 除魔悬赏（低阶） | 主城 / 辅镇 | 3 ticks | stable / ready | 完成低压战斗或轻遭遇 | 灵石 120-180 + 少量材料 | 小幅伤势 / 低资源损耗 |
| 调查寻访 | 主城 / 辅镇 | 3 ticks | stable | 收集线索、识别异常 | 灵石 90-140 + 线索 / 关系结果 | 时间浪费 + 轻状态波动 |

| --- | --- | --- | --- | --- | --- |

## 任务奖励口径

### 1. 寻常任务

原则：

- 奖励稳定
- 可以养活低风险循环
- 不是唯一最佳收益路线

### 2. 高风险任务

原则：

- 奖励显著高于寻常任务
- 必须伴随真实失败成本
- 主要拉升上限，而不是垄断全部收益

## 宗门配置框架

当前阶段只冻结一件事：

- P1 必须有 `可加入宗门的配置框架`

当前阶段不冻结：

- 具体有几个可加入宗门
- 宗门最终名单
- 宗门是否采用固定“剑修 / 丹修 / 阵修”分类
- 宗门总部最终落在哪个州

也就是说：

- 我们当前在做的是 `宗门玩法框架`
- 不是 `宗门内容名录拍板`

### P1 宗门配置至少要能表达的字段

| 字段 | 用途 |
| --- | --- |
| `sectId` | 宗门稳定 ID |
| `displayName` | 前台显示名 |
| `headquartersNodeId` | 总部或主要据点 |
| `joinEntryNodeIds` | 允许加入的节点 |
| `taskBias` | 更容易发哪类宗门任务 |
| `publicIdentity` | 前台展示身份包装 |
| `notes` | 特殊规则或备注 |

说明：

- 当前代码原型里的单宗门 placeholder 只代表“宗门系统曾有原型”
- 不代表 P1 正式名单已经冻结

## 加入宗门规则

- 加入宗门是 `immediate` 动作
- 一次只能加入 `1 个` 宗门
- 加入后默认获得 `外门`
- 加入后开放宗门任务和贡献视图
- P1 不做复杂退宗 / 转宗

补充口径：

- P1 只要求“加入宗门”动作可配置
- 不要求现在就把所有宗门内容一次定死

## 4 类宗门任务模板

| 模板 | 建议时长 | 推荐准备度 | 说明 | 成功贡献 |
| --- | --- | --- | --- | --- |
| 资源上缴 | 1-2 ticks | poor / stable | 交付指定资源换取稳定贡献 | 10 |
| 宗门跑腿 / 联络 | 2 ticks | poor / stable | 在节点间传递消息与物资 | 15 |
| 宗门专属游历 | 3-4 ticks | stable / ready | 带宗门目标标签的州外探索 | 25 |

## 宗门任务奖励结构

每次宗门任务统一回写：

- `基础奖励`
- `宗门贡献`
- `组织日志`

P1 不做：

- 复杂评分
- 连胜奖励
- 按表现浮动贡献

## 宗门贡献规则

### 1. 记录方式

- 贡献是累计值
- 不因头衔更新清零
- 不因晋升消耗

### 2. 回写规则

- 成功：获得完整贡献值
- 失败：`0`
- 放弃：`0`

### 3. 前台用途

- 头衔成长反馈
- 更高层宗门任务推荐
- 轻门槛判断

## 宗门头衔规则

### 档位

- `宗主`
- `长老`
- `精英`
- `内门`
- `外门`

### 周期

- 统一按 `2880 ticks` 自动结算

### 阈值与名额

| 头衔 | 阈值 | 名额 |
| --- | --- | --- |
| 外门 | 加入即得 | 无上限 |
| 内门 | 200 | 32 |
| 精英 | 600 | 16 |
| 长老 | 1500 | 4 |
| 宗主 | 固定职位 | 1 |

### 排序规则

- 先看是否达到阈值
- 再按累计贡献从高到低占位
- 同贡献时按先达到阈值时间优先
- 再按 `characterId` 稳定打平

## P1 推荐接取门槛

### 寻常任务

- `poor` 也可接 `坊市打工 / 跑腿递送`
- `stable` 可接全部寻常任务

### 高风险任务

- `州内精英任务`：建议 `ready`
- `丙等副本`：最低 `stable`
- `乙等副本`：建议 `ready`
- `甲等副本`：建议 `advantaged`

### 宗门任务

- `资源上缴 / 跑腿联络`：`poor / stable`
- `宗门专属游历`：`stable / ready`
- `巡查 / 镇压`：`ready`

## P1 日志要求

### task-log

记录：

- 任务类型
- 来源节点
- 时长
- 成败
- 奖励与损耗

### encounter-log

记录：

- 高风险入口
- 是否进入战斗
- 关键结果

### sect-task-log

记录：

- 宗门任务模板
- 宗门名
- 基础奖励
- 贡献值

### sect-contribution-log

记录：

- 贡献来源
- 本次增加值
- 累计值变化

## P1 最小交付检查

- 主城和辅镇都有任务板。
- 5 类寻常任务都能被接取和结算。
- 至少 3 类高风险入口存在并能产生真实后果。
- 玩家能加入至少 1 个宗门。
- 4 类宗门任务都能结算贡献。
- 头衔能在周期结算时自动更新。
