# 经济护栏与派生视图

## 目的

本文件解决两个经常被遗漏的问题：

1. P1 的循环怎么避免数值塌掉。
2. 前台的建议信息怎么统一，不让每个模块各算各的。

## P1 经济护栏

### 1. 基础原则

- 低风险循环要能养活恢复和基础生产
- 高风险循环要明显更赚，但不能成为唯一收入来源
- 宗门贡献是组织进度，不是替代真实奖励的万能货币
- 洞府是转化地，不是资源原产地

### 2. 建议收益带

| 行为 | 建议收益带 | 说明 |
| --- | --- | --- |
| 坊市打工 | 灵石 100-140 | 最稳定兜底 |
| 跑腿递送 | 灵石 80-120 | 低风险，强化移动意义 |
| 采集委托 | 灵石 90-130 + 材料 | 推动 `游 -> 居` |
| 低阶悬赏 | 灵石 120-180 + 少量掉落 | 轻战斗过渡层 |
| 州内精英 | 灵石 180-260 + 稀有材料 | 单人高风险 |
| 丙等副本 | 灵石 220-320 + 专属掉落 | P1 首个副本层 |
| 宗门跑腿 | 灵石 100-150 + 贡献 15 | 低准备度宗门入口 |
| 巡查 / 镇压 | 灵石 140-220 + 贡献 40 | 组织高压事务 |

### 3. 基础支出带

| 行为 | 建议支出带 | 说明 |
| --- | --- | --- |
| 闭关 | 灵石 80 | 常规成长投入 |
| 疗伤 | 灵石 0-40 或 1 疗伤丹 | 无药也能恢复 |
| 调息回灵 | 灵石 0 或 1 回气丹 | 最便宜兜底动作 |
| 基础生产 | 灵石 25-40 + 材料 | 只服务补给 |

### 4. 经济目标

P1 要满足以下体验：

- 做 `1-2 次` 低风险任务，足以支付 `1 次恢复` 或 `1 次基础生产`
- 做 `3-4 次` 低风险动作，足以支付 `1 次标准闭关`
- 做 `1 次` 高风险成功内容，收益显著高于 `1 次` 普通任务
- 失败后的恢复成本明显存在，但不会高到让玩家破产

## 失败兜底

### 1. 没钱

兜底动作必须存在：

- `坊市打工`
- `跑腿递送`
- `调息回灵`

说明：

- 没钱时不能被迫做高风险内容
- 也不能没钱就无法恢复

### 2. 重伤

兜底路径：

`高风险失败 -> 强制回洞府或疗伤点 -> 疗伤 / 调息回灵 -> 重新回到 low-risk 循环`

说明：

- 重伤后的正确玩法是“先活下来”，不是继续硬冲

### 3. 断料

兜底规则：

- 闭关仍可低效运行
- 基础生产不可无料空转
- 缺料时引导回 `采集委托 / 州外游历`

## 派生视图总原则

P1 所有前台建议视图都必须满足：

- 给玩家直接可读的结论
- 不替代真实结算
- 不隐藏背后影响因素

## readiness

### 档位

- `poor`
- `stable`
- `ready`
- `advantaged`

### 判定建议

#### poor

满足任一即可：

- 处于 `injured`
- 灵力低于 `25%`
- 同时有 2 个以上负面状态
- 当前补给明显不足

#### stable

满足：

- 无重伤
- 灵力高于 `25%`
- 可以完成低风险动作

#### ready

满足：

- 无重伤
- 灵力高于 `60%`
- 当前有基础补给
- 当前目标风险与自身状态匹配

#### advantaged

满足：

- 灵力高于 `80%`
- 有正面状态
- 补给齐全
- 当前内容风险低于自身承受上限

## recoveryState

### healthy

- 无明显伤势
- 可正常进入常规和高风险内容

### wounded

- 有轻伤
- 仍可做低风险循环
- 高风险收益或稳定度下降

### injured

- 必须优先疗伤
- 不建议进入高风险内容

### depleted

- 灵力或关键底牌明显不足
- 不适合连续高压行动

## activityContext

P1 统一映射如下：

| 当前动作组 | activityContext |
| --- | --- |
| 无进行中动作，停留节点 | stationed |
| 赶路 | traveling |
| 从高风险内容撤出 | retreating |
| 疗伤 / 调息回灵 | recovering |
| 基础任务 / 宗门任务 | tasking |
| 州外游历 | exploring |
| 宗门事务 | sect-duty |
| 战斗或遭遇结算中 | encounter-resolving |

## 道势

### 定位

`道势` 是总结性战力表达，不是唯一真实数值。

### P1 构成建议

P1 可以先按以下因子合成：

- 境界基础分
- 主属性平均分
- 关键详细属性修正
- 当前 `readiness` 修正
- 当前状态修正

### 前台用途

- 内容推荐
- 风险提示
- 宗门任务建议
- 副本层级粗匹配

### P1 禁止用途

- 不作为所有结果判定的唯一公式
- 不替代属性、状态、战斗和任务真实结算

## 推荐系统口径

P1 前台推荐只做三件事：

1. 推荐下一个低风险动作
2. 警告当前不适合进入的高风险内容
3. 给出“回洞府 / 接任务 / 入宗门 / 做宗门任务”的下一步建议

不做：

- 复杂 AI 托管树
- 过度拟人化自动策略

## P1 验收清单

- 玩家能一眼看到自己当前是不是适合打高风险内容。
- 玩家能一眼看出自己是“受伤”还是“缺灵力”。
- 角色失败后总有明确的恢复路径。
- 低风险收益能支持洞府恢复和轻量生产。
- 高风险收益高于低风险，但不会压死其他玩法。
