# P1 黄金路径

## 目的

本文件用于定义 P1 的“标准可玩路径”。

它不是剧情脚本，而是一条产品验收路线。只要这条路线可以稳定跑通，就说明 P1 主循环成立了。

## 路径 A：新角色首次入界

### 阶段 1：完成注册

输入：

- 玩家完成标准入界登记

系统输出：

- 角色基础档案
- 注册结果
- 初始状态视图
- 初始推荐行动

默认起点要求：

- 落在一个 `P1 可用的州主城节点`
- 自动拥有 `1 个固定洞府`
- 获得基础起步补给

当前不在本文件冻结：

- 具体出生州 / 出生主城
- 新手补给的精确数值
- 新手补给的最终道具清单

本文件只要求新角色开局必须：

- 能立刻做一次低风险动作
- 失败后至少有一次恢复 / 回灵兜底

### 阶段 2：做第一个低风险动作

推荐动作优先级：

1. `坊市打工`
2. `跑腿递送`
3. `州外游历`

设计原因：

- 新角色需要先体验“时间会流动、动作会结算、日志会产生”
- 第一个动作不应强制战斗

本阶段结束后，玩家应理解：

- 自己在哪
- 有哪些动作可选
- 做完动作后会得到什么

### 阶段 3：完成第一次外出循环

标准流程：

1. 从主城或辅镇前往州外游历区
2. 完成一次游历
3. 获得材料、状态或事件结果
4. 根据状态决定是否回洞府

本阶段最重要的体验：

- 赶路有时间成本
- 州外游历区和城镇不是同一个功能点
- `游` 会把资源和问题一起带回来

### 阶段 4：完成第一次洞府循环

标准流程：

1. 回洞府
2. 根据当前状态选择 `闭关 / 疗伤 / 调息回灵 / 基础生产`
3. 等待 timed action 结算
4. 查看日志与状态变化

本阶段最重要的体验：

- 洞府不是摆设，而是资源转化中枢
- `居` 的主要作用是把问题处理掉，把准备度拉回来

### 阶段 5：完成第一次任务循环

标准流程：

1. 回到州主城或州辅镇
2. 从任务板接取 1 个基础任务
3. 按任务要求去执行
4. 统一回写奖励、损耗和日志

推荐首个任务：

- `坊市打工` 或 `跑腿递送`

本阶段最重要的体验：

- `遇` 不是副本大厅，而是把空间节点包装成可执行事务

### 阶段 6：加入宗门

触发条件建议：

- 完成至少 1 次基础任务
- 角色当前不处于严重伤势

加入后的立即变化：

- 获得 `外门` 身份
- 宗门任务入口开放
- 宗门贡献字段开始显示
- 前台出现宗门推荐事务

本阶段只冻结“存在可加入宗门框架”，不冻结具体加入哪一个宗门。

### 阶段 7：完成第一次宗门任务

推荐首个宗门任务：

1. `宗门跑腿 / 联络`
2. `资源上缴`

本阶段最重要的体验：

- `势` 不是单独的面板
- 宗门会把已有玩法重新赋予组织意义

### 阶段 8：看到长期目标

首次完成宗门任务后，前台至少要能让玩家理解：

- 宗门贡献在累计
- 自己当前的头衔是什么
- 下一个推荐目标是什么

P1 不要求玩家立刻冲头衔，但必须能看见这条成长线。

## 路径 B：低准备度兜底路径

适用状态：

- `readiness = poor`
- `recoveryState = wounded / injured / depleted`

推荐动作顺序：

1. `回洞府`
2. `疗伤` 或 `调息回灵`
3. 若仍缺钱，则做 `坊市打工`
4. 若状态恢复，再回到正常循环

设计要求：

- 低准备度角色永远要有保底动作
- 不能出现“没钱、没药、又受伤，结果无事可做”的软锁

## 路径 C：高风险接入路径

适用状态：

- `readiness = ready / advantaged`
- 当前补给充足

推荐顺序：

1. 先完成一次州外游历或基础任务
2. 进入 `低阶悬赏` 或 `州内精英任务`
3. 若状态良好，再尝试 `丙等副本`
4. 失败后强制回到 `居` 进行恢复与再准备

设计要求：

- P1 高风险路径必须明显比低风险路径更赚
- 但绝不能变成唯一可玩路线

## 单次标准闭环

P1 最短闭环建议统一表达为：

`主城接事 -> 外出执行 -> 带着资源或伤势回洞府 -> 处理状态 -> 再次出门`

若加入宗门，则变为：

`主城 / 山门接事 -> 外出执行 -> 回洞府处理 -> 再接宗门事务 -> 贡献累积`

## 黄金路径验收问题

只要以下问题都能回答“能”，就说明 P1 主循环成立：

- 新角色能否在 10 分钟内完成第一次低风险收益？
- 新角色能否在 20 分钟内看懂“游 -> 居”的资源循环？
- 新角色能否在 30 分钟内完成第一次基础任务？
- 新角色能否在 45 分钟内完成加入宗门并做第一次宗门任务？
- 高风险失败后，角色能否在 1 到 2 个动作内回到可玩状态？
