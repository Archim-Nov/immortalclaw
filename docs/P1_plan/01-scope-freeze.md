# P1 范围冻结

## 目标

P1 的目标不是“把所有修仙玩法都做出来”，而是先把一套能持续运转的修仙世界日常循环跑通。

一句话定义：

> 玩家完成注册后，能够在完整九州中移动、探索、回洞府转化资源、接取基础任务、加入宗门并开始积累贡献与头衔。

## P1 完成定义

P1 视为完成，至少要同时满足以下条件：

1. 新角色能从注册进入州主城，并获得默认洞府与初始行动能力。
2. 玩家能在九州内完成 `州内移动 / 跨州移动 / 游历 / 赶路事件`。
3. 玩家能在洞府内完成 `闭关 / 疗伤 / 调息回灵 / 基础生产 / 好友交流`。
4. 玩家能从州主城或州辅镇接取并完成基础任务。
5. 玩家能加入宗门，接取宗门任务，并获得宗门贡献。
6. 玩家能看到清晰的状态、准备度、恢复状态、近期日志和推荐行动。
7. 高风险内容的失败会产生真实后果，但不会把角色永久卡死。

## P1 模块边界

### 1. `游`

P1 必做：

- 完整九州
- 固定州模板
- 州内移动
- 跨州移动
- 州外游历区
- 州事件池与赶路事件池
- 州副本 `甲 / 乙 / 丙` 三档入口
- `travel-log / event-log`

P1 不做：

- 八荒
- 归墟
- 复杂天气系统
- 大规模区域占领
- 州与州之间完全不同的底层系统

### 2. `居`

P1 必做：

- 每角色 `1 个固定洞府`
- `闭关`
- `疗伤`
- `调息回灵`
- `基础生产`
- `好友交流`
- `cultivation-log / recovery-log / production-log / social-log`

P1 不做：

- 洞府经营扩张
- 多洞府管理
- 道侣系统
- 仇人系统
- 灵植完整系统
- 灵兽完整系统

### 3. `遇`

P1 必做：

- 州主城任务板
- 州辅镇任务板
- 5 类寻常任务模板
- 单人高风险入口
- 州内精英任务
- 甲乙丙副本挑战入口
- `task-log / encounter-log`

P1 不做：

- 深度多人副本机制
- 复杂招募系统
- 多阶段 Boss
- 大量任务分支树
- 深度情义系统

### 4. `势`

P1 必做：

- 加入宗门
- 宗门身份展示
- 4 类宗门任务模板
- 宗门贡献记录
- 头衔自动更新
- `sect-join-log / sect-task-log / sect-contribution-log / title-update-log`

P1 不做：

- 宗门经营
- 复杂权限树
- 宗门建筑系统
- 宗门战争
- 阵营战
- 宗门外交

## 本目录对旧冲突的统一裁决

### 1. 九州规模

裁决：

- P1 直接按完整九州落地
- 不采用“只做 3-4 个代表州”的缩减方案

原因：

- 上层正文已经冻结为完整九州
- 当前九州差异主要走数据表，不要求 9 套独立系统代码

### 2. `居` 是否包含基础生产

裁决：

- P1 保留基础生产
- 但只做轻量补给生产，不做生产队列大系统

原因：

- 上层正文已经把 `基础生产` 纳入 `居` 的 P1 最小交付
- 与 `P2 的基础生产队列` 可以自然衔接，不冲突

### 3. `遇` 的高风险内容强度

裁决：

- P1 做单人高风险入口
- 先做 `州内精英 + 副本挑战入口 + 强事件衍生挑战`
- 多人协作和深机制全部后移

原因：

- P1 需要把 `遇 -> 战 -> 居` 这条高风险支路跑通
- 但不需要把多人副本体系一次做完

### 4. 宗门系统深度

裁决：

- P1 只做“组织归属层”
- 不做经营层

原因：

- 与 `clawcity-gameplay-alignment` 的“宗门先做修仙版 gang”保持一致

## 本目录明确不冻结的内容

以下内容在当前阶段只允许作为后续配置项，不视为已经拍板的正式设定：

- 具体出生州和默认出生主城
- 新手补给的精确数值
- 州内 `3 个辅镇` 和 `甲乙丙节点` 的最终命名文案
- 具体有哪些可加入宗门

也就是说：

- 当前已经冻结的是 `P1 必须有宗门框架`
- 当前没有冻结的是 `P1 最终有哪些宗门、叫什么、怎么包装`
- 当前明确不采用固定“剑修 / 丹修 / 阵修”式宗门分类字段
- 当前宗门阵营明确分为 `正道 / 魔道 / 中立`
- 其中 `中立` 只用于九大默认宗门，可加入的玩家宗门仍只使用 `正道 / 魔道`
- 默认种子世界不再预置固定官方玩家宗门，只保留玩家宗门骨架与九大默认中立宗门据点

## P1 结构图

P1 统一按以下骨架理解：

`注册 -> 州主城落地 -> 低风险任务 / 州外游历 -> 回洞府恢复或转化 -> 更高收益任务 -> 加入宗门 -> 宗门任务与贡献 -> 周期性头衔更新`

## P1 验收清单

- 角色可以进入九州任意州的主城。
- 每州具备固定拓扑：`1 主城 + 3 辅镇 + 1 州外游历区 + 3 副本节点`。
- 赶路不是瞬移，且州内与跨州都有事件。
- 玩家至少能稳定完成 1 次低风险赚钱循环。
- 玩家至少能稳定完成 1 次“外出 -> 回洞府 -> 再出发”的资源循环。
- 玩家至少能稳定完成 1 次基础任务。
- 玩家至少能稳定完成 1 次宗门任务并获得贡献。
- 角色在受伤或缺灵力时，有明确恢复路径。
- 高风险失败会损耗时间、状态和资源，但不会软锁角色。
- 玩家能看到近期日志和系统建议，而不是只能盲玩。
