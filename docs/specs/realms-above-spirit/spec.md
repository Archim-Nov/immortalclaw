# 化神之上的炼虚、合体、大乘

## Summary

化神后期不再是梯子的顶。后面接炼虚、合体、大乘，每一境仍分前期、中期、后期。从化神后期起，每一小阶换一种做法，不把原来的守神台换成更贵的材料再按一次。兵器和功法这一轮仍停在化神。这一句说的是当时那一轮。兵器和功法的下一档后来写在 `docs/specs/combat-ladder-past-spirit/spec.md`。

## Problem

金丹以后的破境已经按阶段分开。人走到化神后期，`state.breakthrough` 是空的，摘要也告诉他没有下一阶。想再往上走，没有境界、没有材料、也没有另一种仪式。

## Goals

- 境界等级 16–18 是炼虚，19–21 是合体，22–24 是大乘。每一境仍用前期、中期、后期。
- 化神后期立炼虚台，进入炼虚。炼虚前期在宗门驻地落虚空印，中期在荒野或甲级门口走碎虚阵。
- 炼虚后期在宗门驻地走合道仪，进入合体。合体前期回洞府点双魂灯，中期在驻地合上天人合符。
- 合体后期在荒野或甲级门口扶天劫柱，进入大乘。大乘前期守大乘劫台，中期只在荒野乘风渡。大乘后期是这一轮的顶。
- 进炼虚、进合体、进大乘可能失败。材料照旧消耗，进度退到六成，人受伤，并带一段走火。小突破会成。一个人做成时，除了双魂灯，都会挂一点伤。有人看着，这点伤不必挂。
- 炼虚台和天劫柱有同伴在同一处时，失败会分掉一点，同伴也挂一点伤。合道仪有人看着，成功率高一截，失败不把伤分给旁人。
- 这些灵材坊市不卖，甲级不另开层。凉州和雷州的灵脉，人到了化神后期去收，会在化神那一份之外再按境界分出炼虚、合体或大乘的灵材。先入当地山门，把灵脉护下来再收。
- 闭关从炼虚起改用虚纹雾，合体用合道露，大乘用乘风灰。化神后期仍用神纹尘。
- `realmPath.sequence`、`goals`、`risk`、`digest.nextStep`、拒绝句和见闻用中文，不写行动标识。
- 气血、灵力和属性包在这三境继续往上走。名声在三次大境界上再动一动。兵器、功法和战斗目录不加新档。

## Non-Goals

- 不新开兵器表，也不新开功法档。化神仍是目录的顶。
- 不新开地宫品级，也不把甲级加到九层以外。
- 不改炼气到化神中期的材料、地点和按钮。
- 不强迫单人修士必须找同伴。同伴改变的是反噬和成功率，不是把这一阶锁死。

## User-Visible Behavior

化神后期的 `realmPath.method` 是 `void-altar`，`methodName` 是炼虚台。人在驻地里看不到这一阶。到了荒野或甲级门口，材料齐了，才能立台。做成以后境界是炼虚前期。句子里没有行动标识。

炼虚前期的 `method` 是 `void-seal`，名字是虚空印。先在驻地拓开，再按实，材料在按实的时候才耗。炼虚中期的 `method` 是 `void-array`，名字是碎虚阵，人要到荒野或甲级门口。

炼虚后期的 `method` 是 `unity-rite`，名字是合道仪，只在宗门驻地。合体前期的 `method` 是 `twin-lamp`，名字是双魂灯，回自己的洞府点灯再收口。合体中期的 `method` 是 `heaven-token`，名字是天人合符，在驻地合上。

合体后期的 `method` 是 `heaven-pillar`，名字是天劫柱。大乘前期的 `method` 是 `mahayana-platform`，名字是大乘劫台。大乘中期的 `method` 是 `wind-crossing`，名字是乘风渡，只在荒野，先迎风再渡。大乘后期没有下一阶。

凉州或雷州的灵脉，化神后期来收，会多出炼虚的灵材。炼虚后期来收，多出的是合体。合体后期来收，多出的是大乘。境界不到化神后期，多出来的那一份不会到手。

## Constraints

- 小突破仍然必成。反噬是伤，不是把进度打回六成。
- 身上有伤时，这些破境不做。
- 旧档的境界等级不用迁移。第十五层读到的就是炼虚台。
- 行动标识只留在 `recommendedAction` 和行动列表。

## Acceptance Criteria

- 境界等级 1–15 的境界名不变。16 是炼虚前期，19 是合体前期，22 是大乘前期，24 是大乘后期。
- 化神中期仍是守神台。化神后期的 `method` 是 `void-altar`，不是守神台。在荒野可以立炼虚台。驻地里这个行动不出现。拿错特殊材料会被拒绝，东西还在。
- 炼虚前期在驻地先拓印再按实，境界加一，虚空印露被耗掉。一个人按实会挂伤。拿炼虚台来做会被拒绝。
- 炼虚中期在荒野走碎虚阵可以做成。炼虚后期在驻地走合道仪，成功进入合体。洞府里合道仪不出现。
- 合体前期点双魂灯再收口，灯灭了不耗材料。合体中期在驻地合符。合体后期扶天劫柱，成功进入大乘。
- 大乘前期守劫台可以做成。大乘中期只在荒野乘风渡，甲级门口不出现这个行动。大乘后期没有下一阶。
- 这些句子、拒绝和见闻里不出现行动标识。
- 化神后期在凉州或雷州的灵脉上收，会多出一份炼虚灵材。化神中期在同一条脉上收，没有这份。
- 炼虚及以后的战斗档仍是化神。（后来由 `docs/specs/combat-ladder-past-spirit/spec.md` 接上，不再作为现行规则。）
