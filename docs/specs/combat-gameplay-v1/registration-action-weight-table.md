# 战斗注册标签动作偏好权重表

## Summary

本文用于承接 `combat-gameplay-v1` 中首版战斗行为选择的权重表，把 `core_temperament` 与 `behavior_aspect` 如何映射到 `快攻 / 普攻 / 核心技 / 重招 / 防御调息` 的偏好分单独冻结为一份实现文档。

本文是首版战斗行为选择的参数表来源；如与 `D:\桌面\immortal-claw\docs\specs\combat-gameplay-v1\spec.md` 冲突，以主 spec 的规则边界为准，以本文的权重表为参数基线。

## 1. 文档定位

当前首版战斗行为选择明确遵循：

- 不额外发明独立人格系统
- 直接复用注册层已有 taxonomy
- 首版只硬接 `core_temperament` 与 `behavior_aspect`
- `secondary_temperament` 与 `cultivation_motive` 先保留接口，不进入首版动作偏好权重表

## 2. 动作集合

首版动作偏好只面向以下 5 类基础动作：

- `快攻 / 轻术`
- `普通攻击`
- `核心技`
- `重招 / 大术`
- `防御 / 调息`

## 3. 权重边界

当前冻结：

- `core_temperament` 权重范围：`-2 ~ +2`
- `behavior_aspect` 权重范围：`-1 ~ +1`
- `core_temperament` 是主导项
- `behavior_aspect` 是节奏修正项

## 4. 合成公式

首版注册偏好分按以下方式合成：

`registrationBias[action] = coreTemperamentWeight[action] + behaviorAspectWeight[action]`

然后进入总评分：

`ActionScore = weaponBaseWeight + registrationBias + battleStateBias + resourceBias + smallRandom`

## 7. 首版解释口径

当前首版解释口径冻结为：

- `core_temperament` 决定长期主打法
- `behavior_aspect` 决定节奏和处理手法
- 兵器家族决定基础骨架
- 战局与资源决定当前轮是否偏离默认偏好

## 8. 运行时约束

首版继续冻结：

- 行为标签只通过稳定 taxonomy IDs 进入运行时
- 不允许基于中文标签字符串写分支逻辑
- 兵器骨架优先于性格偏好；性格只能改变“更倾向怎么打”，不能改写兵器本身职责
- 若后续新增 taxonomy，优先在本文追加映射，而不是散落回主 spec 正文
