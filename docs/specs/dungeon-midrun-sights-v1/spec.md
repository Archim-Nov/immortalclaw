# 地宫中途见闻 v1

## 问题

半托管地宫现在的体验是选定姿态，然后等战报。中途会醒的岔路大多是英文两项：走稳路或抄短路、迎精英或躲开、把收获收起来或再往里。八荒的醒时抉择也是同一套英文。房间节奏每一间都写进游记，句子短，也挤不进六个时辰的摘要。打赢了没有一句能反复拿去说的「带出何物」。

## 目标

- 地宫和八荒的醒时抉择全部改成自然中文。
- 中途醒时的场面加上岔路、遗物、同门相助、夺宝争执。一个场面在说得通时给三到四个做法。
- 地宫和八荒各自仍最多醒三次，超时仍是三刻。三十刻、每三刻走一步的半托管循环不变。
- 每累积两到四笔途中记录，写一条能拿回去说的见闻，同时进游记和摘要。
- 守关打赢时附一句短的、各处相同的「带出何物」。
- 新做法的报酬保持薄。

## 非目标

- 不做同队社交亮点。
- 不做乙级秘境的身份。
- 不做甲级收获编年。
- 不提高醒时次数，不把半托管改回逐步操作。

## 行为

- 第三步仍是伤者岔路：扶起、分水、拿走袋子。超时按姿态代选。
- 第六步和第八步从岔路、遗物、同门、夺宝里抽还没出现过的场面。气血低时精英可以进这一池，收获已经不少且人已经虚时，收手或再往里也可以进这一池。
- 稳妥代选安全的做法，冒进代选有风险的做法，均衡用场面自己的默认项。
- 新做法的灵石大约在扣 6 枚到加 12 枚之间，道德加减不超过 2。原来的短路、硬接精英、再往里仍按旧的薄增益结算。
- 途中每两到四笔记录合成一条见闻。跑完时还没写出去的记录补成最后一条。同队跟着的人拿到同一句，不另记人情。
- 守关胜利的战报末句、游记和摘要都带同一句「带出何物：……」。有实际掉落就写名字和枚数，没有就写一件很轻的东西。
- 八荒四种醒时场面改成中文，并在说得通时补到三项或四项。深度每前进两到四步写一条见闻。走完时同样给一句「带出何物」。

## 验收

- 代理在 `GET /agent/actions` 里看到的地宫和八荒醒时标签是中文，一次三到四个做法。
- 一次地宫仍最多三醒。
- 跑完以后游记和六个时辰的摘要里有见闻。打赢的战报里有「带出何物」。
- 领域测试和 `build:web` 通过。
