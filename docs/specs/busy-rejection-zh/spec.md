# 正忙拒绝不再夹行动 id

## Summary

人还在做事时再提交别的动作，拒绝已经是中文，但每句都写着 `abort-dungeon-expedition`。执事、打坐这种事也会被劝去中止地宫。这一轮只改这句给人看的拒绝。

## Problem

`requireIdle` 不看手头是什么事。只要 `activeJobId` 还在，拒绝就是「你正忙着，手头的事还没做完。等这一趟结束再来。地宫还在走的话，用 abort-dungeon-expedition 结账，人会回到安全的地方。」

实机在扬州执事途中提交 `gather-vein` 或 `sect-chain:patrol`，`error` 和 `summary` 都是这一句。人并不在地宫里，英文行动 id 也漏进了给人看的字。

## Goals

- 没有地宫在走时，拒绝停在「你正忙着，手头的事还没做完。等这一趟结束再来。」
- 地宫远征还在走时，后一句用行动卡上的「中止地宫远征」，不再写行动 id。
- `error` 和 `summary` 仍是同一句。
- 其余正忙拒绝保持现在的中文，不往里塞行动 id。

## Non-Goals

- 不改中止地宫的结算，也不改行动 id。
- 不改八荒和归虚。
- 不改切磋待回应、同行说明、高阶途径里另外几处仍夹着行动 id 的句子。那些不是正忙拒绝。

## User-Visible Behavior

打坐、执事、巡山这类还没做完的事上，再提交别的动作，拒绝是「你正忙着，手头的事还没做完。等这一趟结束再来。」这句话不提地宫。

地宫远征还在走时，同一句后面接上「地宫还在走，用中止地宫远征结账，人会回到安全的地方。」「中止地宫远征」就是门口那张卡的名字。

向正忙的人下挑战书，仍写那个人的名字，并说改日再来。

## Constraints

- 行动 id 留在行动列表上，不写进拒绝。
- 只有 `getActiveDungeonExpedition` 还能找到这一趟时，才提中止。区域地宫、执事、赶路都不算这一趟。
- 中止、岔路、场面选择仍在空闲检查之前处理，忙着也能交这些。

## Acceptance Criteria

- 执事或打坐途中再提交动作，拒绝是上面那句短话，不含 `abort-dungeon-expedition`，也不含其他连字符行动 id。
- 地宫远征途中再提交动作，拒绝含「中止地宫远征」，不含 `abort-dungeon-expedition`。
- 两句都同时出现在 `error` 和 `summary`。
- 相关领域测试通过。
