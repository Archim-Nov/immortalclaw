# 见闻里的敌人要用中文名

## Summary

地宫守关打完以后，游记写成了「与青州甲级秘境 Heavy Warden过了手」。同一场的战报已经在用「重压守卫」「重压守卫·魂灯」。给人看的敌人名字改回配置上的中文名。

## Problem

敌人配置同时有英文 `name` 和中文 `nameCn`。组队战用的是 `nameCn`，所以战报里是重压守卫·魂灯。游记那一句 `与……过了手` 走的是另一条，把地点名和英文 `name` 拼在一起。荒野猎兽在没有州外地名时，也会退回英文 `name`。

## Goals

- 配置了 `nameCn` 的敌人，见闻标题、见闻正文、战报上的敌人名都用这个中文名。
- 重压守卫这场，游记是「与重压守卫过了手」，正文里也是重压守卫，不再出现 Heavy Warden。
- 甲级四层的组队战报仍写重压守卫·魂灯。
- 英文 `name` 留在配置上，不改战斗数值。

## Non-Goals

- 不改守关胜负、掉落、伤势。
- 不把城里切磋里对手修士的本名改掉。
- 不重写战报里本来就整句英文、又没有点出敌人名字的旧结算。

## User-Visible Behavior

金丹后期在青州甲级秘境进四层，和重压守卫打过之后，游记标题是「与重压守卫过了手」。正文写的是和重压守卫过了几合。同一场战报点出重压守卫，从者仍是重压守卫·魂灯这一类中文名。

单独去守这一关时，最近战报上的敌人名也是重压守卫。

## Constraints

- 行动 id、敌人 id 不改。
- 中文名从 `enemyFacingName` 取。`nameCn` 里没有汉字时，守关写「守关」，猎兽写「脉兽」。

## Acceptance Criteria

- 游记里不再出现 Heavy Warden，以及其它已配置敌人的英文 `name`。
- 「与重压守卫过了手」出现在这一场的见闻里。
- 甲级四层战报里仍能看见重压守卫·魂灯。
- 相关领域测试通过。

## Open Questions

- 没有。
