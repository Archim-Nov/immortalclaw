# 本州夺脉与抉择窗口

## Summary

筑基中期的宗门弟子在本州就能看见并打完一次宣战夺脉。地宫中途抉择和宗门事务抉择把等待从三刻拉到十刻，亲手选和时辰到了代选写成两句不同的话。筑基中期、后期的境界说明会提前告诉人，结金丹的材料不在坊市，要去甲级一到三层。

## Problem

听潮阁把扬州药田、灵脉、矿脉都收下以后，`sectLife.raids` 一直是空的，行动列表里也没有 `declare-raid`。矿脉开局没有主人，护脉就能收下。药田和灵脉归本宗。本州没有别的宗门占脉，跨州又被「先打本州的脉」挡住，所以筑基执事、长老在自己的州里跑不通夺脉。

地宫和护脉的场面本身有内容，可是 `timeoutTicks` 只有 3。人没点，就按默认走完。游记里只剩「走了稳路」或「时辰到了，按稳妥的做了」，看不出是自己选的还是时辰到了替你选的。筑基中后期的 `realmPath` 仍只说这一步的材料坊市买得到，不提再往上结金丹要去哪。

## Goals

- 每一州在已有地点上多一条筑基档的边寨，主人是相邻州的中立宗门，不是本州宗门。
- 筑基以后的执事、长老、掌门在山门就能看见 `宣战夺脉：…`，打赢或打输都写一条见闻。
- 护脉仍然只能收自己的脉，或还没有主的脉。边寨不能靠护脉白拿。
- 宗门品级仍按本州占脉来算。邻宗在别州占着的边寨，不给那一宗白加一条本州的脉。
- 地宫醒时抉择和宗门事务抉择等到十刻。等待期间远征不往下走，行动列表里一直有 `dungeon-wake-decision:*`。
- 亲手选写成「你选了……」，并记进这一步的 beat 和道心。超时写成「时辰到了，代选了……」。
- 等待期间 `wakeNodeHint.decisionLine` 和 `digest.priorities` 写「地宫岔路待决」。
- 筑基中期、后期的 `realmPath.where` 和 `goals` 说明：这一小步仍可在坊市买材料；结金丹的材料坊市不卖，要去甲级一到三层的丹霞内府。

## Non-Goals

- 不改中文壳，不改战斗数值，不把九州副本一次写完。
- 不开放任意跨州宣战。边寨人就在本州，只是主人是邻宗。
- 不把八荒醒时、同队投票的超时一并改掉。
- 不改炼气、筑基小突破的购买和成功率。

## User-Visible Behavior

`ensureSpiritVeins` 在每州已有的东镇放一条 `{stateId}:border-camp`。名字是邻宗名字加「边寨」，例如扬州是「苍木谷边寨」，境界档是筑基，主人是该州第一条跨州路上的中立宗门。药田、矿脉、灵脉的归属不变。

筑基执事、长老或掌门在山门，或人已经站在边寨上时，`sectLife.raids` 和行动列表都有 `declare-raid:<veinId>`，标签是 `宣战夺脉：苍木谷边寨` 这种句子。打赢以后边寨归本宗，游记和最近六个时辰里有「见闻：……夺下了……」。打输有「见闻：……没能拿下……」，人受伤，贡献下降。原来三条脉的护脉、收脉不变。

地宫醒时的 `timeoutTicks` 是 10。窗口开着时，`GET /agent/actions` 列出 `dungeon-wake-decision:*`，`wakeNodeHint.decisionLine` 和 `digest.priorities` 都是「地宫岔路待决」。提交一次选择以后，beat 的正文、游记和道心都以「你选了」起头。十刻没人开口，正文和道心以「时辰到了，代选了」起头，代选的仍是原来的稳妥或姿态默认项。

宗门本职和宗门事务最后一拍仍会停下来。等待同样是十刻。自己点了，见闻写「你选了」。到点没点，见闻写「时辰到了，代选了」，然后仍按原来的稳妥项结算。

筑基五层、六层的 `realmPath.where` 在原来的坊市句子后面补一句：这一步仍是小突破，材料可以在坊市买；再往上结金丹，材料坊市不卖，要去甲级一到三层的丹霞内府。四层及更早不写丹霞内府。

## Constraints

- 边寨锚在已经存在的 `{stateId}:sub-town-east`，不新开地点种类。
- 宣战门槛不变：筑基，并且是执事、长老或掌门；仍只能打本州的脉；本宗刚打过要等六个时辰。
- 品级用的占脉数只数 `stateId` 等于本宗州府的脉。
- 地宫一趟仍最多醒三次。窗口变长会把这一趟的墙钟拉长，因为等待时这一步不往下结算。

## Acceptance Criteria

- 领域测试断言每一州都有一条不属于本州中立宗门的边寨，扬州听潮阁的筑基执事能看见 `宣战夺脉：`，长老打赢后见闻里有「夺下了」。
- 站在别人的边寨上没有 `sect-chain:guard-vein`。
- 地宫醒着时，超时前行动列表含 `dungeon-wake-decision:*`，`decisionLine` 和 `digest.priorities` 含「地宫岔路待决」，`timeoutTicks` 在 8 到 12。亲手选写入 beat 和道心，正文含「你选了」。超时正文含「时辰到了，代选了」。
- 筑基五层、六层的 `realmPath` 含「金丹」「坊市不卖」「甲级」「丹霞内府」，并且仍写这一步可以在坊市买。四层不出现「丹霞内府」。

## Open Questions

- 边寨被本宗夺走以后，所有权不会自动改回去。结仇、边衅和冷却后的来探见闻见 `docs/specs/raid-feud-and-jia-gate/spec.md`。
