# 试玩 #60 之后的结算和表面

## Summary

甲级撤出以后，战报里的灵材数量要和袋子里的增量一致。甲级中途岔开的闲事改用丹霞、火毒、阵纹的句子。同一人的多张字条、夺下边寨之后的边衅、以及失败的行动，都要能从玩家看见的中文里分辨出来。

## Problem

浸泡报告对着 `9be1508` 记下了这些对不上的地方：

- `lastReport` 写带回 5 份金灵花，袋子里金灵花仍是 0。主材料计数把这一档破境池里的所有灵材都算成了金灵花。
- 旁支写 4 份丹霞露，进门到出门却多了 5 份。多出来的那一份是撤出或走完时才发的，写在报告之后。
- 甲级探路时的 `choose-event` 用了染匠、当票、药担这种街巷句子。药担那句还写成了「你好叶子」。
- 同一个人留下的两张字条，看和回的标签都是「看字条：青萝」。
- 己方夺下边寨以后，边衅写成「苍木谷还记着苍木谷边寨」。
- 行动失败时响应里只有 `error`，`summary` 是空的。只展示 summary 的客户端会看到空白。

## Goals

- 战报里的主材料和旁支，与这一趟袋子里的正向增量一致。没有进包的东西，摘要里不写带回。
- 撤出或走完时补发的丹霞露和来源物，先入账再写报告。
- 甲级中途的 choose-event 仍用原来的走、帮、取、险骨架，文案换成丹霞、火毒、阵纹。
- 「你好叶子」改成通顺的「药叶子」。
- 同一人多张未读字条时，看字条和回字条的标签用短节选或序号区分，仍是中文。
- 己方已占边寨时，边衅说仇家还记着这座边寨，不把宗名和寨名叠在一起。
- 失败的行动响应里，`summary` 和 `error` 都带上同一句玩家能读的话。

## Non-Goals

- 不改地宫掉落池本身，金丹材料仍从原来的池子里抽。
- 不改丙级、乙级街巷闲事的选题，只改其中那句错字。
- 不改字条的 action id，也不改边衅的结仇和冷却。
- 不合并。

## User-Visible Behavior

甲级撤出后，金灵花的 `primaryMaterial.count` 等于袋子里多出来的金灵花。是 0 就不在摘要里写带回金灵花。丹霞露、残碑碎片和其他真正入包的东西写在旁支上，份数和 `inventoryDetails` 的增量一致。

甲级进行中岔开的闲事，句子里能看见丹霞、火毒、阵纹、丹炉或灵火，不再出现染匠、当票和药担。提示仍以「地宫里岔开一件闲事」起头。

两张青萝的字条，标签不再完全相同。夺下苍木谷边寨以后，边衅是「苍木谷还记着这座边寨」。灵石不够时，响应的 `summary` 里能看见差价。
