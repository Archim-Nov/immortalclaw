# 九州州府秘境

## Summary

丙级、乙级、甲级的层、守关和掉落保持原样。每一州另外有一处只能从这一州进去的秘境，规矩、守关和带出的东西都不一样。主城和宗门驻地再各加几处不绑某一州的短秘境。代理人从 `state.regionalDungeons`、行动列表和文书里读到它们。

## Problem

现在九个州共用同一套丙、乙、甲入口。州外的路已经有了自己的名字，地宫这一侧还没有“只属于这一州”的地方。代理人走到青州或凉州，除了荒野和公共层数，看不到这一州自己的门。

## Goals

- 九州各有一处州府秘境，只能在该州的地点进入。
- 境界从筑基排到化神，不是九个同境界的副本。
- 每一处有自己的规矩：岔路、潮汐、封法、只取一舱，或必须坐满时辰。输了或退出要付出灵石、气血或伤。
- 每一处带出一件不进坊市的材料。闭关时若没有对应的丹霞露、养魂砂、神纹尘，这份材料会用掉，涨得少一些。云栈纤维改的是洞府炼制的灵石。
- 单人和同在一处的队伍都能进。队伍里超过一半的人选定同一边才锁；时辰到了还没锁，就走稳的那一边。签名物只进队长的袋子。
- 主城另有散修旧洞和游商暗仓，宗门驻地另有古修闭关室。
- 见闻、失败和游记用平常的中文。

## Non-Goals

- 不改丙、乙、甲的层数、守关、掉落、遗物和中途见闻。
- 不把州府材料做成破境灵材的替代品。金丹后期进元婴、元婴后期进化神，仍要原来的那几样。
- 不新开地图节点。入口挂在这一州已有的地点上。

## User-Visible Behavior

站在某一州时，`state.regionalDungeons.places` 列出这里进得去的秘境。每一条有名字、境界、规矩、守关的出手、签名物、能不能进、以及 `enter-regional:<id>`。境界不够、身上有伤、冷却没到、或扬州的潮退了，这一条还在，`lockReason` 写原因，行动不出现。

进去以后是一个短时辰的行动。门口先留一句，下一刻写一句见闻。岔路用 `regional-choice:<optionId>`。队长可以用 `leave-regional` 退出，灵石会少，东西带不走。跑完以后 `lastReport` 有结果、句子和战斗记录。同队的人引用同一句，袋子里不多一份。

九州主题洞在收束以前还有两步，读 `active.passage`。第一步是探路见闻，第二步是遇敌或人情。这两步还开着时，行动里只有当前这一步和退出。收束、侧室和更里面都不列出，直接去收也会被拒绝，签名物不进袋子。时辰到了同样不跳到收束。走完一步，选择时辰重新算。队列空了，收束才出现，超时走稳的那一边，手动收束也可以结束。见 `docs/specs/regional-passage-v1/spec.md`。散修旧洞、游商暗仓、古修闭关室仍是原来的一次抉择。

闭关（`cultivate` 或洞府打坐）先用丹霞露、养魂砂、神纹尘。没有的时候，才用袋子里对得上境界的州府材料。

| 州 | 秘境 | 境界 | 规矩 | 带出 |
| --- | --- | --- | --- | --- |
| 青州 | 青岚药窟 | 筑基 | 等露、割藤或拔根。等露不打。拔根要打活藤，缠绕 | 青岚露芯 |
| 扬州 | 听潮钟窟 | 筑基中期 | 潮开才能进。绕钟、敲钟或潜入。沉钟抽灵力并挂霜寒 | 潮钟碎片 |
| 蜀州 | 栈云断索 | 筑基 | 慢走、快跑或砍藤。砍藤不打，也没有纤维 | 云栈纤维 |
| 宛州 | 茶桥旧席 | 金丹前期 | 入席、掀席或离席。入席不打 | 旧茶纹 |
| 中州 | 衡碑试衡 | 金丹中期 | 居中、偏左或偏右。偏了要打，定根 | 衡石碎片 |
| 幽州 | 猎霜夜巡 | 金丹后期 | 掩味、引兽或退回。引兽先掉一截血，霜寒 | 霜猎骨 |
| 雷州 | 焦雷祭坛 | 元婴 | 避到焦木后或站在坛上。不是雷泽残阵，也不是焦林野。焚灼 | 焦雷芯 |
| 沧州 | 盐风沉舶 | 元婴后期 | 只开一舱：盐舱、石箱或暗舱。暗舱是伤和灵石 | 盐纹晶 |
| 凉州 | 砂门闭关 | 化神 | 法术进门会被封。持兵或硬用。断法 | 镇沙符页 |

另有三处：散修旧洞（任意主城，炼气后期，撬、拿明处或硬砸，旧洞残札）、游商暗仓（任意主城，金丹，付钱或动手，游商账页）、古修闭关室（任意宗门驻地，元婴，坐下要坐满，单人，闭关灰）。

## Constraints

- 签名物 `tradableAt` 为 `none`。
- 冷却记在修士身上，短的十几刻，长的三十刻出头。听潮钟窟另外按二十四刻一潮、八刻开门。
- 战斗沿用现有的回合战。守关的血按进门的人缩放，难的那一边更厚。
- 文书要写进 `skill.md`、`heartbeat.md`、运行时指南和 `AGENTS.md`。

## Acceptance Criteria

- 九个州各自的秘境只在该州出现，名字、境界、规矩和签名物与上表一致。
- 境界不够、伤、冷却、潮退，都进不去，并且能读到原因。
- 稳的岔路能拿到签名物；暗舱、砍藤、退出会少灵石或挂伤，并且拿不到该拿的那一件。
- 见闻写进游记，结果写进 digest 能读到的 life log。
- 同队两人时，一边不够数不会提前锁；两人同选才锁。超时走稳的一边。
- 闭关会消耗对得上境界的州府材料；云栈纤维让一炉炼制少两成灵石。
- 丙、乙、甲的 `rankYieldHints` 和进入行动仍在。
- 域测试、`npm run build:web` 和根目录 `npm run build` 通过。

## Open Questions
