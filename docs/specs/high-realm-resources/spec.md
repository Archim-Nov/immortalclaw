# 高境界的灵材、秘境和兵器功法

## Summary

金丹、元婴、化神各自有闭关灵材、破境灵材，以及甲级地宫里对得上的秘境。大圆满和化神的兵器、功法不再只靠坊市加价，秘境掉落、洞府配方、宗门兑换、宗门差事和破境悟到的残页，都写进代理人能读的状态里。炼气和筑基的买材料、洞府破境、丙级乙级探宝保持原样。

## Problem

境界梯子和破境材料已经分到化神，战斗目录也有大圆满和化神的招。活着的循环仍像是把早期那一套加了层数。

- 闭关不吃这一境自己的灵材。金丹以后的人闭关，和炼气用的是同一套空转。
- 甲级九层只是更厚的守关。金丹前期只要把层数刷上去，就能进七层，和元婴后期走的是同一扇门。
- 大圆满和化神的兵器、功法，境界一到就能在坊市按更高的价钱买走。秘境里的锻材、洞府配方、宗门差事和破境残页，没有写成走得通的途径。
- 代理人读 `realmPath` 和 `nextWeapon` 时，看得到去哪一层，看不清这一阶的兵器到底是买、锻、换，还是秘境里掉。

## Goals

- 金丹用丹霞露，元婴用养魂砂，化神用神纹尘。闭关时手里有对应的一份，就用掉，修为多涨一截。没有也不挡住原来的闭关。
- 甲级一到三层是丹霞内府，金丹就能进，掉金丹灵材、丹霞露和大成锻材。
- 甲级四到六层是婴火莲池，金丹后期才能进，掉元婴破境灵材、养魂砂和大圆满锻材。
- 甲级七到九层是神纹天隙，元婴后期才能进，掉化神破境灵材、神纹尘和化神锻材。
- 丙级、乙级的入口和层数不动。炼气后期仍可去丙级七到九层。
- 大圆满和化神的下一阶兵器、功法，坊市不卖。取得途径是秘境掉落、洞府配方、宗门兑换、宗门差事、破境残页。这些写在 `nextWeapon.paths`、`nextManual.paths` 和 `realmPath.resources` 里，每条都是完整的句子，并带上能用的动作。
- 秘境掉落优先给手上这一系还缺的锻材。大约四次里有一次，境界已经够了，会直接掉成器。
- 宗门差事在自己的宗门驻地，带回一份锻材或残页。同一趟隔六个时辰。

## Non-Goals

- 不新开地宫入口，不另做一套钱和商店。
- 不改炼气、筑基的材料、价格、洞府破境和丙级乙级探宝。
- 不改回合、伤口、队伍和社交。
- 不把金丹前期赶去刷七层，也不让他们进婴火莲池。
- 大圆满和化神的宗门兑换仍只看贡献门槛，不扣贡献。

## User-Visible Behavior

炼气的 `realmPath` 仍只谈坊市和当前这一层，不出现丹霞露、婴火莲池或神纹天隙。摘要在无事时仍是「过得平常」，没有 `nextStep`。

金丹前期站在甲级门口，能进一到三层。四层会被告知得到金丹后期才进婴火莲池。探宝掉丹霞露。闭关用掉一份，修为比不用时多十二点。

金丹后期能进婴火莲池，不能进神纹天隙。元婴后期能进神纹天隙。推荐层跟着这条门走：金丹前期和中期看一到三层，金丹后期和元婴前中期看四到六层，元婴后期和化神看七到九层。

元婴修士的下一把大圆满兵器，坊市没有购买动作。`nextWeapon.paths` 里有秘境、配方、宗门、任务、破境五句。宗门贡献够了，兑换动作仍在。驻地能跑 `band-errand:weapon` 或 `band-errand:manual`。

## Constraints

- 掉落、配方和兑换沿用现有的物品、地宫品级和 `recipe-forge` / `recipe-synthesize`。
- 旧存档没有丹霞露、养魂砂、神纹尘时，补 0。
- 甲级一层到三层仍掉金丹破境灵材，不掉元婴和化神的破境灵材。四层起的破境掉落池不改。

## Acceptance Criteria

- 炼气的突破材料仍是原来的那一套，`realmPath` 不出现丹霞露和婴火莲池。
- 金丹前期进不了甲级四层。金丹后期进得了四层，进不了七层。元婴后期进得了七层。丙级高阶不吃这道门。
- 甲级一层的探宝会掉丹霞露，不掉养魂砂。四层会掉养魂砂，不掉神纹尘。七层会掉神纹尘。
- 金丹闭关用掉丹霞露以后，修为比同样一次不用露多十二点。
- 元婴的下一把大圆满兵器不在坊市动作里。`paths` 含秘境、配方、宗门、任务、破境。宗门差事带回这份锻材，六个时辰内不能再跑。
- 金丹后期的推荐层在四到六，不在七到九。炼气后期的丙级推荐层仍在七到九。

## Open Questions

- 没有。化神后期之上这一轮不加境界，也不新开地宫入口。
