# 荒野层的两步岔路

## Summary

九州的荒野仍从原来的门进去，名字、状态、跟着的兽、压力和撤出的短话都不改。走进这一层以后，先停一步历练，再过两刻停一步奇遇或人情。两步都用中文三选，写进游记和 digest。这一层仍是一个人走。八荒和归虚不动。

## Problem

州外已经能讲出青岚坡、听潮浦这些名字，可是走进去以后，代理人能做的仍是再探、猎兽、撤出。压力在掉，地方却不像一个能走完的地方。地宫和州府秘境都已经有中途要答的一步，荒野还没有。

## Goals

- 九处荒野各有两步，内容跟着这一处的名字、状态和跟着的东西，不共用同一套三张卡。
- 第一步多是历练，碰上这一处的兽。第二步是奇遇或人情。
- 答完写一句见闻，游记和 digest 都能读到。选拿走的那一边，东西这时才进袋子。
- 岔路开着时，行动里只有这一步和撤出。再探、猎兽、同行历练不列出。直接提交会被拒绝，这一步的东西不进袋子。
- 时辰到了、气血或灵力见底，也不代选，不跳到下一步，东西不进袋子，人还停在这一步。
- 自己撤出仍是原来的短话，不另扣灵石，也不带上还没选的那一步的东西。
- 两步都走完以后，再探、猎兽、压力和到时撤出还是原来的样子。

## Non-Goals

- 不改八荒的深度、醒时和撤出扣石，也不改归虚。
- 不把荒野改成地宫房间，也不发通关遗物。
- 荒野进度仍是每人一份。同伴不在这一层里投票。`dual-survey-wilderness` 仍是另外一趟双人差事，岔路开着时不出现。
- 路上的见闻还是原来的一句，不在赶路的差事里另开岔路。

## User-Visible Behavior

走进青岚坡以后，`state.wilderness.beat` 写出第几步、共两步、是历练、奇遇还是人情、一句场面，以及三个中文做法。`digest.priorities` 写荒野岔路待决。`wild-choice:<optionId>` 回答。摘要以你选了起头，接着是这一处的见闻，不出现行动编号。

青岚坡第一步是露蛛和药藤，挂缠绕。割藤会把药藤收进袋子。顺着丝找露蛛会拿到兽核，人也挂上伤。绕开则什么都不拿。第二步是洒了的露。旁边有人并把露拢回去，会记下把洒了的露拢给我。旁边没有人，露就留在坡上。自己捡走会多一些灵石。

听潮浦是潮蟹和网里的石。衡野驿是路碑、驿影，然后是亭里没水的人，并写明不是旧驿石廊。栈云径是藤猿、云蛛，然后是栈缝里的绳。猎霜原是霜犬，然后是火堆边的人。砂门碛是沙蜥，然后是沙窝里的水囊。焦林野是雷雀和焦木，写明不是雷泽残阵，然后是灰里的口袋。盐风礁是礁蟹，然后是松了的船缆。茶桥野是茶鼬，然后是棚里收摊的人。

第一步答完，再过两刻，第二步才出现。这两刻里可以再探，也可以撤。第二步还没出现时，到了原来的生存时限，仍会按原来的规矩撤出，第二步的东西不进袋子。

岔路开着时一直停在这一步。压力照样掉。撑满时辰，或者气血、灵力见底，都不会替你选，也不会把这一步的东西放进袋子。

## Constraints

- 名字和场面跟 `wild-places` 里已经有的地名、状态、兽名走，不新做一套状态。
- 旧进度没有这两步字段时，下一次读行动或往前走一刻，从第一步算起。
- 文案不出现行动编号，也不把英文事件名写进摘要。

## Acceptance Criteria

- 走进青岚坡，行动里是三个中文做法和撤出，没有再探。选割藤以后，袋子里多一份矿，游记和 digest 有青岚坡的见闻，摘要里没有行动编号。
- 焦林野的第一步写雷雀、焦木、焚灼，不写露蛛，做法也和青岚坡不同。
- 岔路开着时把世界往前推过生存时限，人还在第一步，矿和灵石都不因这一步增加。这时提交再探会被拒绝。撤出的句子仍是从青岚坡退出来，不另扣灵石。
- 第一步走完再过两刻，第二步才出现。第二步开着时再往前推，仍不把第二步的灵石放进袋子。
- 两步都走完以后，压力仍会把人送出去。撤出不另扣灵石。
- 旁边的人各自有自己的进度。一个人选了，另一个人的岔路还在。
- 九处的做法不互相重复。八荒的三段名字不动。
- `tsc -p tsconfig.json --noEmit` 通过，相关测试通过。

## Open Questions

- 没有。这一层一个人走，所以不需要队伍计票。
