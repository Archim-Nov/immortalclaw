# 乙级中途与组队投票窗口

## Summary

组队地宫的投票从三刻放到十刻，和单人地宫、宗门抉择同一扇窗。乙级进门以后，除了门口那一句身份，中途再有一队有名字的敌人、一处薄机缘、一场口角。组队走进乙级时，第六步不再是通用的短路夺利，换成这一层自己的人情。

## Problem

单人地宫和宗门场面已经等到十刻。组队投票仍是三刻。人多的时候票还没齐，就落到安全项，伤员、让石、分赃这几手常常出不来。

乙级的门已经有名字：雷泽残阵、沉雾沼、铜棺窟。进门以后的可玩内容仍和丙级共用同一套抽法，容易只剩下门口那句，加上一次岔路。遇敌、机缘、人与人之间的口角都不够。

## Goals

- 组队抉择的 `timeoutTicks` 改为 10。超时仍落安全项，冒进姿态也不能单靠超时抢走东西或弃伤。
- 乙级单独再加三类中途节点，仍走现有的远征、室内和组队投票，不另开行动编号。
- 第七步若是搜寻，遇上一队只有乙级才有的敌人。名字不替换守关从者。
- 单人乙级的第六步是这一层的薄机缘，第八步是两个散修的口角。做法三个或四个，句子是中文，不夹行动编号。
- 组队乙级的第六步改成这一层的人情。护住对方记一笔人情并涨好感，趁空拿走记嫌隙以下的仇。游记能验到那一句。
- 丙级和甲级的中途抽法不动。甲级丹霞的气质池、战报和入包不动。

## Non-Goals

- 不增加醒时次数。一趟仍最多三次。
- 不改丙级、甲级组队在第六步的让石和短路。
- 不改乙级守关从者的名字、血量和挂上的状态。阵脚、残雷、沼影、雾丝、棺侍、铜卫仍只出现在守关。
- 不把中途报酬加厚。灵石加减仍落在扣 6 枚到加 12 枚这一档。
- 不新做一套地宫状态，也不把州府秘境的侧室改掉。

## User-Visible Behavior

组队投票开着的时候，`timeoutTicks` 是 10。三个人里有三票仍能提前锁。到点没有锁住，仍按安全项收，句子里仍说时辰到了。

一个人走乙级一到三层，第七步若是搜寻，战报里是雷索客和麻符修。四到六层是沼钩客和湿咒修。七到九层是霜戟客和铜灯修。这一队没有精英，也不是守关从者。

同一次单人乙级，第六步停在机缘上。雷泽残阵是残雷，沉雾沼是没湿透的一包，铜棺窟是棺沿上的铜屑。四个做法。第八步停在口角上，也是四个做法。丙级和甲级的第六步、第八步仍从原来的岔路、遗物、同门、夺宝和后来的新鲜场面里抽。

组队走进乙级，第三步仍是伤，第八步仍是没人认领的东西。第六步换成这一层的人情。雷泽残阵是把丹递过去或趁断法先捡。沉雾沼是拉上干处或自己先踩过去。铜棺窟是把袖口分过去或先摸棺沿。安全项是护住对方。护住以后，对方欠「断法的时候把丹递给我」「雾里把我拉上来」或「霜寒里把袖口分给我」，好感往上走，游记里有这一句。趁空拿走，自己多八枚灵石，和在场的人结 3 点仇，还没到嫌隙。

## Constraints

- 玩家看见的句子里不出现行动编号，也不出现英文内部名字。
- 乙级第七步的敌人只在搜寻时出现，不改抽步，因此甲级前三步先探路的规则不动。
- 组队第六步的新人情只在 `grade === "乙"` 时替换让石。丙级、甲级的测试行程仍走原来的三步。

## Acceptance Criteria

- 组队三个旧场面和乙级第六步的新场面，`timeoutTicks` 都是 10。没锁住的票，冒进也落到安全项。
- 乙级第七步搜寻能打出上述第三队名字。丙级、甲级同一步没有这队。原来的雷枪客、断法修、残阵主和后手名字仍在。
- 单人乙级第六步是机缘，第八步是口角，句子里有这一层的地名。丙级第六步仍能抽到原来的新鲜场面。甲级第六步不会变成乙级机缘。
- 组队乙级护住对方以后，人情原因、好感、游记可以断言。趁空拿走以后，灵石和仇可以断言。
- `npx tsc -p tsconfig.json --noEmit` 通过。相关 `node --import tsx --test` 通过。

## Open Questions

- 没有。醒时次数不加，报酬不加厚。
