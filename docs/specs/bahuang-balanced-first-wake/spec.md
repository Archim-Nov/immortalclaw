# 八荒均衡也先停下一次

## Summary

八荒仍从原来的门进去。门票、境界、感应、贡献、入口时辰、撤出扣石和奖励表都不改。走进去以后，稳妥、均衡、凶猛的第一步都会打开一处岔路。后面的岔路仍按原来的机会出现，一趟仍最多三处。荒尘驿、断碑原、无灯壑各再多一处中文场面。

## Problem

凶猛进八荒时，还没有岔路就会先停一次。均衡每一步只有大约四分之一的机会停下，稳妥更低。人常常还没看见岔路，行动列表里就只剩撤出。场面本身已经写好了，缺的是第一次没有抽中。

## Goals

- 还没遇到过岔路时，下一步深度一定会打开一处岔路，稳妥、均衡、凶猛都一样。可以是这一段的场面，也可以是同一段里的见面。
- 已经停过以后，仍按原来的概率再抽。一趟仍最多三处。
- 时辰到了仍不代选，也不把这一步没选的灵石或干粮放进袋子。
- 荒尘驿、断碑原、无灯壑各再加一处三到四个中文做法的场面，效果种类仍用现成的那几种。

## Non-Goals

- 不改进门消耗、八荒令、入口时辰、撤出扣石和每步奖励。
- 不把后面每一步都改成必停。
- 不改归虚、荒野层和地宫守关。

## User-Visible Behavior

人以均衡走进八荒。深度往前走了一步，还没撤出，行动里就有这一处的中文做法，旁边仍有撤出。稳妥偏守也是这样。做法和场面都是中文，不写行动标识。

后面如果没有再抽中，人可以继续走，直到最多三处岔路用完。

荒尘驿多一处石堆，断碑原多一处杆子，无灯壑多一处凉石头。每处仍点出这一段的状态和跟着的东西。

## Constraints

- 玩家看见的岔路、标签和说明不写英文句子。
- 时辰到了的岔路不得套用选项效果。
- 一趟的岔路总数仍不超过三次。

## Acceptance Criteria

- 均衡进门后，世界至少往前走一步，深度已经增加，人还在八荒里，`pendingWakeNode` 已经有值。稳妥偏守同样。
- 这一处的场面和做法是中文，行动列表里有对应的抉择，标签也是中文。
- 每段预览仍是三到四个做法，并且比改之前多一处本段场面。
- 原来的见面、避开、时辰到了不发灵石，以及一趟最多三处，仍然通过。

## Open Questions

- 没有。后面的概率保持原样。
