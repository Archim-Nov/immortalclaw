# 甲级带出按气质分池

## Summary

甲级撤出或走完时，旁支不再是同一份清单。这一层的气质（丹霞、火毒、阵纹）决定带出哪一件，层数和是否走完决定份数，中途的走、帮、险会少带、换一种或再多一份。件数先入包，再写进战报。

## Problem

丹霞露和主材料已经和袋子对齐，但旁支仍薄。丹霞、火毒、阵纹这三池只出现在中途句子里，撤出或走完时看不出这一趟沾的是哪一种。走完和中途撤出的差别，也常常只剩一份故事遗物，摘要读起来像同一张单。

## Goals

- 甲级按层数落入丹霞、火毒、阵纹其中一池。中途岔开的闲事只从这一池里抽。
- 撤出或走完时，这一池的专属物真正进袋子，并写进 `lastReport.secondaryDrops`、`secondaryDropCards` 和见闻。一到三层是丹霞余砂、火毒凝滴、阵纹残片轮着来，四到六层、七到九层仍是这三件，句子里带上婴火莲池或神纹天隙，走完的份数更多。
- 中途至少一类抉择会改带出。险多一份，帮换成下一池的那一件，走少一份并把身上的伤按下去两刻。
- 走完比同样抉择下的中途撤出份数更多。摘要能读出「走完」和「中途撤出」。
- 战报上的份数等于这一趟袋子里的增量。没有进包的东西，摘要里不写带回。

## Non-Goals

- 不改乙级的遇敌、机缘、口角和组队人情，不把组队投票从十刻改回去。
- 不改金灵花只计真正入包的主材料，也不改撤出或走完时先入账再写报的丹霞露、养魂砂、神纹尘和来源物。
- 不把这三件卖到坊市，也不拿它们代替闭关灵材或甲级故事遗物。
- 不新开地宫，不增加醒时次数，不改三十刻。
- 放弃和被抬出来不发这一池的专属物。

## User-Visible Behavior

金丹走甲级一层，气质是丹霞。中途的闲事是丹炉、丹方或壁上的露。中途撤出，袋子里多一份丹霞余砂，战报旁支和见闻都写这一份。走完同一层，是两份。四层走完是三份丹霞余砂，句子里是婴火莲池。七层走完是四份，句子里是神纹天隙。

二层是火毒凝滴，三层是阵纹残片。门口的收获提示里也能看见这一层的那一件。

中途选了险，撤出或走完时再多一份。选了帮，旁支换成下一池的那一件，份数不变。选了走，份数少一，身上若有伤就按下去两刻。这一择当时就写进见闻，东西在撤出或走完时才进袋子。

金灵花仍只在真正进包时出现在主材料上。丹霞露、养魂砂、神纹尘仍在撤出或走完时入账，份数和战报一致。

## Constraints

- 专属物是物品目录里的 `ItemId`，坊市不收。
- 入账发生在写 `lastReport` 之前，和丹霞露同一段。
- 玩家看见的句子里不夹行动编号。
- 旧存档没有气质字段时，按层数再算。

## Acceptance Criteria

- 甲级一层、二层、三层撤出，旁支分别是丹霞余砂、火毒凝滴、阵纹残片，份数和袋子增量一致。
- 同一层走完的份数多于中途撤出。四层、七层走完又多于一层走完。摘要能读出走完和中途撤出。
- 选险以后份数比不选多一。选帮以后旁支换成另一件。选走以后份数少一，有伤时伤刻减少。
- 战报每一件的份数等于这一趟袋子里的正向增量。金灵花为 0 时摘要不写带回金灵花。丹霞露仍在。
- 乙级撤出不获得这三件。乙级中途和组队投票的既有测试仍过。
- `npx tsc -p tsconfig.json --noEmit` 通过。

## Open Questions

- 没有。这三件不参与闭关，也不代替走完才有的那一份故事遗物。
