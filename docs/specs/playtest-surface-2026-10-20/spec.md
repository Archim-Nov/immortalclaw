# 2026-10-20 试玩：名字、关系句、任务名和任务去向

## Summary

墨儿在青岚城试玩时，同一个人在请托卡上换成了另一个中文名，关系句在「嫌隙」上叠了一次字，告示上的两桩高风险事务用了内部说法，接过的任务从状态里消失，做完也没有一句结果。这一轮把这四件事补到代理人能读的字上。

## Problem

cultivator-5 的存档名字是 Luna。攀谈、赠礼、待客、组队、切磋、`socialLinks` 和 `nearbyCultivators` 都写 Luna。请托卡走 `facingPersonName`，把 Luna 换成苏青萝。城里另有一位修士叫青萝，两张卡对不上人。悬赏委托人的名字也走了同一套转换，和旁边的人用的不是同一个字。

`describeArcLine` 在好友且有嫌隙时写成「可嫌隙到了嫌隙」。等级名本身就是嫌隙，句子变成空话。宿怨塞进同一句，会写成「嫌隙到了宿怨」，等级也对不上。

告示上的 `strong-event-quest` 给人看的名字是「强事件线索」，`state-elite` 是「州内精英任务」。这是设计稿里的说法，不像城里贴出来的事务。

接下两桩以后，`GET /agent/state` 不带已接任务。执行强事件线索的四刻里，另一桩的执行卡也不在行动列表里。做完以后游记、`recentEvents` 和摘要都没有结果，灵石变了却对不上是哪一笔。失败会把 `injuryTicksRemaining` 抬高，`status` 变成 injured，但没有调用带伤同步，`statusEffects` 是空的，也没有一句说为什么受伤。人在城里有伤时，行动列表在列出已接任务之前就返回，调查寻访像是丢了。

`recentEvents` 取的是 `worldEvents` 里本人或没有主人的最近五条。请人进府和游商暗仓本来就写游记，不写世界事件。任务结算原先两边都不写，所以这一轮之后 `recentEvents` 停在旧时辰。

## Goals

- 同一位修士在代理人能看见的字里只用存档里的那一个名字。请托、应下、办完、悬赏委托人和旁边的人、关系列表用同一个字。
- 关系句在无嫌隙、嫌隙、宿怨下都读得通，等级名不在同一句里叠成「到了嫌隙」。
- 玩家看见的事务名改成城里的说法。`strong-event-quest` 显示为凶险传闻，`state-elite` 显示为州府急务。动作 id 和类型 id 不动。旧存档里已经写下的这两个旧名字，读出来也用新名字。
- `state.activeQuests` 在还有未做完的事务时列出名字、在哪接下的、做完要几刻、会不会自己过期。做不了时用一句中文说明原因。
- 事务做成或没做成，游记、摘要和 `recentEvents` 各留一句中文，写出灵石增减。挂了伤要写还要养几刻，并和 `statusEffects` 里的带伤对上。
- 身上有伤时，已接事务的执行卡还在，说明就是那句原因。交上去不开始做，回执复述同一句。

## Non-Goals

- 不改请托、事务报酬、成功率和伤势数值。
- 不改存档里的 `name` 字段。
- 不把请人进府、游商暗仓补进 `recentEvents`。这两处已经写在游记里。
- 不给已接事务另加过期时限。告示上的帖子仍按原来的间隔换，接下以后留到做完。
- 不改任务 id，也不部署。

## User-Visible Behavior

站在 Luna 旁边请她守关，卡是「请托：Luna守关」。旁边的青萝仍是「请托：青萝守关」。Luna 贴出的悬赏，接受卡和 `localCommissions.posterName` 都写 Luna。关系列表和旁边的人也写 Luna。

墨儿与 Luna 已是好友、嫌隙到了嫌隙这一档时，关系句写成两人之间有了嫌隙，不再出现「嫌隙到了嫌隙」。宿怨、点头之交、知己的句子各自把等级说全。

告示上接下的卡是「接下：凶险传闻」「接下：州府急务」。摘要写「接下了凶险传闻」，不写强事件线索。

两桩都接下以后，状态里能看见它们，并写明是在青岚城接下的，人在这里就能做，做完要几刻，不会自己过期。正在做的那一桩写正在做。另一桩在这一趟没结束前写明要等这一趟结束。做完或没做成，游记、摘要和最近事件都有一句结果，里面有灵石的增减。没做成并挂伤时，状态是 injured，`statusEffects` 里有带伤，剩余刻数和那句「还要养」一致。另一桩还在，卡和状态都写身上有伤、养好了再做。把这张卡交上去，回执是同一句，事务不开始。

## Constraints

- 动作 id 仍是 `quest:accept:<type>:<index>` 和 `quest:execute:<type>:<index>`。
- 给人看的新句子是完整中文，不写动作 id，不写英文字段名。
- 任务标题里夹着的拉丁词仍换成中文。那是标题里的词，不是某位修士的存档名。
- `recentEvents` 仍只取世界事件，最近五条，本人或没有主人的。

## Acceptance Criteria

- Luna 的请托卡、悬赏卡、`socialLinks.targetName`、`nearbyCultivators.name` 都是 Luna，不含苏青萝。青萝的请托卡仍是青萝。
- 无嫌隙、嫌隙、宿怨各自配上点头之交、好友、知己和没有交情，关系句都不出现「到了嫌隙」或「到了宿怨」。嫌隙这一档的句子里「嫌隙」只出现一次。
- 新告示和旧存档里的强事件线索、州内精英任务，给人看的名字是凶险传闻、州府急务。类型 id 不变。
- 接下两桩后，状态里有这两桩。执行凶险传闻并失败后，游记、摘要和 `recentEvents` 写出没做成、少了多少灵石、还要养几刻。带伤的剩余刻数与这句话一致。调查寻访还在，卡和拒绝回执都说明身上有伤。
- 做成时，同一处写出得了多少灵石。
- 相关领域测试和类型检查通过。
