# 甲级秘境的守关

丹霞内府、婴火莲池、神纹天隙已经按境界开门，也各自掉自己的灵材。这一轮只把守关打出差别：三处的怪、状态和失败代价不一样，丙级和乙级仍是练手。

## Summary

甲级守关按秘境加重，并且各有一种已经存在的战斗状态。丹霞内府贴焚灼，婴火莲池抽灵力并挂幻惑，神纹天隙用镇压压出手和先手。层数越高，血量和伤害涨得越明显，防御涨得少一些，避免只剩一堵血墙。中后段一个人或没配齐的队伍很难清。五人分好护、控、破、输出、辅助，才是走法。输了或者逃走会挂伤、掉灵石，神纹天隙还会乱一阵气息。代理人在 `realmPath`、`dungeon.advice` 和每层的 `mysteryLine` 里读到完整的中文提醒。

## Problem

甲级九层的守关仍然是同一套守卫按层数把威胁值加上去。秘境的名字已经分开，打起来却差不多。

- 丹霞、婴火、神纹的怪是同一套体型和同一套招，只是后面的更厚。
- 失败和逃走的代价没有跟着秘境变。高层撤出来，往往只是轻伤，摘要里也没有能拿去讲的句子。
- 代理人看得到去哪一层拿材料，看不到这一层的守关会怎样压人。

## Goals

- 丹霞内府（甲级一到三层）的守关偏压和焚灼。火会在回合结束时继续烧。
- 婴火莲池（甲级四到六层）的守关抽灵力，并挂幻惑。主守会用生息把灵力补回来。
- 神纹天隙（甲级七到九层）的守关用镇压压低伤害和先手。侧翼里有封架的，也有抢先手的。
- 三处都是三只一组，但从者的体型、打法和状态不同。血量和伤害随层数明显上升，防御升得慢。
- 中后段单人很难清。五人分好角色，仍是打算让人打过的路。
- 在这些层输了或逃走，人会挂伤，灵石会掉。婴火莲池额外抽走灵力。神纹天隙会留下一段走火。摘要里能读到一句完整的话。
- 队伍战打成平手时，甲级伤势沿用逃走的时长。灵石、走火和摘要句子仍只在输了或逃走时结算。
- `state.dungeon.advice`、甲级 `rankYieldHints.mysteryLine` 和 `realmPath` 用完整中文写出这一层的提醒。丙级、乙级的提示仍说这里是练手。
- 丙级、乙级的守关人数、血量和伤害公式不变。秘境的进门境界也不变。

## Non-Goals

- 不新开地宫入口，不改丙级、乙级的探宝和进门。
- 不另做一套状态或另一套回合。甲级威胁用现成的焚灼、幻惑、镇压和生息。
- 不改队伍人数、角色、疗伤和伤了就不能进地宫的规则。
- 不改丹霞露、养魂砂、神纹尘的掉落和闭关加成。

## User-Visible Behavior

金丹前期站在甲级门口，仍只能进丹霞内府。守关是三只，主守压人，炉卫和余火贴焚灼。一个人还能试。输了会挂伤，也会掉一些灵石。

金丹后期进婴火莲池。守关会抽灵力，幻惑让下一击发飘，主守自己还会把灵力补回来。单人很容易被耗死。五人里要有人护、有人补、有人破防。逃走也会挂伤、掉灵石。

元婴后期进神纹天隙。镇压压住出手和先手。输了或逃走，伤更重，灵石掉得更多，气息会乱一阵。五人把护、控、破、输出、辅助都带上，才是这里的走法。

丙级和乙级的守关和以前一样。炼气的 `realmPath` 仍然不提这三处秘境。

## Constraints

- 状态的数值用现有状态表里的档位，不另写一套伤害公式。
- 旧存档没有新字段。`advice` 是读状态时现算的。
- 直接挑战守关的旧回合，甲级会换成这一秘境对应的法术，好让同一套状态挂上去。远征里的队伍战才是代理人平常打到的那一仗。

## Acceptance Criteria

- 丙级一层仍是一只精英，血量沿用原来的公式。乙级一层仍是三只，血量也不吃甲级这套加成。
- 甲级一层的守关比不加秘境系数时更厚，九层又比一层厚。九层的攻击涨幅大于防御涨幅。
- 丹霞的战报里能看见焚灼，婴火能看见幻惑，神纹能看见镇压。
- 同样的种子下，婴火和神纹的单人胜场少于五人队伍。丙级一层的单人仍然打得过。
- 神纹守关打输，伤、灵石和摘要句子都在。丙级打输不会掉这份额外的灵石。
- 甲级平手的伤势时长等于同层逃走。打赢的甲级伤势底线仍是零。丙级平手不加这份额外伤。
- 金丹后期的 `realmPath` 和甲级四层的 `mysteryLine` 都写到婴火莲池的危险。炼气的 `realmPath` 不出现神纹天隙。

## Open Questions

- 没有。化神后期之上这一轮不加境界，也不新开地宫入口。
