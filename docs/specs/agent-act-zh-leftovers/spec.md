# 动作回执上剩下的英文

## Summary

#42 把赠礼卡换成了中文物品名。再浸泡一次，礼送出去以后的回执仍是 `gifted`、`qi-pill` 和 `Affinity`。人还在做事时提交别的动作，拒绝也还是 `Cultivator is busy with an active job`。这一轮只换这几句给人看的字。

## Problem

`send-message:<id>:gift-item` 成功以后，摘要写成「墨儿 gifted 1 qi-pill to 青萝. Affinity +21.」。卡面、游记和道录已经用回气丹。好感的数字没变，只是回执还夹着英文。

同一段传话里，问候、分享、求助和门口那三句的回执仍是 `sent greet` 这一类。看消息的回执仍是 `read N messages`。

`requireIdle` 拦的是自己手头还有事，不是对方正忙。实机看到的那句英文属于这一处。向一个正在做事的人下挑战书，另有一句 `Target is busy with an active job`。

## Goals

- 赠礼回执用中文物品名，并写出好感增减。行动 id 仍是 `gift-item`。
- 同门仍是好感 +21，其他人仍是 +15。嫌隙和宿怨的句子不动。
- 问候、分享、求助、门口传话和看消息的回执改成中文。
- 自己正忙时的拒绝改成中文，并仍点出 `abort-dungeon-expedition`。
- 向正忙的人下挑战书、应战时对方已经开工、同行的搭档正忙，这几句拒绝也改成中文。

## Non-Goals

- 不改赠出哪一件、好感、嫌隙和宿怨的结算。
- 不改地宫、宗门场面、字条和职务超时。
- 不把切磋、组队、委托里其余仍是英文的回执放进这一轮。

## User-Visible Behavior

身上有回气丹时，送给青萝，回执是「墨儿送了1个回气丹给青萝。好感+15。」同门则是好感 +21。物品名跟目录里的中文名一致，符和碎片也用「个」，不把丹药单独改成「颗」。

自己还在打坐或走地宫时再提交别的动作，拒绝是「你正忙着，手头的事还没做完。」地宫还在走时，这句话会点出 `abort-dungeon-expedition`。向一个正在做事的人下挑战书，拒绝写那个人的名字，并说改日再来。

## Constraints

- 物品 id 和行动 id 不改。
- 地宫中止的行动 id 留在拒绝里，代理人仍能照着提交。
- 自己正忙不要写成「对方正忙」。那一句指的是提交动作的人。

## Acceptance Criteria

- 赠礼回执含中文物品名和「好感+15」或「好感+21」，不含 `gifted`、`Affinity` 和物品 id。
- 问候的回执是中文，并写出好感 +3。
- 自己有进行中的事情时，拒绝含「你正忙着」，不含 `Cultivator is busy`。地宫进行中时仍提到 `abort-dungeon-expedition`。
- 向正忙的人下挑战书，拒绝含对方的名字和「正忙着」，不含 `Target is busy`。
- 相关领域测试通过。
