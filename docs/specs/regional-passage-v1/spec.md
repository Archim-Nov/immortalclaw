# 九州主题洞的两步

## Summary

九州九处主题洞仍从原来的门进去，名字、境界、潮汐、冷却和签名物都不改。进门以后先有一步探路见闻，再有一步遇敌或人情，然后才是原来的收束选择。散修旧洞、游商暗仓、古修闭关室仍是一次抉择。

## Problem

州府秘境已经有门口身份、侧室和更里面的一间，可是主路仍是选一次就结束。代理人能说出青岚药窟在青州，说不出这一趟里先看见了什么、碰上了谁。

## Goals

- 九处主题洞各有两步可玩内容，加上原来的收束，一共至少三步。
- 第一步是探路，写下中文见闻，不结束这一趟，也不把签名物放进袋子。
- 第二步要么打出中文敌人名，要么在有同队的人时记下人情或分赃。
- 走完和中途退出的摘要不一样。走完才把签名物放进队长的袋子。
- 文案不出现行动编号。

## Non-Goals

- 不改丙、乙、甲的层、守关、中途见闻、遗物和组队十刻投票。
- 不改三处短洞的一次抉择。
- 不改签名物、潮汐、冷却、侧室和更里面那一间的计票。
- 探路、遇敌或人情还开着时，收束不出现在行动里，直接提交也被拒绝，签名物不进袋子，这一步留在原地。时辰到了同样不跳到收束。侧室和更里面的房间跟收束一起，等这两步走完才出现。走完一步，选择时辰按原来的两刻重新算，差事跟着这一窗走。队列空了以后，超时才走稳的收束，手动收束也可以结束。没走完的步不会被自动补成收束。散修旧洞、游商暗仓、古修闭关室没有这两步，进门仍能直接收束。

## User-Visible Behavior

站在主题洞里时，`state.regionalDungeons.active.passage` 写出当前这一步：第几步、共两步、是探路、遇敌还是人情、一句场面，以及三个中文做法。`regional-choice:<optionId>` 回答这一步。一个人自己就能定。同队要超过一半才锁，锁不上就只记下谁先说了。

答完第一步，第二步才出现。这两步还开着时，行动列表里只有当前这一步和退出。`active.options`、`active.interior`、`active.deeper` 先空着。收束、侧室、更里面的做法即使直接提交，也会被拒绝，句子是路还没走完，不出现行动编号。答完第二步，`passage` 为空，收束、侧室和更里面的房间一起出现。

进门以后若一直不选，刻数过了原来的期限，人仍停在当前这一步，签名物不进袋子，差事也不结束。走完一步，这一窗从这一刻再算两刻。两步都走完以后，再空过这两刻，才自动走稳的收束，签名物这才进袋子。手动选收束也可以结束。青岚药窟那一边是等露，茶桥旧席那一边是入席，听潮钟窟那一边是绕开钟。主题洞的 `choiceTicks` 和 `durationTicks` 不加长，短洞的一次抉择仍按原来的时辰收束。

遇敌的名字是：青岚药窟露虫，听潮钟窟潮蛭，栈云断索藤雀，衡碑试衡衡卒，焦雷祭坛焦雷虫，盐风沉舶盐蟹。打赢或打输都把这个名字写进最近的战报。这一场不发签名物。

茶桥旧席、猎霜夜巡、砂门闭关的第二步是人情。把东西让给同来的人，会记下一句原因，例如把席上的茶让给我。自己拿走会在双方加上三分怨，还没到嫌隙。旁边没有别人时，这两句只写成把东西留下或自己收着，不欠人情。

中途 `leave-regional` 仍是退出。青岚药窟退出写瓶子是空的，走完等露写青岚露芯进了袋子。两句对得上，也分得开。

## Constraints

- 战斗沿用现有回合战，敌人比收束那场薄。
- 人情沿用现有的欠人情记录，原因是中文短句。
- 旧存档没有 `passageIndex` 时，从探路这一步算起。

## Acceptance Criteria

- 九处主题洞都有探路，再加遇敌或人情。三处短洞没有这两步。
- 青岚药窟可以先看路、再打露虫、再等露。露芯在等露之后才进袋子。打露虫时战报里的名字是露虫。
- 探到一半退出，摘要是瓶子是空的，袋子里没有露芯。
- 茶桥旧席同队把茶让出去，会记下把席上的茶让给我。旧茶纹要等入席才进队长的袋子。
- 见闻、战报和摘要是中文，不出现行动编号。
- 推进到期限时，青岚药窟仍停在探路，不发露芯。再空等若干刻也一样。走完探路和露虫以后，先空过一刻还不收束；满两刻才走等露，露芯进袋子。茶桥旧席同样先停在探路，走完茶渍和让茶以后，超时才入席。
- 进听潮钟窟时，行动里只有沿水线这一步和退出。绕开钟、敲钟、潜入，以及侧门和更里面，都不列出。这时候直接绕开钟会被拒绝，潮钟碎片不进袋子，人还停在探路。走完探路、潮蛭还在时，绕开钟仍被拒绝。两步都走完以后，绕开钟才把碎片放进袋子。再空等满两刻，超时也会把碎片放进袋子。
- 原来的州府秘境测试仍通过。`tsc -p tsconfig.json --noEmit` 通过。

## Open Questions

- 无。差事在探路没走完时不会自己结束，所以拒绝提前收束不会把这一趟卡死。退出仍可随时走。
