# 地宫表面和侧室超时

## Summary

丙级地宫回来以后，给人看的句子用中文物品名和地名。同队进州府秘境时，队长已经选过的侧室不会在超时时被稳的那一间盖掉。行动卡上还露着英文的路程、进地宫和荒野入口，改成和其余卡片一样的中文。

## Problem

实机浸泡以后，`lastReport.summary`、游记和摘要里仍能看见 `cloud-heart-grass`、`ruin-fragment`、`yangzhou:main-city`，以及 `(completed rank 1 balanced)`。州府秘境的侧室和签名选择共用一个时限。队长选了侧室、同伴没投票，窗口关上时会改写成稳的那一句。`/agent/actions` 里还有 `Travel to`、`Enter dungeon` 和 `Consumes no ticket`。

## Goals

- 战报摘要、游记、六个时辰的摘要和同类给人看的句子，用物品和地点的中文名。
- 状态里的 item id 和 location id 保持原样。
- 侧室没人投出多数时，若队长已经投过，就留下队长那一句。谁都没答，仍写稳的那一句。
- 签名选择超时仍走稳的那一边。掉落、战斗和冷却不变。
- 前往、进地宫、地宫远征、走进荒野、进八荒的卡片用完整中文，不中英夹杂。

## Non-Goals

- 不加新的地宫内容，不改层数、守关、掉落和姿态结算。
- 不把同队地宫第三、六、八步的超时从稳的那一边改掉。
- 不把其余仍是英文的系统卡，例如治疗和切磋，放进这一轮。

## User-Visible Behavior

走完丙级以后，摘要写「云心草」「残碑碎片」和「青岚城」或「广津城」这一类名字。`primaryMaterial.itemId` 和 `returnLocationId` 仍是内部 id。

两个人进散修旧洞，队长选「抽一页能看的」，同伴不投。两刻以后游记和摘要里是「有一页还没烂」，不是「没有翻」。只有同伴投了冒险的那一间、队长没投，仍写「没有翻」。两人投了同一间，仍当场锁上。签名选择没锁时，仍走撬开那一边。

站在城里，去东镇的卡片写「前往」。站在坡上，进荒野的卡片写不消耗入场符，以及这一层能撑几刻。地宫门口的卡片写「进丙级地宫」和「地宫远征」，姿态用稳妥、均衡、冒进。

## Constraints

- 远征步骤内部仍用原来的任务标记判断要不要另结算甲级失败，避免同一场守关扣两次。
- 侧室的报酬仍是原来的几枚灵石、一点名声或一点气血，不另加。

## Acceptance Criteria

- 丙级战报摘要、地宫归来的游记和六个时辰的摘要里没有带连字符的物品 id、没有 `州:地点` 这种 location id，也没有英文括号结果。摘要里能读到云心草和回来的城名。
- 队长的侧室选择在同伴弃权超时后仍在游记和摘要里。只有同伴投票时，超时仍是稳的那一句。
- 相关领域测试通过。
