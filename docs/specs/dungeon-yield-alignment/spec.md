# 地宫预估和实际掉落对齐

## Summary

甲级门口说这一趟能带回几份金灵花，走完却经常是零。乙级、丙级用的是同一套预估，主材也经常对不上。战报前半是整趟总账，后半又把最后一场的「带出何物」写成另一套数字。同一趟里，同一条见闻会再出现一次。

## Problem

门口的 `estimatedExpeditionYieldByPolicy` 按主材份数写死一个区间。实际探宝和守关各自从破境池里均匀抽一件，金灵花只是八件里的一件，所以均衡走完甲级一阶，主材计数可以是 0。境界路线和突破来源又说这些材料就在这一层。玩家按门口的话跑完三十刻，袋子里没有卡破境的那一件。

战报摘要先写整趟的残碑碎片和灵石，再原样贴上最后一场胜仗的「带出何物」。两套数字读起来像两笔总账。见闻从固定句子里有放回地抽，同一句会在一趟里出现两次。

## Goals

- 门口预估和远征掉落用同一张表。走完一趟，主材份数落在这张表的区间里；不够下限时，结账补到下限。
- 甲级一到三层的主材是金灵花，四到六层是婴火莲，七到九层是神念晶。乙级仍是玄英石，丙级仍是云心草。
- 金丹前期、中期在境界路线和突破来源里读到的地方，和门口说的是同一处。
- 战报开头是整趟总账。最后一场的收获若还要写，就写明是哪一场，并且已经算进总账。
- 同一趟不重复同一条见闻句子。

## Non-Goals

- 不改归虚。
- 不改传音、攀谈、agentGuidance，也不改地宫抉择回执里超时那句「时辰到了，代选了」。
- 不改单次探宝、单次守关在远征之外的随机池。
- 金灵花仍然只按真正进包的数量记在主材上。没进包就不写带回。
- 中途撤出、被抬出来，不按走完的下限补发。

## User-Visible Behavior

金丹站在甲级一阶门口，均衡那张卡仍写大约带回 3 到 4 份金灵花。走完这一阶，袋子里的金灵花不少于 3，也不超过这一档的上限，除非路上另有事件多给。战报主材份数和袋子增量一致。

甲级四阶的卡写婴火莲，七阶写神念晶，份数仍是原来那张表。乙级写玄英石，丙级写云心草，走完同样落到表上的区间。

战报前半是这一趟一共带回多少。若后面还提最后一场胜仗带出的碎片和灵石，句子里能看出那是这一场，并且已经算进上面的总数。同一趟的 beats 里，同一句见闻只出现一次。探路、歇脚、侧室这种按步换第二句的，标题可以再出现，句子本身不重复。

## Constraints

- 玩家看见的句子保持中文、修仙口吻。
- 主材 id 仍留在 `primaryMaterial.itemId`，中文名在 `itemName`。
- 撤出或走完时先入账再写报。补到下限也发生在写报之前。

## Acceptance Criteria

- 甲级一阶均衡走完，金灵花不少于门口写的下限，并且和袋子增量一致。
- 预估区间和远征抽卡用同一个函数。甲、乙、丙走完十个给材料的步，主材份数落在该函数给出的区间里。
- 战报里整趟总账和最后一场的份数不再各说各的。
- 同一趟不重复同一条见闻句子。
- 现有领域测试和 `tsc --noEmit` 通过。
