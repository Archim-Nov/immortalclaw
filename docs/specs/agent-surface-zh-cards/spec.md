# 动作卡上还露着的英文

## Summary

#45 和 #46 把突破、切磋、赠礼回执和正忙拒绝改成了中文。再看一遍动作卡，问候、分享和求援仍把英文种类写在括号里，说话和回话的说明还在教 `act` 和 `line`，请托、悬赏和任务标题里也会把 Emma 这种英文名字直接接在「守关」前面。这一轮只改这些给人看的字。

## Problem

`send-message:<id>:greet`、`share-info`、`request-help` 的卡面写成「发送消息（greet）：某人」。动作 id 本来就带着种类，卡面再写一遍英文，读起来像接口说明。

`say` 和 `reply-line` 的说明写成「act 的 body 可带 line」。字条的回信和留话也是这一句。代理人要交的仍是那一句短话，说明不必把字段名再念一遍。

请托守关的标签是「请托：人名守关」。人名若是 Emma，或是登记时用的 Lin Yuelan 这一类英文桩，卡上就变成 Emma守关。任务标题和悬赏委托人若存的也是这个英文名，接下和接受的卡会照样显示。

## Goals

- 问候、分享见闻、求援三张卡的标签和说明用这三个中文名。动作 id 仍是 `greet`、`share-info`、`request-help`。
- `say`、`reply-line`，以及同一句接口腔的回字条、留字条，说明只说最多四十字、不另写就代说。不再出现 `act` 和 `line`。
- 请托、任务和悬赏卡上的英文人名改成中文显示名。Emma 显示为艾玛，Lin Yuelan 显示为林月兰。没有对上的英文名也换成一个稳定的中文名。已经是中文的名字不动。

## Non-Goals

- 不改好感、人情、任务报酬和悬赏结算。
- 不改角色存档里的名字，附近的人、游记和摘要仍用原来的名字。
- 不改 `POST /agent/act` 上可选的 `line` 字段。技能说明里仍可以告诉代理人这个字段。

## User-Visible Behavior

站在青萝旁边，三张传话卡是「发送消息（问候）：青萝」「发送消息（分享见闻）：青萝」「发送消息（求援）：青萝」。说明里也是问候、分享见闻、求援。

对她说话，说明写最多四十字，不另外写就代说一句。她先说了一句之后，回话的说明同样不提接口字段。

请 Emma 守关，标签是「请托：艾玛守关」。请 Lin Yuelan 守关，标签是「请托：林月兰守关」。请青萝守关，仍是「请托：青萝守关」。任务标题若存成 Emma守关，接下的卡是「接下：艾玛守关」。Emma 贴出的悬赏，接受卡写艾玛，不写 Emma。

## Constraints

- 动作 id、物品 id 和角色 id 不改。
- 中文名只出现在这几张卡的标签和说明上。结算句子继续用角色自己的名字。

## Acceptance Criteria

- 三张传话卡的标签含问候、分享见闻、求援，不含 `greet`、`share-info`、`request-help`。动作 id 不变。
- `say` 和 `reply-line` 的说明含「四十」，不含 `act` 或 `line`。回字条和留字条同样不含这两个词。
- Emma 的守关请托、Emma守关的任务标题、Emma 的悬赏卡都不含 Emma。Lin Yuelan 的守关请托显示林月兰。青萝的请托仍写青萝。
- 相关领域测试通过。
