# 甲级进门到守关之间

## Summary

金丹第一次走丹霞内府时，均衡和冒进常常在第一步就撞上守关。甲级守关会挂伤，远征随即撤出，所以整段中途只看得到撤退。门口同时列着 `enter-dungeon` 和 `start-dungeon-expedition`，两张卡开的是同一趟三十刻的远征。

## Problem

乙级没开过的一层，探路、侧室和第三步的岔路会先出现，守关在后面。甲级用的是同一套步数和醒时，并没有把中途关掉。差别在抽步：这一阶还没开过时，每一步都可能直接守关。甲级守关输了或撤出会挂伤，均衡和冒进因此在第一步结束，醒时和 `choose-event` 都还没排上。

门口的两张卡标签不同，行为相同。代理会把它们看成一先一后的两道门。

## Goals

- 甲级还没开过的那一阶，前三步先探路。侧室或岔路排在守关前面，仍用现有的醒时和事件卡。
- 醒时仍最多三次，超时仍是十刻。第三步仍是伤者。
- 门口只列出 `enter-dungeon`。`start-dungeon-expedition` 仍能开同一趟，只是不再列在门口。
- 进门卡写明三十刻、这一阶的收获，以及甲级门口那一阶会先走路再守关。句子是中文，不带行动编号。

## Non-Goals

- 不改甲级守关的血量、从者和挂上的状态。
- 不改乙级、丙级的抽步。已经开过的甲级层仍整趟探路。
- 不新做一套中途状态。不增加醒时次数，不把三十刻改长。
- 不删掉 `start-dungeon-expedition` 这个编号。旧的调用还能进。

## User-Visible Behavior

筑基站在丹霞内府门口，仍只有进不去的那一张卡，句子里有丹霞内府、金丹和丹霞露。

金丹在同一门口看到三张进门卡，姿态是稳妥偏守、均衡、凶猛偏攻。旁边不再有另一套远征卡。卡上写着三十刻，以及这一阶还是门口时，进门以后先走一段，岔路和侧室在守关前面。

金丹用任一姿态走进还没开过的甲级一层，第一步之后行动列表里除了撤退，还有事件卡或地宫抉择。守关排在这张卡之后。抉择仍是中文。醒时若出现，超时仍是十刻。

## Constraints

- 前三步固定探路只加在甲级、且这一阶还没被本人开过的时候。`chooseDungeonExpeditionStepKind` 仍是唯一的抽步处。
- 侧室仍走事件池，岔路仍走 `dungeon-wake-decision`，超时仍是十刻。
- 玩家看见的句子里不夹行动编号。

## Acceptance Criteria

- 筑基在 `yangzhou:dungeon-a` 看到 `dungeon-gate-locked`，行动列表里没有 `enter-dungeon`。
- 金丹在同一门口能看见 `enter-dungeon:rank-1` 的三种姿态，看不见 `start-dungeon-expedition`。直接提交旧编号仍能开同一趟。
- 金丹以均衡或冒进走进还没开过的甲级一层，在守关之前，行动列表里至少有一张不是撤退的抉择或事件卡。
- 甲级前三步的抽步结果是探路。乙级第一步仍可以抽到守关。
- 领域测试和 `npx tsc -p tsconfig.json --noEmit` 通过。

## Open Questions

- 没有。两套门口不再并列表，旧编号保留给已经发出去的调用。
