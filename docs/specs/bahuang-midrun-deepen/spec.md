# 八荒中途再厚一层

## Summary

八荒仍从原来的门进去，门票、境界、荒野感应、贡献和入口时辰都不改。走进去以后，荒尘驿、断碑原、无灯壑各自有自己的中文岔路和见闻。同一带里如果还有另一个正在走八荒的修士，会停一次见面：避开、攀谈，或者交手。交手走城里切磋已经在用的技能对决，不另做一套只扣压力的假打。时辰到了不代选，也不把这一步没选的灵石放进袋子。

## Problem

八荒的门票和三段地名已经能用。中途仍是同一套深度、匣子、险廊、撤退、脚印、灭火，只在句子前面加上地名。荒尘驿的断法、沙客、尘骑，断碑原的定根、碑影、碑仆，无灯壑的幻惑、灯烬、壑影，没有各自的岔路。两个人同时在八荒里，也碰不见，更不能交手。城里的 `challenge-cultivator` 是另一张卡，进不了这一趟。

## Goals

- 三段各有自己的中文岔路，场面里点出这一段的状态和跟着的东西。一趟仍最多三处岔路。
- 见闻仍隔几步写一次，句子比原来多几句，仍用这一段的名字。
- 另一个修士也在同一段里走着，下一次岔路可以是见面。避开留下见闻，不打。攀谈在没有嫌隙或宿怨时加一点好感。交手用现成的技能对决结算，两边的 `recentCombats` 都留下这一场的 `combatRounds`。
- 时辰到了，岔路关掉，写一句时辰到了。不代选，不发这一步的灵石，也不替人交手。
- 进门、耗门票、撤出扣石、`state.bahuang` 和 `state.wildRoute` 的三段建议保持原样。门口拒绝的句子改成中文。

## Non-Goals

- 不改归虚，也不改荒野层的两步岔路。
- 不改八荒的深度上限、压力、干粮和撤出扣的那一笔灵石。
- 不把见面做成城里那种要对方先接挑战书的差事。人已经在同一段里，选了交手就当场结算。
- 不改观众页，也不改地宫守关。

## User-Visible Behavior

人在荒尘驿停下时，岔路写沙客、尘骑和断法。走到断碑原，写碑影、碑仆和定根。走到无灯壑，写灯烬、壑影和幻惑。每处三到四个中文做法。选了会摸到灵石的那一个，灵石这时才进袋子。摘要是中文。

时辰到了还没选，游记写这一处没选，东西没有进袋子。灵石不因这一步增加。

另一位修士也在同一段里时，岔路写成碰见了谁，做法是避开、攀谈、交手。避开的游记有见闻，战报不增加。攀谈在还能说话时好感加三。已经是嫌隙或宿怨时，话照样说，好感不加，句子里有剑拔弩张。交手以后两边都能读到这一场的招式，摘要写出谁赢了、谁输了，或者打成平手，并写灵石有没有动。好感和怨隙按城里切磋同一档走。对方如果已经离开这一段，这一架不开，句子写人已经不在。

撤出的摘要用这一段原来的短话。没有路引、境界不够、贡献不够、感应不够、入口关着，拒绝的句子都是中文。

## Constraints

- 交手必须调用 `runPartyBattle`，并且 `duel` 为真，和城里切磋的技能结算同一条路。快照仍用 `buildCultivatorCombatSnapshot`。
- 见面只认 `bahuangProgress` 里状态仍是进行中、并且深度落在同一段的修士。没有这样的人，就不编一个假人。
- 一趟里同一个人只见面一次。岔路总数仍不超过三次。
- 旧存档上已经打开的旧岔路，原来的选项编号还能结算。
- 玩家看见的摘要、拒绝、岔路标签和见闻不写英文句子。

## Acceptance Criteria

- 深度落在荒尘驿、断碑原、无灯壑时，预览岔路分别写到沙客、碑影、灯烬，三处的做法不共用同一套句子。
- 两个人都在八荒里，其中一人选交手。两边的 `recentCombats[].combatRounds` 都有这一场，招式句子里有「使出」，行动摘要是中文。
- 选避开，游记有见闻，战报不增加。
- 岔路开着时把时辰走完，不选那个会拿到灵石的做法，灵石不因这一步增加，游记写时辰到了。
- 原来的门票消耗、进门、撤出测试仍然通过。
- 改过的包类型检查通过。

## Open Questions

- 没有。同一段里没有第二个人时，这一趟就只有当地的岔路。
