# 乙级秘境的身份

筑基走到乙级，九层现在还是同一套从者和同一句练手。甲级已经有丹霞内府、婴火莲池、神纹天隙。乙级不该只是那三处的瘦副本。

## Summary

乙级按一到三、四到六、七到九层各给一处能讲出来的地方。雷泽残阵挂断法，从者是阵脚和残雷。沉雾沼挂缠绕，从者是沼影和雾丝。铜棺窟挂霜寒，从者是棺侍和铜卫。输了或撤出掉几枚灵石，并留下一句短话。血量、伤害和甲级的掉落门都不动。丙级七到九层轻覆一层旧驿石廊，挂定根，从者是灯奴和石卒，不另扣灵石，门口的句子带上这一州的一点味道。

## Problem

筑基到金丹前，代理人在乙级读到的提醒仍是「练手，比丙级重一档」。守关从者一律叫从者和侧翼。战报里没有能拿回去说的状态，输了也没有这一层自己的句子。九层只是同一场仗按层数加厚。

## Goals

- 乙级一到三层叫雷泽残阵。守关挂已有的断法。从者叫阵脚和残雷。
- 乙级四到六层叫沉雾沼。守关挂已有的缠绕。从者叫沼影和雾丝。
- 乙级七到九层叫铜棺窟。守关挂已有的霜寒。从者叫棺侍和铜卫。
- 这三处输了或撤出，掉很少的灵石，游记和摘要路径上留下一句短话。不另加伤的时长，不走火，不抽灵力。
- 守关人数、血量、伤害仍按原来的乙级公式。直接挑战守关的法术也不改。
- `state.dungeon.advice`、`rankYieldHints.mysteryName`、`mysteryLine`，以及筑基的 `realmPath.where`，用完整中文写出这一层的名字、状态和从者。
- 丙级一到六层仍是练手，没有名字。七到九层叫旧驿石廊，挂已有的定根，从者叫灯奴和石卒。输了只留一句短话，不扣灵石。站在哪一州的门口，`advice` 和 `mysteryLine` 再补一句这一州的廊是什么样。
- 炼气后期的 `realmPath` 点出旧驿石廊。炼气前期不提它。

## Non-Goals

- 不改丹霞露、养魂砂、神纹尘的掉落，不改甲级进门境界，不改甲级守关的血量、伤害、状态和失败代价。
- 不给乙级或丙级发通关遗物。
- 不新开地宫入口，不改层数和解锁。
- 不另做一套状态。断法、缠绕、霜寒、定根都用现成的。
- 不按州改乙级的守关。州的句子只覆在丙级七到九层的门口提醒上。

## User-Visible Behavior

筑基前期站在乙级门口，`advice` 和一到三层的 `mysteryLine` 写雷泽残阵、断法、阵脚和残雷。四到六层写沉雾沼，七到九层写铜棺窟。`realmPath.where` 跟着当前这一段走。打起来从者的名字换了，身上会挂那一种状态。输了或撤出，袋子少几枚灵石，游记里有那一句短话。

炼气后期走到丙级七到九层，读到旧驿石廊和定根。青州的廊干一些，雷州的廊会响，各州一句，守关还是同一套。一到六层没有这个名字。

金丹站在甲级，仍读丹霞内府、婴火莲池、神纹天隙。遗物、掉落和守关公式与这一轮之前相同。

## Constraints

- 状态档位用现成表里的第二档。不另写伤害公式，不加额外抽灵。
- 旧存档没有新字段。名字和句子在读状态时现算。
- 甲级的 `mysteryLine` 仍先接原来的秘境说明和守关提醒。乙级和丙级不进那张表。

## Acceptance Criteria

- 乙级一层仍是三只，血量等于原来的乙级公式，不吃甲级倍率。从者名字是阵脚和残雷，主守挂断法。
- 乙级五层从者是沼影和雾丝，挂缠绕。九层从者是棺侍和铜卫，挂霜寒。三处的失败句子各写各的地方，灵石少于甲级一层输掉的那一笔，不加伤的底线，不走火。
- 丙级一层仍是一只精英，没有威胁状态。丙级六层的从者仍叫从者。丙级八层血量仍是原来的丙级公式，从者是灯奴和石卒，挂定根。输掉不另扣灵石。
- 筑基的 `realmPath.where` 和乙级 `mysteryLine` 写出对应的那一处。炼气前期的 `realmPath` 不出现雷泽残阵、旧驿石廊、丹霞内府。
- 丙级七层的 `mysteryLine` 在青州和雷州各有一句不同的话，名字仍是旧驿石廊。甲级一层的 `mysteryName` 仍是丹霞内府，并仍带遗物提示。
- 战报的几句里能看见挂上的状态。甲级的焚灼、幻惑、镇压仍会写进这几句。

## Open Questions

- 没有。乙级不按州拆成九套守关，丙级七到九层只在句子上分州。
