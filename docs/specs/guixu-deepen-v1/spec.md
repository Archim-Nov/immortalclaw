# 归虚走成一趟终局

## Summary

归虚仍从原来的五处进去。仙缘、境界、个人解锁和共用解锁都不改。玩家看见的名字、拒绝、收尾和游记改成中文。走进去以后会停下，三到四个中文做法里选一个。短的一趟停一次，长的一趟停两次。时辰到了不代选，也不把这一步没选的灵石放进袋子。收尾仍落下原来那一档遗宝，句子改成中文，每处至少三句不同的收尾。

## Problem

归虚已经能按仙缘和境界打开，再跑一段时辰，从事件池里抽一次奖励。池子几乎是一句英文。节点名是 Guixu Threshold Gate、Guixu Ancient Seal 这种英文。打开和走完的摘要也是英文。和八荒比，它还不是一趟能走的终局，只是一次抽奖。

## Goals

- 五处对玩家显示的名字是归虚门槛、归虚古印、归虚灵枢、归虚虚廊、归虚本源心。标识仍是原来的英文 id。
- 打开、拒绝、探索、收尾、世界事件和游记不出现英文句子。仙缘就写仙缘，不写感应。
- 两刻的一趟停一次，三刻及以上停两次，不超过两次。每处的做法不共用同一套句子。做法三到四个。
- 选了会摸到灵石的那一个，灵石这时才进袋子。看、稳住、记下，不发这一步的灵石。
- 时辰到了，岔路关掉，写一句时辰到了。不代选，不发这一步的灵石。
- 收尾仍给这一处原来的遗宝。古印至少一件传说遗宝，本源心至少两件，门槛和灵枢至少一件上古遗宝，虚廊至少一件传说遗宝和两件上古遗宝。每处收尾池至少三句中文。
- 岔路开着时，行动列表只有这些做法。`state.guixu.run` 和 digest 写归虚岔路待决。
- 旧存档里已经打开的节点还在。存档里的英文节点名在玩家看见的地方改口。世界时辰照走，只停这一趟自己的剩余时辰。

## Non-Goals

- 不改八荒的门票、岔路和交手，也不改地宫守关。
- 不降低仙缘或境界门槛，也不把个人解锁改成共用。
- 不加后台工人，不在时辰里调用模型。
- 不改观览页。静态观览已经用归虚和仙缘，不渲染这些节点的英文名。
- 不新开付款或部署路径。

## User-Visible Behavior

人站在青州甲级地宫门口，读 `state.guixu`。`wildernessAttunement` 是仙缘。五处写着中文名、要多少仙缘、要哪一境，以及还差什么。

仙缘或境界不够时，打开会被拒绝，句子里写仙缘或境界。已经开过的，句子写这一处已经开过了。共用的古印、虚廊、本源心，一个人打开以后，旁边的人不用再开，可以直接探。门槛和灵枢只记在自己名下。

走进去以后，游记先有一句见闻。岔路开着十刻。做法是中文。选摸一把，袋子里多三十六枚灵石。选冒险的那一档，多六十四枚灵石，气血下去一截。本源心里把火吹旺，还会挂两刻伤。时辰到了还没选，游记写时辰到了，这一处没选，灵石不因这一步增加。

两刻的门槛和古印只停一次。三刻的灵枢、虚廊，和四刻的本源心，会再停一次，场面和上一处不同。两处之间可以再有一句见闻，同一句不重复。

这一趟走完，摘要、游记和世界事件都是中文，并写带出何物。遗宝用上古遗宝、传说遗宝、残碑碎片，不写英文物品 id。

## Constraints

- 行动 id 仍是 `unlock-guixu:<nodeId>`、`explore-guixu:<nodeId>`，岔路是 `guixu-choice:<optionId>`。
- 岔路存在这一趟的 job 上。时辰到了只把这一趟的剩余时辰放回去继续走，不卡住世界时辰。
- 时辰到了不得套用选项效果。
- 收尾用的事件 id 仍是英文短横线。已经写在进行中的 job 上的旧 id 还能结算，句子是中文。
- 玩家看见的摘要、拒绝、岔路和见闻不写英文句子，也不写修士（智能体）、只观不问。

## Acceptance Criteria

- 打开归虚门槛的行动标签是中文，含归虚门槛，不含 Guixu。
- 仙缘不够、境界不够、已经开过，拒绝句子分别写到仙缘、境界、已经开过。
- 共用的古印打开一次以后，另一个人在同一处能看到探归虚古印。
- 探古印会停下。选摸一把，灵石加三十六。游记有见闻，摘要是中文。
- 岔路开着时把时辰走完，不选那个会拿到灵石的做法，这一步的灵石不增加，游记写时辰到了，且不写代选了。
- 本源心会先后停下两处不同的场面。
- 走完古印，袋子里有传说遗宝。世界事件的标题是中文。
- 存档里的节点名仍是英文时，行动标签仍显示归虚古印。
- 岔路开着时世界时辰仍往前，这一趟的剩余时辰停住。
- 原来的解锁、共用、探索测试仍然通过。
- 改过的包类型检查通过。

## Open Questions

- 没有。五处仍锚在青州甲级地宫门口，不另开门。
