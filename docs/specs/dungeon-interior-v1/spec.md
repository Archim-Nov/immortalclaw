# 地宫和州府秘境的内部

## Summary

丙级、乙级、甲级的门、守关从者、见闻、同队投票和甲级遗物保持原样。州府秘境的门、潮汐、签名物和投票也保持原样。这一轮补的是进门以后、守关以前的内容：能选的侧室，按层换名字的中途敌人，以及探路、歇脚、侧室这几段能写进游记的路程。

## Problem

排名层的中途仍然最多醒三次，醒与醒之间大多是沉默的搜寻或守关。州府秘境更短，常常是选一次，然后打守关或直接结算。代理人能讲出门在哪，讲不出这一趟里面发生了什么。

## Goals

- 排名层仍最多醒三次。第三步仍是伤者。第六步和第八步在原有岔路、遗物、同门、夺宝之外，也可以是陷阱、小龛、侧室、兽窝或封门。每处三到四个中文做法，仍用 `dungeon-wake-decision:<optionId>`。
- 不是醒时的那几步写下探路、歇脚、侧室或将到守关。这些句子进游记的见闻，也进摘要。
- 搜寻的第二步是一场有名字的遭遇，第五步在仍是搜寻时是一场中途精英。敌人按层换：兵器和法术各一只，中途精英再加一只。守关原来的从者名字不变。
- 十二处州府秘境各有一间侧室，三到四个做法，仍用 `regional-choice:<optionId>`。选侧室不结束这一趟，也不发签名物。签名选择仍是超过一半才锁，时辰到了没锁就走稳的那一边。侧室单独计票。队长已经选了、其他人没在时辰里投出多数，就留下队长那一句。没人答侧室时，结算签名选择的同时记下稳的那一句。
- 州府秘境的险路再带一名随从，写进 `combatRounds`。门口的守关名字不变。
- 荒野和八荒在不是见闻的那一拍，可以多写一句路上的一处，并带上这一处的名字。
- 报酬保持薄。伤、灵石和一句能拿回去说的话就够。

## Non-Goals

- 不增加排名层的醒时次数，不改同队在第三、六、八步的投票。
- 不改乙级、丙级、甲级守关的从者名字、血量和状态。
- 不改州府秘境的进门条件、潮汐、冷却、签名物和遗物。
- 不把侧室做成另一套行动编号。

## User-Visible Behavior

一个人进丙级或乙级，第一步的游记里有探路。后面若是搜寻，战报里能看见这一层自己的名字，比如雷泽残阵的雷枪客和断法修，中途精英是残阵主。第六步或第八步若抽到新场面，做法仍是中文，三到四个。同队的人仍只在原来的三处投票。

进青岚药窟时，`active.passage` 是探路，然后是露虫，见 `docs/specs/regional-passage-v1/spec.md`。这两步还开着时，`active.options`、`active.interior`、`active.deeper` 先空着，行动里也没有等露和石窝。两步走完以后，`state.regionalDungeons.active.options` 才是等露、割藤、拔根，`active.interior` 才是旁边的石窝。`regional-choice:room-qinglan-look` 只记下那一句，露芯还在等后面的选择。探路或露虫还开着时，超时不跳到等露，直接去收也被拒绝，露芯不进袋子。这两步走完以后，签名选择超时仍走等露。侧室若队长已经开口、同伴没有投出多数，就留下队长那一句；谁都没答，才带上侧室里稳的那一句。

荒野和八荒的见闻还在。中间多出来的句子标题是路上的一处。

## Constraints

- 旧存档没有 `interiorResolved`。结算签名选择时，若侧室还没答，就补上稳的那一句，不另扣灵石。队长已经投过的侧室不算没答。
- 战报仍最多留三场。若带出何物的那一场会被挤掉，就把它留在这三场里。
- 中途遭遇不走甲级守关的失败扣石。只有第五步的中途精英，在非稳妥姿态打输时，才挂两刻伤。

## Acceptance Criteria

- 排名层一次跑完仍最多三醒。第三步的做法仍是扶起、分水、拿走袋子。
- 乙级一层的中途名字是雷枪客、断法修、残阵主。丙级一层不是灯奴。甲级一层是火刀客、焚咒修、炉前使。
- 五处新醒时场面各有四个中文做法。旧的同门场面在只剩它没出现时仍会被抽到。
- 十二处州府秘境都有侧室。青岚药窟先看石窝再等露，露芯仍进袋子，见闻还在。
- 险路的战报里能看见随从的名字。等露、割藤这种不险的选择不额外加一只怪。
- 领域测试、`build:web` 和根目录 `npm run build` 通过。

## Open Questions

- 没有。中途的报酬不再加厚。
