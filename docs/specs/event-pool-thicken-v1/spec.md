# 事件池加厚 v1

## 问题

游历、赶路、州外和副本里，代理读到的事件经常是同一套句子换个地名。人情和宗门只在少数二选一里出现，早期池子也不该靠大额掉落撑场面。

## 目标

- 沿用现有 `EventTemplate`、抽取和道德二选一，不另做一套事件引擎。
- 全局游历和全局赶路的条数明显增加，场面彼此不同。
- 各州游历、赶路、州外补上当地才说得通的场面，而不是只改标题里的一个词。
- 人情和轻量宗门杂务写进普通事件：送礼、闲话、人情、值日、带一句话。不新开宗门外交，也不花贡献。
- 奖励保持薄：几枚灵石、一点修为、短状态、一句关系。炼气能抽到的条目不掉筑基以上的突破材料。
- 代理看见的标题和正文用完整中文句子。

## 非目标

- 不把道德选项改成三到四个。现有记录就是正邪两个方向，接口仍是 `options` 两项。
- 不建八荒专属极端池。八荒仍走现有远征和醒时抉择。
- 不做副本多阶段事件链。副本仍是按品级和层数抽一条。
- 不改 `skill.md`。没有新的动作编号，待决选择仍走原来的 pending 和 choose。

## 行为

- 新事件进入现有全局、州、旅途州、节点池，权重和 `minRealm` 过滤不变。
- 有 `moralityChoice` 的新事件仍是两项，道德增减方向相反，两边奖励都薄。
- 世界日志标题优先用 `nameCn`。没有中文名时才退回英文 `name`。
- 筑基材料只出现在 `minRealm` 至少为筑基的条目上。金丹材料只出现在至少金丹的条目上。元婴和化神材料不进这些池。

## 验收

- 全局游历不少于原来的两倍，全局赶路不少于原来的两倍。
- 九州游历、九州赶路、九州州外都有新增的当地场面。
- 相关目录测试和类型检查通过。
- 规格里写明八荒极端池和副本多阶段链仍留到以后。
