# Immortal Claw 五行属性与法术衍生策划案

## 文档目标

本文档用于冻结五行系统作为独立属性层的设计方案，并定义五行法术的基础衍生逻辑，作为后续法术、功法、附灵、阵法、地脉与环境交互的共同依据。

本文档解决以下问题：

- 五行是否独立于主属性存在
- 五行基础值如何初始化
- 五行如何衍生法术强度、状态强度与元素抗性
- 五行的相生相克在系统中如何落地
- 五行法术应该分成哪些流派

若要继续查看战斗层细化，请配合阅读：`docs/specs/oc-cultivation-foundation/five-element-status-and-skill-prototypes.md`

## 一、系统定位

### 1.1 五行是独立属性系统

当前定稿：

- 五行系统不绑定 8 个主属性
- 五行系统不视为主属性的附属修正
- 五行系统作为与主属性平行的第二套基础面板存在

角色的底层结构因此变为：

- 主属性系统：描述角色本身的肉身、心性、灵识、兵道素质
- 五行属性系统：描述角色体内灵气结构与元素倾向
- 兵器系统：描述外功路线
- 法术系统：由五行系统衍生

### 1.2 五行的作用边界

五行系统当前主要负责：

- 元素法术强度
- 元素状态强度
- 元素抗性
- 元素功法适性
- 元素环境共鸣
- 元素附灵、阵法、法宝与洞府交互

五行系统当前不负责：

- 替代气血、灵力、速度、命中等通用战斗面板
- 决定玩家是否能使用某一类兵器
- 决定角色是否能学习某一类外功

## 二、五行基础属性

### 2.1 五行基础面板

当前定稿为 5 个独立属性：

- `金行`
- `木行`
- `水行`
- `火行`
- `土行`

这 5 个值共同构成角色的“灵气结构图谱”。

### 2.2 数值范围

当前定稿：

- 五行属性的成长暂不设硬上限
- 新角色五行总量：`250`
- 默认平均线：`50`

初始参考区间：

- `30-39`：该元素偏弱
- `40-49`：略弱或未成体系
- `50-59`：平均水平
- `60-69`：该元素较强
- `70+`：在新角色与前中期阶段已属于明显专精，后期仍可继续成长

### 2.3 由登记结果初始化
问卷登记生成的 `five_element_scores` 不直接用于战斗，而是用于初始化角色的五行基础面板。

建议换算公式：

- 每个元素先获得固定基础值 `30`
- 额外 `100` 点按登记结果比例分配

即：

- `五行属性值 = 30 + round(该元素原始分数 / 五行总分 * 100)`

这样做的好处：

- 每个角色都有五行底盘，不会出现元素完全为 0
- 登记问卷决定的是分布结构，不是绝对强度碾压
- 主灵根与副灵根会自然在面板上体现出来

### 2.4 灵根与五行属性的关系

灵根不是额外一套独立数值，而是对五行基础属性排序后的解释层。

例如：

- 金行 44
- 木行 49
- 水行 63
- 火行 36
- 土行 58

可以推导出：

- 主行：水
- 副行：土
- 灵根判定：若最终为 `水 61 / 土 58`，则是 `水单灵根`；若最终为 `水 61 / 土 60`，则是 `水土双灵根`

## 三、相生相克规则落地

### 3.1 设计原则

当前定稿规则如下：

- `本属性决定法术强度`
- `本属性 + 相生属性决定状态强度`
- `本属性 + 相克属性决定抗性`

为避免实现歧义，本文明确约定：

- “相生属性”指 **生我者**
- “相克属性”指 **克我者**

也就是说：

- 金的相生属性是土，因土生金
- 金的相克属性是火，因火克金
- 木的相生属性是水，因水生木
- 木的相克属性是金，因金克木
- 水的相生属性是金，因金生水
- 水的相克属性是土，因土克水
- 火的相生属性是木，因木生火
- 火的相克属性是水，因水克火
- 土的相生属性是火，因火生土
- 土的相克属性是木，因木克土

### 3.2 五行映射表

| 元素 | 本属性决定 | 状态强度取值 | 抗性取值 |
| --- | --- | --- | --- |
| 金 | 金行 | 金行 + 土行 | 金行 + 火行 |
| 木 | 木行 | 木行 + 水行 | 木行 + 金行 |
| 水 | 水行 | 水行 + 金行 | 水行 + 土行 |
| 火 | 火行 | 火行 + 木行 | 火行 + 水行 |
| 土 | 土行 | 土行 + 火行 | 土行 + 木行 |

## 四、五行衍生值

### 4.1 三组核心衍生值

每个元素都产出三组衍生值：

- `元素法术强度`
- `元素状态强度`
- `元素抗性`

共计 15 个内部衍生值。

### 4.2 计算公式

建议第一版采用线性公式，便于理解与平衡：

- `元素法术强度 = 本属性`
- `元素状态强度 = 0.7 * 本属性 + 0.3 * 生我属性`
- `元素抗性 = 0.7 * 本属性 + 0.3 * 克我属性`

例如：

- `火法术强度 = 火行`
- `火状态强度 = 0.7 * 火行 + 0.3 * 木行`
- `火抗性 = 0.7 * 火行 + 0.3 * 水行`

### 4.3 对外转化建议

为了与战斗系统衔接，建议将三组衍生值转换为可用修正：

- `元素伤害加成 = 元素法术强度 * 0.6%`
- `元素状态加成 = 元素状态强度 * 0.4%`
- `元素减伤 = 元素抗性 * 0.5%`

建议上限：

- 元素伤害加成不设硬上限，但后续可通过境界或装备进行软控
- 元素状态加成建议软上限 `40%`
- 元素减伤建议软上限 `60%`

### 4.4 五行系统内部平衡逻辑

这套规则会自然形成三类 build：

- 单行专精型：本属性极高，法术强度突出
- 相生状态型：本属性与生我属性都高，状态压制更强
- 相克抗性型：本属性与克我属性都高，对同系或相关法术更耐受

例如：

- `火高 + 木高`：更适合灼烧、爆燃、持续伤害型火法
- `火高 + 水高`：火法依然强，但对火系伤害也更能扛
- `水高 + 金高`：更适合冻结、迟滞、幻流控制型水法
- `土高 + 木高`：土法更稳，也更能抗土系压制与地脉控制

## 六、五行法术的系统关系

### 6.1 与兵器系统的关系

五行系统与兵器系统分离，但两者可以联动：

- 兵器招式可以挂元素标签
- 元素法术可以附着在兵器套路上
- 同一把兵器会因为五行不同而获得不同打法

例如同样是枪修：

- 火行枪修：更偏突进、爆发、连刺追击
- 水行枪修：更偏控距、卸力、迟滞封位
- 土行枪修：更偏站场、打断、压阵推进

### 6.2 与环境系统的关系

后续可基于五行系统扩展：

- 地脉区域加成
- 洞府环境增益
- 阵法共鸣
- 丹药属性偏转
- 法宝附灵

### 6.3 与主属性系统的关系

当前定稿中，五行系统与主属性系统平行存在。

这意味着：

- 五行不从主属性导出
- 五行不作为主属性的附属词条
- 两套系统未来可以在施法消耗、命中方式、装备门槛等环节交互，但不是一一绑定关系

## 七、当前冻结边界

本文档已经冻结的内容包括：

- 五行作为独立属性系统存在
- 五行 5 项基础属性
- 五行初始化思路
- 相生相克在法术强度、状态强度、抗性中的落地方式
- 五行 15 条法术分支与其功能定位

本文档尚未冻结的内容包括：

- 各五行法术的具体技能列表
- 技能消耗、冷却、施法前摇与范围模板
- 元素状态之间的进阶反应规则
- 五行与法宝、阵法、地脉的数值化联动
- 五行与境界突破之间的额外耦合机制

这些内容将在下一阶段法术与功法专项设计中继续扩展。

## 八、当前版本结论

当前版本已经明确：五行不是主属性修正项，而是一套独立存在的属性系统。

五行系统的职责已经清楚分成三层：

- 本属性决定法术强度
- 本属性与生我属性决定状态强度
- 本属性与克我属性决定抗性

在此基础上，金、木、水、火、土各自发展出 3 条法术分支，共 15 条衍生路线。

这使得 Immortal Claw 的法术系统不再只是“元素颜色不同的伤害”，而是拥有完整构筑空间的独立玩法层。
