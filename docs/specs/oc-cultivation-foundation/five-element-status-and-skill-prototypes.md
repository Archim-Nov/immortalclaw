# Immortal Claw 五行状态与法术原型策划案

## 文档目标

本文档承接《五行属性与法术衍生策划案》，继续把五行系统从“属性层”推进到“战斗执行层”。

本文档主要解决四个问题：

- 五行法术在战斗里到底通过哪些状态产生差异
- 元素状态如何与 `控制强度`、`控制抗性`、`元素抗性` 一起结算
- 15 条法术分支各自应该承担什么战斗职责
- 后续做技能表时，可以直接套用哪些技能原型

建议将本文档视为五行系统第二阶段冻结稿，作为后续：

- 技能表制作
- 功法树设计
- 敌方怪物元素设计
- 法宝、阵法、洞府与地脉联动
- PVE 战斗节奏设计

的共同依据。

## 一、系统定位回顾

### 1.1 五行的三层职责

当前已经冻结的五行职责仍然保持不变：

- `本属性` 决定该元素法术强度
- `本属性 + 生我属性` 决定该元素状态强度
- `本属性 + 克我属性` 决定该元素抗性

统一表达式如下：

- `元素法术强度 = 本属性`
- `元素状态强度 = 0.7 × 本属性 + 0.3 × 生我属性`
- `元素抗性 = 0.7 × 本属性 + 0.3 × 克我属性`

其中：

- `生我属性` 指相生链条中“生我者”
- `克我属性` 指相克链条中“克我者”

例如：

- 木的 `生我属性` 为水，`克我属性` 为金
- 火的 `生我属性` 为木，`克我属性` 为水
- 土的 `生我属性` 为火，`克我属性` 为木

### 1.2 五行在战斗中的职责分工

五行系统在战斗中不直接替代通用主属性，而是负责三种专门输出：

- `元素伤害`：决定术法的直接威力
- `元素状态`：决定持续伤害、控制、标记、护盾、回复、领域等效果强度
- `元素对抗`：决定角色面对对应元素法术时的承受能力

换句话说：

- 主属性与详细属性解决“角色底子”
- 五行属性解决“法术风格”
- 兵器系统解决“外功手感”

三者叠加后，才构成完整战斗角色。

## 二、五行状态系统总则

### 2.1 状态分类

为便于后续统一结算，五行状态分为 7 类。

#### 1）伤害型状态

持续对目标造成伤害，通常以回合、秒数或触发次数结算。

典型状态：

- `焚灼`
- `蚀甲灼痕`
- `金锋刻印`

#### 2）软控制状态

会限制目标行动效率，但不完全剥夺行动权。

典型状态：

- `霜寒`
- `迟缓`
- `凝滞`
- `镇压`

#### 3）硬控制状态

直接打断、定身、冻结或强制压制目标。

典型状态：

- `定根`
- `冻结`
- `震慑`
- `断法`

#### 4）削弱型状态

降低目标的防御、回复、护盾、施法稳定或命中能力。

典型状态：

- `裂甲`
- `熔甲`
- `错识`
- `护罩破损`

#### 5）增益型状态

提升角色自己的攻击、防御、恢复或资源循环能力。

典型状态：

- `锐化`
- `回春`
- `生长祝福`
- `稳固`

#### 6）标记型状态

本身不一定立即生效，但会成为后续技能的引爆条件或增幅条件。

典型状态：

- `激燃标记`
- `破禁标记`
- `反震印`
- `烈焰印记`

#### 7）场域型状态

在一定区域内长期存在，持续影响站位、输出或防御节奏。

典型状态：

- `地壁`
- `厚土领域`
- `水幕流转`
- `灵植域`

### 2.2 基础结算规则

五行状态不单独绕过原有战斗面板，而是和既有详细属性一起工作。

建议统一采用以下结算框架：

- `状态附着值 = 技能基础附着 + 元素状态强度 + 控制强度加成`
- `状态抵抗值 = 目标元素抗性 + 控制抗性加成`
- 若 `状态附着值 > 状态抵抗值`，则状态成功附着

这样做的好处是：

- 五行高的角色更擅长打出“属于自己元素”的状态
- `控制强度 / 控制抗性` 仍然保留通用战斗价值
- 面对同元素对手时，元素抗性可以形成鲜明的职业对抗感

### 2.3 状态持续与叠层规则

为了避免规则膨胀，第一版建议固定为以下 5 条：

1. `持续型伤害状态` 可叠层，默认上限 `5` 层
2. `软控制状态` 可刷新时长，默认不叠层，只取最高强度
3. `硬控制状态` 默认不可叠层，只能延长或覆盖
4. `增益型状态` 同名默认不可叠层，不同来源只刷新持续时间
5. `场域型状态` 同一施术者同名场域只能存在 `1` 个

### 2.4 覆盖优先级

当多个同名状态同时存在时，采用统一优先级：

- 更高 `状态强度` 覆盖更低状态强度
- 若强度相同，则保留剩余时间更长者
- 若是标记型状态，则按层数叠加或刷新，由该分支单独注明

### 2.5 驱散与净化规则

第一版建议把解状态能力也做成统一底层：

- `净化`：移除负面状态，优先移除软控制与削弱状态
- `驱散`：移除正面状态或场域状态
- `破除`：专门针对护盾、禁制、阵地、结界
- `强解`：可以解除硬控制，但应当更稀有

五行上的职责分配建议如下：

- 金更擅长 `破除` 与 `驱散`
- 木更擅长 `净化` 与 `恢复`
- 水更擅长 `转化` 与 `卸力`
- 火更擅长 `引爆` 与 `持续压血`
- 土更擅长 `稳态抵抗` 与 `场域对顶`

## 四、五行分支战斗职责

### 4.1 金系：破、御、禁

- `锋刃`：单体斩切、破甲、点杀
- `罡御`：护体、反震、兵器锐化
- `破禁`：断法、拆盾、解阵、碎结界

### 4.2 木系：养、束、盛

- `生息`：治疗、回灵、续航
- `缠束`：缠绕、定身、控位
- `丰茂`：增益、伴生、召唤、持续强化

### 4.3 水系：寒、幻、润

- `寒流`：减速、冻结、控场
- `幻流`：迷惑、错位、干扰判断
- `润泽`：化劲、净化、资源循环

### 4.4 火系：爆、蚀、追

- `炽焰`：正面爆发、范围轰杀
- `炼化`：持续灼烧、熔甲、消耗资源
- `激燃`：追击、连爆、斩杀、收割

### 4.5 土系：壁、镇、域

- `岩壁`：护盾、减伤、守点
- `镇岳`：击退、打断、压制、强控
- `地脉`：领域、阵地、地形收益

## 五、15 条法术分支技能原型

这里的“技能原型”不是最终技能名册，而是后续做技能树时可直接复用的模板。

每条分支先固定 `3` 个基础模板：

- `起手技`：低门槛、快速挂状态
- `核心技`：该分支最能体现玩法识别度的技能
- `爆发技 / 大技`：消耗资源或依赖前置状态，负责拉开上限

### 5.1 金系法术原型

#### 锋刃系

1. `断锋诀`
   - 起手技
   - 单体金系斩切
   - 造成金伤并附加 `裂甲`

2. `穿罡斩`
   - 核心技
   - 对带有 `裂甲` 或 `金锋刻印` 的目标追加高额穿透伤害

3. `千刃追命`
   - 爆发技
   - 消耗目标身上的 `裂甲` / `金锋刻印` 层数，换取点杀爆发

#### 罡御系

1. `金罡护体`
   - 起手技
   - 为自身附加 `金罡护身`

2. `玄金锻兵`
   - 核心技
   - 给兵器附加 `锐化`，使接下来数次外功附带金伤或破甲

3. `万钧回震`
   - 爆发技
   - 在持续时间内将受击转化为范围反震，并触发 `反震印`

#### 破禁系

1. `截脉钉`
   - 起手技
   - 中距离断法攻击，附加 `断法`

2. `碎阵印`
   - 核心技
   - 对护盾、结界、场域目标造成额外破坏，并叠加 `破禁标记`

3. `禁纹崩解`
   - 爆发技
   - 范围驱散正面状态，若目标已有 `破禁标记` 则追加打断或削盾

### 5.2 木系法术原型

#### 生息系

1. `回春引`
   - 起手技
   - 为己方单体附加 `回春`

2. `生灵归元`
   - 核心技
   - 群体回复气血与灵力，并强化 `生息`

3. `万木续命`
   - 爆发技
   - 短时间内大幅强化持续恢复，对低血量目标收益更高

#### 缠束系

1. `藤锁术`
   - 起手技
   - 附加 `缠绕`

2. `盘根禁步`
   - 核心技
   - 对已被 `缠绕` 的目标施加 `定根`

3. `千蔓封径`
   - 爆发技
   - 生成大片缠束区域，持续限制走位并刷新 `缠绕`

#### 丰茂系

1. `荣枝祝`
   - 起手技
   - 给己方附加 `生长祝福`

2. `灵植伴行`
   - 核心技
   - 召出 `木灵伴生`，持续提供治疗、增益或协同攻击

3. `万象繁生`
   - 爆发技
   - 快速扩张灵植场域，强化召唤体与持续技能

### 5.3 水系法术原型

#### 寒流系

1. `凝霜诀`
   - 起手技
   - 对目标附加 `霜寒`

2. `寒潮锁脉`
   - 核心技
   - 对带有 `霜寒` 或 `凝滞` 的目标提高冻结概率

3. `玄冰封界`
   - 爆发技
   - 大范围冻结型场控，适合作为开团或保命手段

#### 幻流系

1. `迷波术`
   - 起手技
   - 附加 `幻惑`

2. `错识换影`
   - 核心技
   - 制造目标锁定错误与路径判断失真，叠加 `错识`

3. `千面流光`
   - 爆发技
   - 在短时间内反复触发错位、隐匿与感知扰乱

#### 润泽系

1. `润体诀`
   - 起手技
   - 为己方附加 `化劲`

2. `流泉归息`
   - 核心技
   - 提供群体回灵、净化与小额减伤

3. `水幕天轮`
   - 爆发技
   - 展开 `水幕流转` 场域，持续减伤并转化部分伤害

### 5.4 火系法术原型

#### 炽焰系

1. `焚光诀`
   - 起手技
   - 单体或小范围火伤，附加 `烈焰印记`

2. `赤炎坠`
   - 核心技
   - 对带有 `烈焰印记` 的目标造成高爆发火伤

3. `天火覆压`
   - 爆发技
   - 范围轰击型火法，适合作为战斗高峰技能

#### 炼化系

1. `灼脉印`
   - 起手技
   - 附加 `焚灼`

2. `熔甲炙骨`
   - 核心技
   - 对持续燃烧目标叠加 `熔甲`，削弱护盾与护体

3. `炉火化形`
   - 爆发技
   - 延长全场 `焚灼` 并提升灼烧伤害，适合持久压血

#### 激燃系

1. `火行追星`
   - 起手技
   - 突进或补位攻击，附加 `激燃标记`

2. `余烬连爆`
   - 核心技
   - 对带 `激燃标记` 的目标连续触发追击爆炸

3. `燎原绝路`
   - 爆发技
   - 对残血或多层标记目标进行斩杀式引爆

### 5.5 土系法术原型

#### 岩壁系

1. `岩甲术`
   - 起手技
   - 为己方附加 `岩甲`

2. `地壁成城`
   - 核心技
   - 展开 `地壁`，形成阻挡、护体或断路效果

3. `玄垣不动`
   - 爆发技
   - 在短时间内大幅提升减伤、韧性与护盾收益

#### 镇岳系

1. `镇脉击`
   - 起手技
   - 对目标附加 `镇压`

2. `岳压断势`
   - 核心技
   - 对已被 `镇压` 的目标打出强打断或 `震慑`

3. `坠岳封关`
   - 爆发技
   - 范围压制，适合守点、反冲锋或打断敌方大招节奏

#### 地脉系

1. `引脉诀`
   - 起手技
   - 为所在区域附加 `地脉共鸣`

2. `厚土成域`
   - 核心技
   - 展开 `厚土领域`，提升己方站场收益并压低敌方推进效率

3. `山河镇界`
   - 爆发技
   - 强化整个战区的地形优势，配合队友完成长期压场

## 六、分支之间的连携思路

为了让五行系统不是“五种不同颜色的技能”，需要提前定义跨分支连携逻辑。

### 6.1 同元素内部连携

每个元素内部建议形成固定战斗节奏：

- 金：`破甲 -> 锐化 / 断法 -> 点杀`
- 木：`治疗 / 铺场 -> 缠束控位 -> 召唤或续航滚雪球`
- 水：`减速 -> 幻惑干扰 -> 冻结或化劲转守`
- 火：`挂燃烧 / 标记 -> 压血 -> 连爆斩杀`
- 土：`立壁 / 立域 -> 镇压敌方节奏 -> 稳定接团`

### 6.2 跨元素连携

第一版推荐重点支持以下连携：

- `金 + 火`：裂甲后引爆，形成高破防爆发线
- `木 + 水`：恢复与化劲联动，形成续航与软控线
- `水 + 火`：先挂减速或冻结，再用火法定点爆破
- `土 + 金`：土系稳场后，金系进行定点拆盾与点杀
- `木 + 土`：木系持续养成，土系负责前排站场与领域保护

### 6.3 与兵器系统的连携

由于五行和兵器已明确分离，因此五行法术应该更多承担“附着层”和“构筑层”的职责。

建议兵器与五行的联动方式固定为以下 4 种：

- `附灵`：兵器招式附带元素伤害或状态
- `借势`：兵器命中后提高某一元素状态附着概率
- `收束`：兵器连段消耗元素标记，打出终结技
- `共鸣`：特定兵器套路在某元素场域内获得额外收益

## 七、第一版数值落地建议

### 7.1 技能模板参数

后续做技能表时，每个技能原型至少要标注以下字段：

- `元素`
- `分支`
- `技能类型`（单体 / 群体 / 场域 / 辅助 / 反制）
- `主效果`
- `附带状态`
- `基础伤害系数`
- `基础附着值`
- `持续时间`
- `冷却`
- `灵力消耗`
- `前摇 / 后摇`

### 7.2 状态强度映射建议

第一版建议将状态强度映射成三类实际效果：

- 持续伤害倍率
- 控制持续时间
- 护盾 / 治疗 / 场域收益

即：

- `伤害型状态` 主要吃状态伤害系数
- `控制型状态` 主要吃持续时间与命中门槛
- `增益 / 场域型状态` 主要吃收益倍率与覆盖时间

### 7.3 抗性映射建议

元素抗性建议至少拆成三层效果：

- 减少同元素直接伤害
- 降低同元素状态附着成功率
- 缩短同元素控制与负面持续时间

这样才能让“堆某一元素抗性”真正有玩法意义，而不只是单纯减伤。
