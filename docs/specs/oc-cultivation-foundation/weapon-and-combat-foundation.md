# Immortal Claw 兵器与战斗基础策划案

## 文档目标

本文档聚焦五行与兵器分离后的兵器路线、20 种兵器的属性适配，以及当前阶段已经冻结的战斗底层规则。

## 一、兵器系统总原则

### 1.1 五行与兵器分离

- 五行不绑定兵器种类。
- 兵器也不绑定某一种灵根。
- 玩家可以自由组合五行倾向与兵器路线。

这意味着角色构成是：

- 五行 / 灵根：定义气机与成长风格
- 兵器：定义外功手感与作战形式

### 1.2 兵器不是主属性

- 游戏不把“剑、刀、枪、弓”本身做成主属性。
- 主属性仍然是通用角色属性。
- 兵器通过“主要吃哪 3 个主属性”来定义适配度。

### 1.3 当前兵器定位

- 第一版扩展为 20 种兵器。
- 兵器多样性来自属性适配、节奏差异与风格标签，而不是 20 套完全独立系统。

## 二、兵器适配规则

### 2.1 三属性适配模型

每种兵器都有 3 个核心适配属性：

- 主属性：`50%`
- 副属性：`30%`
- 辅属性：`20%`

这 3 项主要用于定义：

- 兵器熟练成长速度
- 招式威力修正
- 架势稳定度
- 特性触发倾向

### 2.2 相关主属性解释

与兵器系统关系最强的主属性包括：

- `兵魄`：兵器掌握与外功底盘
- `身法`：位移、节奏、追击与快兵表现
- `体魄`：承压、站场、重兵支撑
- `神识`：命中、控距、精确与奇兵表现
- `悟性`：复杂招式、变招、技巧流成长
- `道心`：稳守、反制、防御型兵器支撑
- `灵元`：半法兵器与术兵混合流
- `根骨`：长时间运劲与持续输出能力

## 四、兵器族群划分

### 4.1 快兵系

- 剑
- 双剑
- 匕首
- 拳套

共同特点：

- 出手快
- 连段多
- 更吃身法与会心

### 4.2 重兵系

- 刀
- 巨刀
- 斧
- 锤

共同特点：

- 爆发高
- 压制强
- 更吃体魄与兵魄

### 4.3 长兵系

- 枪
- 戟
- 棍
- 钩镰

共同特点：

- 擅长控距
- 更依赖站位与节奏
- 对追击、封位、架势控制更敏感

### 4.4 柔兵奇兵系

- 鞭
- 链刃
- 流星锤
- 绫

共同特点：

- 变化多
- 更适合做控制、干扰与功能性玩法
- 更容易与五行染色系统产生明显差异

### 4.5 远奇灵兵系

- 弓
- 弩
- 扇
- 伞

共同特点：

- 偏远程或半法器
- 具备较强功能性与风格分化空间

## 五、兵器与战斗底层的关系

### 5.1 兵器不替代通用战斗属性

虽然每把兵器有自己的三属性适配，但角色战斗仍然沿用通用面板：

- 命中
- 闪避
- 速度
- 外功伤害倍率
- 术法伤害倍率
- 会心
- 暴伤
- 护心
- 韧性
- 控制强度
- 控制抗性

兵器系统主要影响的是“驾驭效率”和“打法表现”。

### 5.2 当前战斗核心约定

#### 会心

- 基础值固定为 `0%`
- 主要来自属性、兵器、技能、功法与装备

#### 暴伤

- 基础值固定为 `150%`

#### 护心

- 基础值固定为 `0%`
- 只负责抗暴击率，不与韧性重叠

### 5.3 当前建议的战斗判定

- `最终暴击率 = clamp(武器/技能基础会心 + 攻方会心 - 守方护心*0.7, 0%, 55%)`
- `最终暴击伤害 = 攻方暴伤`
- `控制命中率 = 技能基础概率 + (控制强度 - 控制抗性) * 0.5%`

## 六、五行如何作用于兵器

### 6.1 当前冻结原则

- 五行不改变兵器类别。
- 五行改变同类兵器的作战风格。
- 也就是说，五行负责“染色”，兵器负责“骨架”。

### 6.2 染色示例

以剑为例：

- 金剑：更偏精准、破防、斩断
- 水剑：更偏变招、控节奏、后手反击
- 火剑：更偏爆发、追击、收割
- 土剑：更偏稳守、抗压、反制
- 木剑：更偏成长、续航、压制

同理，其他兵器也遵循这一原则。

## 七、当前冻结边界

本文件已经冻结的内容包括：

- 五行与兵器分离
- 20 种兵器清单
- 每种兵器的三属性适配
- 兵器族群划分
- 当前阶段的暴击与控制基础规则

本文件尚未冻结的内容包括：

- 每种兵器的基础会心、基础暴伤、攻击距离与架势值
- 各兵器的主动技、被动技与招式树
- 五行染色后对兵器技能组的具体改写方式
- 兵器与功法、法器、宗门路线之间的联动细节

这些内容将在后续兵器与战斗专项设计中继续扩展。
