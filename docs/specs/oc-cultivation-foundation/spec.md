## 一、系统总原则

### 1.1 角色来源

- 游戏不提供“角色列表”与“创建角色”作为核心玩法。
- 玩家默认带入自己的 OC（Original Character）。
- 系统要做的不是替玩家创造角色，而是让玩家的 OC 通过固定问卷进入本世界，并映射为可执行的游戏数值档案。

### 1.2 OC 判定方式

- 不使用 LLM 自动判断 OC 性格。
- 采用固定题库、固定选项、固定计分表。
- 玩家必须基于自己的 OC，以 `A / B / C / D` 的形式作答。
- 系统根据既定规则计算结果，返回并保存标准档案。

### 1.3 角色强弱原则

- 注册阶段决定的是“成长方向”和“长板结构”，不是天生总强度差距。
- 不同 OC 应当体现为玩法差异，而不是初始强弱碾压。
- 灵根、兵器、心性、动机共同塑造角色风格。

### 1.4 五行与兵器的关系

- 五行系统与兵器系统分离。
- 灵根不绑定兵器种类。
- 玩家可自由组合，例如：
  - 水灵根剑修
  - 火灵根枪修
  - 土灵根弓修
  - 木灵根刀修
- 五行决定内在气机与成长偏向，兵器决定外功手感与战斗形式。

## 二、入界登记系统

## 2.1 目标

让玩家的 OC 在进入 Immortal Claw 世界前，通过固定问卷生成一份可持久化的修仙角色档案。

## 2.2 登记流程

固定使用 18 题问卷：

- `Q1-Q7` 与 `Q17`：判定核心心性
- `Q8-Q12`：判定五行行事相
- `Q13-Q16` 与 `Q18`：判定修行动机

回答规则：

- 每题只能回答 `A / B / C / D`
- 不允许开放式作答
- 不允许模型自由解释角色性格后再代选

## 2.3 登记结果结构

登记完成后，系统需要输出两层结果：

### 用户可读结果

- 本命心性
- 次命心性
- 行事相
- 修行动机
- 灵根判定
- 一段简短总结语

### 标准档案结果

统一使用 `registration_record` 结构，作为持久化和后续初始化角色数值的唯一标准输入。

核心字段包括：

- `core_temperament`
- `secondary_temperament`
- `behavior_aspect`
- `cultivation_motive`
- `five_element_scores`
- `spirit_root_result`
- `confidence`
- `summary`

## 2.4 工程落地约束

- 问卷 skill 面向玩家，不面向开发者。
- 用户阅读 skill 并作答。
- skill 私下计分，不向用户暴露完整计分过程。
- 最终返回标准 `registration_record`。
- 若环境支持持久化，系统应直接保存该记录。

## 三、心性、行事相与动机系统

## 3.1 十大核心心性

每个心性绑定一个主五行与副五行，用于后续五行分数修正。

| 心性 | 主五行 | 副五行 | 气质说明 |
| --- | --- | --- | --- |
| 守戒型 | 金 | 土 | 重边界、重规矩、重秩序 |
| 断锋型 | 金 | 火 | 果决、锋利、敢于正面斩断 |
| 扶生型 | 木 | 水 | 重护持、重恢复、重成全 |
| 向荣型 | 木 | 火 | 进取、生长、持续向上 |
| 潜渊型 | 水 | 土 | 潜伏、耐心、先看势 |
| 观澜型 | 水 | 木 | 善观察、善判断、善调度 |
| 炽心型 | 火 | 木 | 热烈、执着、有强驱动 |
| 争胜型 | 火 | 金 | 好胜、要强、敢争先 |
| 镇岳型 | 土 | 金 | 稳、重、能扛、能压阵 |
| 守成型 | 土 | 水 | 重积累、重根基、重保全 |

### 核心心性判定规则

- 分数最高者为 `core_temperament`
- 分数第二者为 `secondary_temperament`

## 3.2 十五种行事相

行事相由五行行为倾向直接推导，采用 5 个单元素相与 10 个双元素相，共 15 种。

### 单元素相

- `metal / 裁断`
- `wood / 生发`
- `water / 观势`
- `fire / 烈行`
- `earth / 镇持`

### 双元素相

- `metal-wood / 砺生`
- `metal-water / 冷鉴`
- `metal-fire / 烈锋`
- `metal-earth / 守序`
- `wood-water / 润悟`
- `wood-fire / 荣焰`
- `wood-earth / 厚培`
- `water-fire / 潜燃`
- `water-earth / 潜守`
- `fire-earth / 炽垒`

### 行事相判定规则

对 `metal / wood / water / fire / earth` 五个分数排序后：

- 若第一名比第二名高 `>= 3`，输出单元素相
- 若第一名与第二名差值 `<= 2`，输出前两名组成的双元素相
- 若第二名与第三名同分，则优先使用本命心性的主五行作为排序裁决

## 3.3 十大修行动机

当前定稿的修行动机共有 10 个：

- 求长生
- 证大道
- 求真知
- 护所爱
- 济世人
- 雪旧恨
- 争高低
- 振门庭
- 逆天命
- 求逍遥

其中，原先方案中的“争一口气”统一改为：

- `争高低`

### 修行动机判定规则

- 分数最高者为 `cultivation_motive`
- 若领先稳定且 `Q18` 与前两名一致，则置信度更高

## 3.4 五行修正规则

行为五行计分完成后，再叠加心性修正：

- 本命心性：主五行 `+3`，副五行 `+1`
- 次命心性：主五行 `+1`

## 3.5 灵根判定规则

根据最终五行分数排序：

- 第一名领先第二名 `>= 3`：`单灵根`
- 第一名领先第二名 `1~2`：`偏灵根`
- 第一名与第二名同分：`双灵根`

示例：

- `木单灵根`
- `火偏灵根`
- `水土双灵根`

## 3.6 置信度规则

最终档案包含四层置信度：

- `core`
- `behavior`
- `motive`
- `overall`

约定：

- 若本命心性领先明显且 `Q17` 对应稳定，`core=high`
- 若行为五行前两名稳定且第三名明显落后，`behavior=high`
- 若动机领先明显且 `Q18` 对应稳定，`motive=high`
- 任一层过低，则 `overall` 下降

## 四、五行系统定位

## 4.1 五行不是职业锁

- 五行不绑定某一种兵器。
- 五行不决定“能不能练某种外功”。
- 五行主要决定：
  - 修炼成长方向
  - 数值偏向
  - 功法适性
  - 战斗风格染色

## 4.2 五行的功能定位

| 五行 | 核心含义 | 常见风格 |
| --- | --- | --- |
| 金 | 裁断、精准、破甲、决断 | 高命中、斩断、破防、点杀 |
| 木 | 生长、恢复、韧性、延展 | 持续成长、续航、培育、连段 |
| 水 | 观察、流动、控制、后手 | 控场、游走、卸力、侦查 |
| 火 | 爆发、执行、压制、炼化 | 爆发、追击、压血线、强攻 |
| 土 | 稳固、防守、承载、镇压 | 抗压、护体、打断、站场 |

## 4.3 五行与武器的关系

- 五行不决定“拿什么武器”。
- 五行决定“同一把武器被用成什么风格”。

例如同样是剑修：

- 金灵根剑修：更偏精准与破防
- 水灵根剑修：更偏变招与控节奏
- 火灵根剑修：更偏爆发与追击
- 土灵根剑修：更偏稳守与反打
- 木灵根剑修：更偏成长与持续压制

## 五、角色主属性系统

## 5.1 主属性数量

当前定稿为 8 个主属性：

- 根骨
- 体魄
- 灵元
- 神识
- 悟性
- 道心
- 身法
- 兵魄

## 5.2 初始数值原则

- 主属性成长暂不设硬上限
- 新注册角色建议总点数：`400`
- 单项初始建议范围：`30-70`
- `50` 视为新注册角色在同境界下的初始平均值

推荐初始强度解释：

- `30-49`：偏弱或暂未发展
- `50-59`：平均水平
- `60-74`：明显优秀
- `75-89`：非常突出
- `90+`：罕见特长

## 5.3 八大主属性定义

### 根骨

定义：吸收灵气、转化资源、承载修炼成果的底子。

主要影响：

- 修炼效率
- 灵力回复
- 丹药与灵石转化率
- 突破承载能力

### 体魄

定义：肉身强度、承压能力、近战硬度。

主要影响：

- 气血上限
- 外防与韧性
- 控制抗性
- 重兵稳定性

### 灵元

定义：灵力储量与灵力输出质量。

主要影响：

- 灵力上限
- 术法威力
- 持续施法能力
- 部分暴伤收益

### 神识

定义：感知、判断、御器、命中与控场能力。

主要影响：

- 命中
- 控制强度
- 侦测与识破
- 会心

### 悟性

定义：理解功法、拆解招式、举一反三的能力。

主要影响：

- 功法学习速度
- 熟练度获取速度
- 顿悟概率
- 少量会心与暴伤

### 道心

定义：心境稳定、意志强度、抗压与抗偏移能力。

主要影响：

- 突破稳定
- 控制抗性
- 心魔抗性
- 护心

### 身法

定义：速度、步法、闪转腾挪与攻防节奏。

主要影响：

- 速度
- 闪避
- 追击与脱战
- 会心

### 兵魄

定义：兵器掌握、外功杀伤、招式稳定与兵道理解。

主要影响：

- 外功伤害倍率
- 招架与破招能力
- 兵器熟练成长
- 会心与暴伤

## 六、详细属性系统

## 6.1 第一版详细属性池

当前定稿的 15 个详细属性如下：

- 气血上限
- 灵力上限
- 灵力回复
- 外功伤害倍率
- 术法伤害倍率
- 命中
- 闪避
- 速度
- 韧性
- 控制强度
- 控制抗性
- 突破稳定
- 会心
- 暴伤
- 护心

## 6.2 详细属性公式

### 基础资源

- `气血上限 = 200 + 8*体魄 + 2*根骨 + 2*道心`
- `灵力上限 = 120 + 8*灵元 + 2*根骨 + 2*神识`
- `灵力回复 = 2 + 0.10*根骨 + 0.08*灵元 + 0.05*道心`

### 攻击效率

- `外功伤害倍率 = 100% + 0.70*兵魄 + 0.20*体魄 + 0.10*身法`
- `术法伤害倍率 = 100% + 0.65*灵元 + 0.20*神识 + 0.15*悟性`

### 命中与机动

- `命中 = 75% + 0.12*神识 + 0.08*兵魄 + 0.05*身法`
- `闪避 = 5% + 0.15*身法 + 0.05*神识`
- `速度 = 100 + 0.60*身法 + 0.20*神识`

### 稳定与控制

- `韧性 = 0.40*体魄 + 0.35*道心 + 0.15*兵魄`
- `控制强度 = 0.55*神识 + 0.25*悟性 + 0.20*灵元`
- `控制抗性 = 0.45*道心 + 0.30*体魄 + 0.15*神识`
- `突破稳定 = 40 + 0.35*道心 + 0.25*根骨 + 0.20*悟性`

### 暴击相关

- `会心 = 0% + 0.06*神识 + 0.05*身法 + 0.02*悟性 + 0.02*兵魄`
- `暴伤 = 150% + 0.30*兵魄 + 0.15*灵元 + 0.10*悟性`
- `护心 = 0% + 0.06*道心 + 0.04*体魄 + 0.02*根骨`

## 6.3 会心、暴伤、护心约定

### 会心

- 表示暴击触发能力
- 初始基础值固定为 `0%`
- 会心主要由属性、兵器、技能、功法与装备词条获得

### 暴伤

- 表示暴击触发后的伤害倍率
- 初始基础值固定为 `150%`

### 护心

- 表示角色守住心神与气机、降低被暴击概率的能力
- 初始基础值固定为 `0%`
- 护心与韧性不同，不承担抗打断或抗控制职责

## 6.4 对抗判定建议

### 暴击率判定

- `最终暴击率 = clamp(武器/技能基础会心 + 攻方会心 - 守方护心*0.7, 0%, 55%)`

### 暴击伤害判定

- `最终暴击伤害 = 攻方暴伤`

### 控制命中建议

- `控制命中率 = 技能基础概率 + (控制强度 - 控制抗性) * 0.5%`

### 突破建议

- `突破成功修正 = (突破稳定 - 境界难度) * 0.6%`

### 境界成长与突破类型

- 境界只直接作用于 `8 个主属性`，不直接作用于 `5 个五行属性`
- 外部加成（功法、装备、宗门、临时 buff）不吃境界倍率
- 最终主属性建议公式：`最终主属性 = (基础主属性 + 境界固定成长) × 境界倍率 + 外部加成`

### 第一版境界范围

- 第一版只实现 `炼气 / 筑基 / 金丹` 三个大境界
- 每个大境界细分为 `前期 / 中期 / 后期`
- 小层级不承担明显玩法分化，只提供少量基础主属性成长

### 境界倍率说明

- 境界倍率用于表现跨大境界差异，即便主属性接近，高境界角色仍应略强
- 境界倍率只取当前大境界，不随外部加成一起放大
- 第一版当前临时境界倍率建议：
  - 炼气：`1.00`（`100%`）
  - 筑基：`1.10`（`110%`）
  - 金丹：`1.25`（`125%`）
- 以上为当前阶段的临时占位数值，后续可继续调优，但必须保持越高境界倍率越高

### 小层级突破

- 小层级修为达到瓶颈后，也需要进行一次普通突破
- 小层级突破不分 `人道 / 地道 / 天道`，只消耗对应境界丹药
- 当前临时命名建议：
  - 炼气期小层级突破丹：`聚气丹`
  - 筑基期小层级突破丹：`凝元丹`
  - 金丹期小层级突破丹：`养丹露`

### 大境界突破类型

- 玩家在大境界突破前主动选择 `人道 / 地道`
- `人道` 与 `地道` 需要不同的突破材料
- `地道` 材料整体更稀有、更难获取
- 大境界突破材料均有优劣品级，系统根据本次投入材料的平均品级修正最终成功率
- 建议结算思路：`突破最终成功率 = 基础概率 + 材料平均品级修正 + 其他修正`
- `人道 / 地道` 失败时只损失材料
- `天道` 不走常规材料堆叠路线，需要完成专门突破任务后才可尝试
- `天道突破` 失败时按突破失败结算，并施加不同程度的临时惩罚
- 失败后的受伤、修为受损等临时负面状态，留待后续 debuff 设计统一展开
- 突破类型不额外提高境界倍率

### 突破记录

- 每次突破都应写入一条 `breakthrough_record`
- 建议字段包括：
  - `timestamp`
  - `target_realm`
  - `breakthrough_method`
  - `outcome`
  - `breakthrough_result`
  - `granted_growth_package`

### 境界固定成长规则

- 每个大境界转阶拥有独立的基础成长包
- 本次突破固定成长：`当前大境界基础成长包 × 突破类型倍率`
- 固定成长包平均分配到 `8 个主属性`
- 当前临时倍率建议：
  - 人道：`1.00`
  - 地道：`1.25`
  - 天道：`1.50`

### 当前临时基础成长包

- `炼气 -> 筑基`：`240`，平均到 8 个主属性后为每项 `+30`
- `筑基 -> 金丹`：`400`，平均到 8 个主属性后为每项 `+50`
- `金丹 -> 元婴`：`640`，平均到 8 个主属性后为每项 `+80`
- `元婴 -> 化神`：`960`，平均到 8 个主属性后为每项 `+120`
- 以上均为当前阶段的临时占位数值，后续可继续调优，但必须保持越高境界的基础成长包越高

### 小层级成长

- 每个大境界内部按 `前期 / 中期 / 后期` 划分
- 小层级不提供明显能力区分，只提供少量基础主属性成长
- 每次小层级提升的成长量 = 当前境界对应突破基础成长包的 `1/3`
- 小层级成长平均分配到 `8 个主属性`
- 小层级成长在结算时统一向上取整

## 七、兵器系统

## 7.1 设计原则

- 五行与兵器分离。
- 兵器不再只保留少量固定职业，而是扩展为 20 种。
- 每种兵器由 3 个主要属性决定其驾驭效率。

推荐权重：

- 主属性：`50%`
- 副属性：`30%`
- 辅属性：`20%`

可用于定义：

- 兵器熟练成长速度
- 兵器招式威力修正
- 兵器架势稳定性

## 7.3 兵器系统说明

### 快兵系

- 剑、双剑、匕首、拳套
- 共同特点：节奏快、变招多、较重视会心与身法

### 重兵系

- 刀、巨刀、斧、锤
- 共同特点：爆发强、压制力高、需要体魄支撑

### 长兵系

- 枪、戟、棍、钩镰
- 共同特点：控距、压线、对站位更敏感

### 柔兵奇兵系

- 鞭、链刃、流星锤、绫
- 共同特点：打法变化大，更适合做控制与特殊机制

### 远奇灵兵系

- 弓、弩、扇、伞
- 共同特点：远程、半法器、反制或功能性更强

## 八、系统间关系

## 8.1 已冻结的角色结构

当前角色结构已经明确为：

- `OC 本体`
- `18 题入界登记结果`
- `心性 + 行事相 + 动机`
- `五行分数 + 灵根判定`
- `8 个主属性`
- `15 个详细属性`
- `自由选择的兵器路线`

- `小层级瓶颈突破与大境界突破路径规则`

## 8.2 推荐的初始化链路

1. 玩家带入自己的 OC
2. 玩家完成 18 题入界登记
3. 系统产出 `registration_record`
4. 系统保存标准档案
5. 根据档案初始化五行倾向与角色属性分布
6. 玩家选择主修兵器路线
7. 后续再由功法、技能、装备、境界继续塑造 build

## 九、当前版本结论

本轮已经确定 Immortal Claw 的角色底层不是“系统生成角色”，而是“玩家携带 OC 入界登记”。

围绕这一原则，目前已经完成以下冻结：

- 18 题固定问卷接入逻辑
- 10 心性、15 行事相、10 动机的判定框架
- 五行与兵器分离
- 8 个主属性模型
- 15 个详细属性模型
- 会心与护心基础值为 `0%`
- 暴伤基础值为 `150%`
- 20 种兵器及其主属性适配

这份文档可作为后续角色系统、战斗系统、功法系统与数值实现的共同基线。
