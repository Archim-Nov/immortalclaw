# 玩家属性与境界设定整理

## 目的

这个文件夹用于把当前已经讨论到相对稳定的玩家属性、境界与突破设定整理成一个更适合继续策划推进的入口。

这里的内容是策划整理稿，不代表代码已经实现。
当前阶段应优先把这里视为讨论基线；旧路线图、旧预览文档和当前原型代码只作为参考。

## 文件索引

- `player-attributes.md`
  - 整理玩家属性的分层、主属性、详细属性和五行属性
- `realms-and-breakthroughs.md`
  - 整理第一版境界范围、小层级成长、大境界突破与突破记录

## 当前边界

本文件夹当前只整理以下内容：

- 玩家主属性与详细属性
- 五行属性与其衍生关系
- 第一版境界范围
- 小层级成长与瓶颈突破
- 大境界突破的基本结构

本文件夹暂不展开以下内容：

- 突破材料具体清单
- 天道任务细节
- 失败后的 debuff 细节
- 五行法术技能表
- 兵器和战斗专项设计

## 当前建议阅读顺序

1. 先读 `player-attributes.md`，明确角色面板怎么构成
2. 再读 `realms-and-breakthroughs.md`，明确角色怎样随着境界成长
3. 若后续要继续细化战斗或法术，再回到原始 spec 查看对应专项文档
