# 玩家属性整理

## 1. 属性系统总览

当前玩家属性分成三层：

- 主属性
  - 角色本体长期成长的核心面板
- 详细属性
  - 由主属性进一步推导出来的战斗和资源属性
- 五行属性
  - 独立于主属性的另一条长期成长线，决定法术和元素偏向

简单理解：

- 主属性回答“这个人本体强在哪里”
- 详细属性回答“战斗和资源结算时具体怎么算”
- 五行属性回答“这个人更偏什么灵气路线”

## 2. 主属性

### 2.1 当前冻结原则

- 主属性不设硬上限
- 主属性是长期量化角色实力的数据
- 新注册角色建议总点数：`400`
- 单项初始建议区间：`30-70`
- `50` 视为新注册角色在同境界下的初始平均值

### 2.2 八个主属性

| 主属性 | 白话解释 | 主要偏向 |
| --- | --- | --- |
| 根骨 | 身体和修炼底子 | 修炼效率、资源转化、突破承载 |
| 体魄 | 肉身强度 | 气血、防御、抗压 |
| 灵元 | 灵力储量和输出质量 | 灵力上限、术法威力 |
| 神识 | 感知和控制能力 | 命中、控制、侦测 |
| 悟性 | 学习和理解能力 | 功法学习、熟练成长、顿悟 |
| 道心 | 心境和稳定性 | 突破稳定、抗心魔、护心 |
| 身法 | 移动和节奏 | 速度、闪避、追击 |
| 兵魄 | 驾驭兵器与外功能力 | 外功伤害、招式稳定 |

### 2.3 当前 P1 实现约定

- 新注册角色先以 `50 x 8 = 400` 作为主属性基线
- `registration_record v2` 里的稳定 taxonomy IDs 会对主属性做 `小幅加性修正`
- 当前主属性修正只读取：
  - `core_temperament_id`
  - `secondary_temperament_id`
  - `behavior_aspect_id`
  - `cultivation_motive_id`
  - `overall confidence`
- 这一步的目标是“让风格有差异”，不是“让注册直接决定强弱层级”
- 因此实现必须同时满足：
  - 总点数仍保持 `400`
  - 单项仍落在 `30-70` 建议区间内

当前 P1 代码约定为：

- 心性和行事相通过其对应的稳定 ID，给八个主属性施加平衡后的偏移
- 修行动机再追加一层小幅倾向修正
- `overall confidence` 只影响偏移强度，不改变偏移方向
- 原始五行分数当前仍不直接改写八个主属性；它们继续保留在五行层，主要用于元素倾向、元素状态和元素抗性链路

## 3. 详细属性

### 3.1 当前定稿的 15 个详细属性

- 气血上限
- 灵力上限
- 灵力回复
- 外功伤害倍率
- 术法伤害倍率
- 命中
- 闪避
- 速度
- 韧性
- 控制强度
- 控制抗性
- 突破稳定
- 会心
- 暴伤
- 护心

### 3.2 当前定位

详细属性不是单独分配点数的面板，而是由主属性公式推导出来的结果。

这样做的好处是：

- 玩家成长时只需要关注更核心的主属性
- 战斗层仍然可以有足够细的结算维度
- 后续调整数值时，主属性和战斗表现的关系更清楚

当前 P1 实现约定：

- 详细属性按冻结公式直接由主属性推导
- 需要小数的条目暂统一保留到 `2` 位小数，避免先在接口层丢失精度

### 3.3 当前重点结算项

目前比较关键的详细属性有：

- `气血上限`
- `灵力上限`
- `突破稳定`
- `会心`
- `暴伤`
- `护心`

其中：

- `会心` 决定更容易触发暴击
- `暴伤` 决定暴击后会打出多重的伤害
- `护心` 主要用来压低对方对你的暴击收益，不负责抗打断

## 4. 五行属性

### 4.1 当前冻结原则

- 五行属性与主属性分离
- 五行属性不设硬上限
- 五行属性是独立长期成长线
- 境界不直接作用于五行属性

### 4.2 初始原则

- 新角色五行总量：`250`
- 默认平均线：`50`

初始参考区间：

- `30-39`：该元素偏弱
- `40-49`：略弱或未成体系
- `50-59`：平均水平
- `60-69`：该元素较强
- `70+`：在新角色与前中期阶段已属于明显专精，后期仍可继续成长

### 4.3 五行属性的作用

五行属性当前主要用于衍生三类结果：

- 元素法术强度
- 元素状态强度
- 元素抗性

当前冻结关系为：

- 本属性决定法术强度
- 本属性与生我属性决定状态强度
- 本属性与克我属性决定抗性

对应当前线性公式：

- `元素法术强度 = 本属性`
- `元素状态强度 = 0.7 * 本属性 + 0.3 * 生我属性`
- `元素抗性 = 0.7 * 本属性 + 0.3 * 克我属性`

## 5. 当前属性系统边界

当前已经相对稳定的内容：

- 主属性不封顶
- 五行属性不封顶
- 主属性、详细属性、五行属性的三层结构
- 八个主属性和十五个详细属性的基本定义
- 五行属性的三类衍生方向

当前仍待后续细化的内容：

- 五行如何进一步修正主属性
- 详细属性在实现层的最终取整和显示方式
- 功法、装备、宗门、buff 的完整乘区顺序
- 五行法术和兵器在战斗中的正式落地
