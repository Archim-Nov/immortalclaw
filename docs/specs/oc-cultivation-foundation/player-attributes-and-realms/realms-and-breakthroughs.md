# 境界与突破整理

## 1. 第一版境界范围

第一版只实现三个大境界：

- 炼气
- 筑基
- 金丹

每个大境界再细分为三个小层级：

- 前期
- 中期
- 后期

当前设计里：

- 大境界负责体现玩法层次和境界差异
- 小层级只负责平滑成长，不承担明显玩法分化

## 2. 境界倍率

### 2.1 作用

境界倍率用于表现跨大境界差异。

简单理解：

- 即便两个角色主属性数值接近
- 更高境界的角色仍然应该略强

### 2.2 当前冻结规则

- 境界倍率只直接作用于 `8 个主属性`
- 境界倍率不直接作用于 `5 个五行属性`
- 境界倍率不放大外部加成
- 突破方式不额外提高境界倍率

当前建议公式：

- `最终主属性 = (基础主属性 + 境界固定成长) × 境界倍率 + 外部加成`

### 2.3 第一版临时境界倍率

- 炼气：`1.00`（`100%`）
- 筑基：`1.10`（`110%`）
- 金丹：`1.25`（`125%`）

这些数值当前只是占位，后续还能继续调，但必须保持“越高境界倍率越高”。

## 3. 小层级成长

### 3.1 当前冻结规则

- 每个大境界内部按 `前期 / 中期 / 后期` 划分
- 小层级不提供明显能力区分，只提供少量基础主属性成长
- 小层级成长平均分配到 `8 个主属性`
- 小层级成长结算时统一向上取整

### 3.2 小层级瓶颈突破

- 小层级修为达到瓶颈后，也需要进行一次普通突破
- 小层级突破不分 `人道 / 地道 / 天道`
- 小层级突破只消耗对应境界丹药

当前临时命名建议：

- 炼气期小层级突破丹：`聚气丹`
- 筑基期小层级突破丹：`凝元丹`
- 金丹期小层级突破丹：`养丹露`

### 3.3 小层级成长量

当前冻结规则：

- 每次小层级提升的成长量 = 当前境界对应突破基础成长包的 `1/3`
- 因为一个大境界内部只有 `前 -> 中`、`中 -> 后` 两次小提升
- 所以一个大境界内部的小成长总量不是完整突破包，而是它的一部分

## 4. 大境界固定成长包

### 4.1 当前规则

- 每个大境界转阶拥有独立基础成长包
- 固定成长包平均分配到 `8 个主属性`

### 4.2 当前临时基础成长包

- `炼气 -> 筑基`：`240`，平均后每项 `+30`
- `筑基 -> 金丹`：`400`，平均后每项 `+50`
- `金丹 -> 元婴`：`640`，平均后每项 `+80`
- `元婴 -> 化神`：`960`，平均后每项 `+120`

说明：

- 第一版当前只做到 `炼气 / 筑基 / 金丹`
- 后两档仍然可以保留为后续占位
- 这些数值目前只是策划占位，不是最终平衡值

## 5. 大境界突破

### 5.1 人道 / 地道

当前冻结规则：

- 玩家在大境界突破前主动选择 `人道` 或 `地道`
- `人道` 与 `地道` 需要不同的突破材料
- `地道` 材料整体更稀有、更难获得
- 所有突破材料都有优劣品级
- 系统根据本次投入材料的平均品级修正最终成功率

建议结算思路：

- `突破最终成功率 = 基础概率 + 材料平均品级修正 + 其他修正`

失败结果：

- `人道 / 地道` 失败时只损失材料

### 5.2 天道

当前冻结规则：

- `天道` 不走普通材料堆叠路线
- `天道` 可遇不可求，需要完成专门突破任务后才可尝试
- `天道突破` 失败时直接按突破失败结算
- `天道突破` 失败后会施加不同程度的临时惩罚

目前暂不展开：

- 天道任务怎么触发
- 天道任务的具体流程
- 天道失败后到底给哪些 debuff

## 6. 突破记录

每次突破都应写入一条 `breakthrough_record`。

当前建议字段包括：

- `timestamp`
- `target_realm`
- `breakthrough_method`
- `outcome`
- `breakthrough_result`
- `granted_growth_package`

这些字段当前主要用于：

- 存档记录
- 角色履历展示
- 后续条件判断
- 失败结果追踪

## 7. 当前边界

当前已经相对稳定的内容：

- 第一版只有 `炼气 / 筑基 / 金丹`
- 小层级采用 `前期 / 中期 / 后期`
- 小层级突破和大境界突破是两套不同规则
- 大境界倍率只作用主属性
- 大境界突破采用 `人道 / 地道 / 天道` 分层
- 突破记录需要单独保存

当前仍待后续细化的内容：

- 小层级突破丹药正式命名与产出
- 人道 / 地道突破材料清单
- 天道任务和失败 debuff 细则
- 大境界倍率与成长包的最终平衡值
- 突破基础概率和其他修正项的正式公式
