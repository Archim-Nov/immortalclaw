# Immortal Claw 角色与属性系统策划案

## 文档目标

本文档聚焦角色接入、入界登记、五行定位、主属性与详细属性系统，作为后续角色初始化、成长曲线与数值实现的基础依据。

## 一、角色接入原则

### 1.1 OC 接入而非系统造角

- 游戏不以“创建新角色”作为核心入口。
- 玩家默认携带自己的 OC 进入世界。
- 系统负责将玩家 OC 映射成可执行的修仙角色档案，而不是替玩家重新设计角色。

### 1.2 不使用 LLM 自动判性格

- OC 判定采用固定问卷。
- 不允许模型根据开放式描述自由判断性格。
- 玩家必须基于自己的 OC，按 `A / B / C / D` 回答题目。
- 系统依照固定计分表生成唯一标准档案。

### 1.3 初始阶段不制造强度碾压

- 登记阶段只决定角色的成长方向与长板结构。
- 不应在注册时制造总强度差距。
- 不同 OC 的差异应体现为风格不同，而不是天生高人一等。

## 二、入界登记系统

### 2.1 登记目标

让玩家的 OC 在进入 Immortal Claw 世界前，通过一套固定流程生成标准 `registration_record`，并作为后续角色初始化的唯一可信输入。

### 2.2 登记流程

当前定稿为 18 题：

- `Q1-Q7` 与 `Q17`：判定核心心性
- `Q8-Q12`：判定行事相与五行行为倾向
- `Q13-Q16` 与 `Q18`：判定修行动机

作答规则：

- 只允许 `A / B / C / D`
- 不允许开放式长答
- 不允许中途改写题意
- 不允许将判定逻辑暴露给用户

### 2.3 登记结果

登记结果分为两层：

#### 玩家可读结果

- 本命心性
- 次命心性
- 行事相
- 修行动机
- 灵根判定
- 简短总结语

#### 标准持久化结果

统一使用 `registration_record` 结构，核心字段为：

- `core_temperament`
- `secondary_temperament`
- `behavior_aspect`
- `cultivation_motive`
- `five_element_scores`
- `spirit_root_result`
- `confidence`
- `summary`

### 2.4 工程约束

- skill 面向玩家，不面向开发者。
- skill 私下完成计分，不公开完整分配细节。
- skill 输出必须可直接保存。
- 若环境支持持久化，系统应立即保存 `registration_record`。

## 三、心性、行事相与动机系统

### 3.1 十大核心心性

| 心性 | 主五行 | 副五行 | 气质说明 |
| --- | --- | --- | --- |
| 守戒型 | 金 | 土 | 重边界、重规矩、重秩序 |
| 断锋型 | 金 | 火 | 果决、锋利、敢于正面斩断 |
| 扶生型 | 木 | 水 | 重护持、重恢复、重成全 |
| 向荣型 | 木 | 火 | 进取、生长、持续向上 |
| 潜渊型 | 水 | 土 | 潜伏、耐心、先看势 |
| 观澜型 | 水 | 木 | 善观察、善判断、善调度 |
| 炽心型 | 火 | 木 | 热烈、执着、有强驱动 |
| 争胜型 | 火 | 金 | 好胜、要强、敢争先 |
| 镇岳型 | 土 | 金 | 稳、重、能扛、能压阵 |
| 守成型 | 土 | 水 | 重积累、重根基、重保全 |

判定规则：

- 分数最高者为 `core_temperament`
- 分数第二者为 `secondary_temperament`

### 3.2 十五种行事相

当前定稿采用 5 个单元素相与 10 个双元素相，共 15 种。

#### 单元素相

- `metal / 裁断`
- `wood / 生发`
- `water / 观势`
- `fire / 烈行`
- `earth / 镇持`

#### 双元素相

- `metal-wood / 砺生`
- `metal-water / 冷鉴`
- `metal-fire / 烈锋`
- `metal-earth / 守序`
- `wood-water / 润悟`
- `wood-fire / 荣焰`
- `wood-earth / 厚培`
- `water-fire / 潜燃`
- `water-earth / 潜守`
- `fire-earth / 炽垒`

判定规则：

- 若第一元素分数比第二高 `>= 3`，输出单元素相
- 若第一与第二差值 `<= 2`，输出双元素相
- 若第二与第三同分，则用本命心性的主五行做第一裁决

### 3.3 十大修行动机

- 求长生
- 证大道
- 求真知
- 护所爱
- 济世人
- 雪旧恨
- 争高低
- 振门庭
- 逆天命
- 求逍遥

约定：

- 原方案中的“争一口气”统一替换为 `争高低`
- 分数最高者为 `cultivation_motive`

### 3.4 五行修正与灵根判定

行为五行分数生成后，再叠加心性修正：

- 本命心性：主五行 `+3`，副五行 `+1`
- 次命心性：主五行 `+1`

灵根判定规则：

- 第一名领先第二名 `>= 3`：`单灵根`
- 第一名领先第二名 `< 3`：`双灵根`
- 双灵根按前两名五行展示，分高者在前；若同分，则优先用本命心性的主五行，再按固定顺序 `金木水火土`

### 3.5 置信度

最终档案包含：

- `core`
- `behavior`
- `motive`
- `overall`

其中：

- 本命心性稳定则 `core` 更高
- 行事相前两位清晰则 `behavior` 更高
- 修行动机领先稳定则 `motive` 更高
- 任一层过低会拉低 `overall`

## 四、五行系统定位

### 4.1 五行不是职业锁

- 五行与兵器系统分离。
- 灵根不决定“拿什么兵器”。
- 五行不限制“能不能练某种外功”。

### 4.2 五行的作用

五行当前用于定义：

- 内在气机偏向
- 成长方向与资源转化风格
- 功法适性
- 战斗风格染色

### 4.3 五行功能定义

| 五行 | 核心含义 | 常见风格 |
| --- | --- | --- |
| 金 | 裁断、精准、破甲、决断 | 高命中、斩断、点杀 |
| 木 | 生长、恢复、韧性、延展 | 续航、成长、培育、连段 |
| 水 | 观察、流动、控制、后手 | 控场、游走、卸力、侦查 |
| 火 | 爆发、执行、压制、炼化 | 爆发、追击、强攻 |
| 土 | 稳固、防守、承载、镇压 | 抗压、护体、打断、站场 |

## 五、主属性系统

### 5.1 八大主属性

当前定稿为：

- 根骨
- 体魄
- 灵元
- 神识
- 悟性
- 道心
- 身法
- 兵魄

### 5.2 初始数值原则

- 主属性成长暂不设硬上限
- 新注册角色建议总点数：`400`
- 单项初始建议区间：`30-70`
- `50` 视为新注册角色在同境界下的初始平均值

### 5.3 各主属性定义

#### 根骨

吸收灵气、转化资源、承载修炼成果的底子。

主要影响：

- 修炼效率
- 灵力回复
- 丹药与灵石转化率
- 突破承载能力

#### 体魄

肉身强度、承压能力、近战硬度。

主要影响：

- 气血上限
- 外防与韧性
- 控制抗性
- 重兵稳定性

#### 灵元

灵力储量与灵力输出质量。

主要影响：

- 灵力上限
- 术法威力
- 持续施法
- 部分暴伤

#### 神识

感知、判断、御器与控场能力。

主要影响：

- 命中
- 控制强度
- 侦测与识破
- 会心

#### 悟性

理解功法、拆解招式、举一反三的能力。

主要影响：

- 功法学习速度
- 熟练成长
- 顿悟概率
- 少量会心与暴伤

#### 道心

心境稳定、意志强度、抗压与抗偏移能力。

主要影响：

- 突破稳定
- 控制抗性
- 心魔抗性
- 护心

#### 身法

移动、步法与攻防节奏能力。

主要影响：

- 速度
- 闪避
- 追击与脱战
- 会心

#### 兵魄

兵器掌握、外功杀伤与招式稳定度。

主要影响：

- 外功伤害倍率
- 兵器熟练成长
- 招架与破招
- 会心与暴伤

## 六、详细属性系统

### 6.1 当前定稿的 15 个详细属性

- 气血上限
- 灵力上限
- 灵力回复
- 外功伤害倍率
- 术法伤害倍率
- 命中
- 闪避
- 速度
- 韧性
- 控制强度
- 控制抗性
- 突破稳定
- 会心
- 暴伤
- 护心

### 6.2 详细属性公式

#### 基础资源

- `气血上限 = 200 + 8*体魄 + 2*根骨 + 2*道心`
- `灵力上限 = 120 + 8*灵元 + 2*根骨 + 2*神识`
- `灵力回复 = 2 + 0.10*根骨 + 0.08*灵元 + 0.05*道心`

#### 攻击效率

- `外功伤害倍率 = 100% + 0.70*兵魄 + 0.20*体魄 + 0.10*身法`
- `术法伤害倍率 = 100% + 0.65*灵元 + 0.20*神识 + 0.15*悟性`

#### 命中与机动

- `命中 = 75% + 0.12*神识 + 0.08*兵魄 + 0.05*身法`
- `闪避 = 5% + 0.15*身法 + 0.05*神识`
- `速度 = 100 + 0.60*身法 + 0.20*神识`

#### 稳定与控制

- `韧性 = 0.40*体魄 + 0.35*道心 + 0.15*兵魄`
- `控制强度 = 0.55*神识 + 0.25*悟性 + 0.20*灵元`
- `控制抗性 = 0.45*道心 + 0.30*体魄 + 0.15*神识`
- `突破稳定 = 40 + 0.35*道心 + 0.25*根骨 + 0.20*悟性`

#### 暴击相关

- `会心 = 0% + 0.06*神识 + 0.05*身法 + 0.02*悟性 + 0.02*兵魄`
- `暴伤 = 150% + 0.30*兵魄 + 0.15*灵元 + 0.10*悟性`
- `护心 = 0% + 0.06*道心 + 0.04*体魄 + 0.02*根骨`

### 6.3 会心、暴伤、护心规则

#### 会心

- 表示暴击触发倾向
- 基础值固定为 `0%`

#### 暴伤

- 表示暴击触发后的伤害倍率
- 基础值固定为 `150%`

#### 护心

- 表示守住心神与气机、降低被暴击概率的能力
- 基础值固定为 `0%`
- 与韧性分工不同，不负责抗打断与抗控制

### 6.4 当前建议的底层判定

- `最终暴击率 = clamp(武器/技能基础会心 + 攻方会心 - 守方护心*0.7, 0%, 55%)`
- `最终暴击伤害 = 攻方暴伤`
- `控制命中率 = 技能基础概率 + (控制强度 - 控制抗性) * 0.5%`
- `突破成功修正 = (突破稳定 - 境界难度) * 0.6%`

## 6.5 境界成长与突破框架

### 境界成长规则

- 境界只直接作用于 `8 个主属性`，不直接作用于 `5 个五行属性`
- 外部加成（功法、装备、宗门、临时 buff）不吃境界倍率
- 最终主属性建议公式：`最终主属性 = (基础主属性 + 境界固定成长) × 境界倍率 + 外部加成`

### 第一版境界范围

- 第一版只实现 `炼气 / 筑基 / 金丹` 三个大境界
- 每个大境界细分为 `前期 / 中期 / 后期`
- 小层级不承担明显玩法分化，只提供少量基础主属性成长

### 境界倍率说明

- 境界倍率用于表现跨大境界差异，即便主属性接近，高境界角色仍应略强
- 境界倍率只取当前大境界，不随外部加成一起放大
- 第一版当前临时境界倍率建议：
  - 炼气：`1.00`（`100%`）
  - 筑基：`1.10`（`110%`）
  - 金丹：`1.25`（`125%`）
- 以上为当前阶段的临时占位数值，后续可继续调优，但必须保持越高境界倍率越高

### 小层级突破

- 小层级修为达到瓶颈后，也需要进行一次普通突破
- 小层级突破不分 `人道 / 地道 / 天道`，只消耗对应境界丹药
- 当前临时命名建议：
  - 炼气期小层级突破丹：`聚气丹`
  - 筑基期小层级突破丹：`凝元丹`
  - 金丹期小层级突破丹：`养丹露`

### 大境界突破类型

- 玩家在大境界突破前主动选择 `人道 / 地道`
- `人道` 与 `地道` 需要不同的突破材料
- `地道` 材料整体更稀有、更难获取
- 大境界突破材料均有优劣品级，系统根据本次投入材料的平均品级修正最终成功率
- 建议结算思路：`突破最终成功率 = 基础概率 + 材料平均品级修正 + 其他修正`
- `人道 / 地道` 失败时只损失材料
- `天道` 不走常规材料堆叠路线，需要完成专门突破任务后才可尝试
- `天道突破` 失败时按突破失败结算，并施加不同程度的临时惩罚
- 失败后的受伤、修为受损等临时负面状态，留待后续 debuff 设计统一展开
- 突破类型不额外提高境界倍率

### 突破记录

- 每次突破都应写入一条 `breakthrough_record`
- 建议字段包括：
  - `timestamp`
  - `target_realm`
  - `breakthrough_method`
  - `outcome`
  - `breakthrough_result`
  - `granted_growth_package`

### 境界固定成长包

- 每个大境界转阶拥有独立的基础成长包
- 本次突破固定成长：`当前大境界基础成长包 × 突破类型倍率`
- 固定成长包平均分配到 `8 个主属性`
- 当前临时倍率建议：
  - 人道：`1.00`
  - 地道：`1.25`
  - 天道：`1.50`

### 当前临时基础成长包

- `炼气 -> 筑基`：`240`，平均到 8 个主属性后为每项 `+30`
- `筑基 -> 金丹`：`400`，平均到 8 个主属性后为每项 `+50`
- `金丹 -> 元婴`：`640`，平均到 8 个主属性后为每项 `+80`
- `元婴 -> 化神`：`960`，平均到 8 个主属性后为每项 `+120`
- 以上均为当前阶段的临时占位数值，后续可继续调优，但必须保持越高境界的基础成长包越高

### 小层级成长

- 每个大境界内部按 `前期 / 中期 / 后期` 划分
- 小层级不提供明显能力区分，只提供少量基础主属性成长
- 每次小层级提升的成长量 = 当前境界对应突破基础成长包的 `1/3`
- 小层级成长平均分配到 `8 个主属性`
- 小层级成长在结算时统一向上取整
