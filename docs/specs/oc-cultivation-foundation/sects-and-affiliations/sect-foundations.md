# 宗门基础设定

## 1. 宗门在第一版中的定位

当前讨论里，宗门不是单纯的属性加成表，也不是一次性剧情节点。
它更像一个长期组织系统，主要承担三类作用：

- 成长组织
  - 给玩家提供落脚点、修行资源和后续成长入口
- 身份路线
  - 让玩家决定自己是加入正道、魔道，还是始终做散修
- 社会系统
  - 为后续的成员关系、职位权限、宗门任务和宗门管理留出入口

简单理解：

- 玩家属性、境界，决定“这个人有多强”
- 宗门，决定“这个人站在哪边、跟谁混、以后能走什么路”

在程序上也可以先用很简单的方式理解：

- 角色身上有一条“当前宗门归属”
- 宗门本身是一类独立对象
- 后面再慢慢给宗门挂上资源、任务、职位和路线

## 2. 第一版宗门成长路线

### 2.1 练气期

练气期为新玩家提供 4 个固定预设宗门，作为前期落脚点。

当前冻结规则：

- 练气期可以选择加入预设宗门
- 练气期也允许一直保持散修
- 练气期不开放自建宗门
- 预设宗门主要承担“引导门派”的作用，不要求玩家一开始就做复杂 build 选择

### 2.2 筑基期

当玩家修炼到筑基期后，宗门选择开始变得更自由。

当前冻结规则：

- 玩家可以继续留在原有宗门
- 玩家可以退出宗门后转为散修
- 玩家可以退出宗门后开山立派

### 2.3 金丹期

金丹期当前只保留一个方向性结论：

- 玩家会在已有宗门基础上继续扩大影响力和成长空间

这部分的资源、权限和规模玩法暂时还没有展开。

## 3. 预设宗门入口规则

### 3.1 数量与立场

第一版预设 4 个固定宗门。

当前冻结规则：

- 预设宗门一共 4 个
- 其中 2 个为正道宗门
- 其中 2 个为魔道宗门

这样设计的目的很直接：

- 让世界一开始就有正魔对立感
- 同时保证两边都有去处，不会显得哪边内容明显更少

### 3.2 门派调性

当前已经明确，预设宗门不应设计成天下闻名的大宗门。

当前冻结规则：

- 第一版的预设宗门应采用“地方性小门派”的风格
- 它们更像新手在本地能接触到的修行组织
- 不适合使用过于恢弘、过于顶级仙门感的名字

简单理解：

- 世界里可以有大宗门
- 但新手刚进入服务器时，先接触到的是本地小门派

### 3.3 入门门槛

当前冻结规则：

- 练气期加入预设宗门几乎无门槛
- 宗门不承担过重的新手筛选功能

这样做的原因是：

- 给玩家一个轻量入口
- 不让新手在进入世界初期就被复杂条件拦住

### 3.4 第一版预设宗门

第一版的 4 个预设宗门，当前先作为“新手落脚点”和“世界立场入口”存在。

当前冻结名单：

- `栖云观`
  - 正道
  - 山中小观，门风清静，重规矩，也重心性。
- `白溪门`
  - 正道
  - 依溪而居的小门派，行事务实，待人平和，重日常修行。
- `枯骨堂`
  - 魔道
  - 偏行阴秘之术的小魔门，门人寡言冷厉，行事隐狠。
- `血藤寨`
  - 魔道
  - 盘踞荒野的魔修势力，门风粗烈，崇尚强弱分明。

当前这一层只冻结：

- 宗门名字
- 正魔立场
- 一句话气质

暂时还没有冻结：

- 各宗门的详细历史
- 各宗门的具体修行方向
- 各宗门的正式玩法差异与数值加成

## 4. 散修路线

第一版明确保留散修路线。

当前冻结规则：

- 玩家可以一直不加入任何宗门
- 玩家可以长期以散修身份自行修炼
- 玩家到了筑基期后，也可以在散修状态下准备开山立派

在程序上可以把这件事理解为：

- 角色的“当前宗门归属”允许为空
- 归属为空时，角色就是散修

## 5. 自建宗门

### 5.1 第一版范围

第一版确定支持玩家自建宗门，但从轻量版开始。

当前冻结规则：

- 第一版允许玩家开山立派
- 自建宗门先采用轻量版设计
- 暂时不追求一上来就做完整建筑系统、复杂战争系统和重经营系统

简单理解：

- 先让玩家“能建起来”
- 再考虑宗门“如何做大做强”

### 5.2 解锁时机

当前冻结规则：

- 自建宗门不在练气期开放
- 玩家达到筑基期后，才开放退宗与开山立派

### 5.3 建立条件

当前冻结规则：

- 开山立派的成立条件，第一版只看一笔灵石和材料
- 这笔资源本质上用于建立宗门福地
- 不与境界、声望、复杂人脉系统强绑定

简单理解：

- 创建门槛低
- 真正的难点不在“能不能注册一个宗门”
- 而在“这个宗门后面能不能发展下去”

### 5.4 宗门方向

当前已明确一个设计边界：

- 创建宗门时，未来可能会记录“宗门方向”这一类标签
- 但这一层暂时不做深度冻结
- 目前不急着把宗门方向和具体玩法、数值效果绑死

## 6. 玩家与宗门的归属关系

当前冻结规则：

- 一个角色同一时间只能属于一个宗门
- 退宗之后，才能加入别的宗门
- 退宗之后，才能开山立派

这条规则的好处很简单：

- 容易理解
- 容易实现
- 不会出现一个角色同时吃多个宗门加成的混乱情况

如果用很白的话说，就是：

- 角色同一时间只能挂一块宗门牌子

## 7. 宗门职位与权限

### 7.1 第一版职位结构

第一版宗门内部职位，当前冻结为 4 层：

- `掌门`
- `长老`
- `内门弟子`
- `外门弟子`

简单理解：

- `掌门` 是宗门负责人
- `长老` 是高层管理和管理员层
- `内门弟子` 是核心培养层
- `外门弟子` 是普通成员与新入门成员

### 7.2 自建宗门的初始职位

当前冻结规则：

- 玩家自建宗门后，创建者自动成为 `掌门`

这条规则很自然，也方便实现。
程序上可以理解为：

- 创建宗门时，系统同时创建第一条成员记录
- 这条记录的职位就是 `掌门`

### 7.3 预设宗门的默认入门职位

当前冻结规则：

- 玩家加入预设宗门后，默认身份是 `外门弟子`

简单理解：

- 刚入门先从外围开始
- 后续再通过贡献或任命往上走

### 7.4 掌门权限

当前冻结规则：

- `掌门` 是宗门最高权限
- `掌门` 可以提拔 `长老 / 内门弟子 / 外门弟子`
- `掌门` 可以移除 `长老 / 内门弟子 / 外门弟子`

简单理解：

- 掌门负责核心人事和关键决策

### 7.5 长老权限

当前冻结规则：

- `长老` 是管理员层
- `长老` 的人数不能无限增加
- `长老` 数量应与宗门规模挂钩
- `长老` 可以提拔 `外门弟子 -> 内门弟子`
- `长老` 可以移除 `外门弟子`
- `长老` 不能调整 `长老` 和 `掌门` 层级

简单理解：

- 长老负责日常管理
- 但核心权力仍然留在掌门手里

### 7.6 内门与外门的基础玩法差异

当前冻结规则：

- `外门弟子` 主要接基础宗门任务
- `内门弟子` 可以接更核心、更高阶的宗门任务

当前这一层先只冻结“任务权限差异”。
更细的资源权限、宝库权限和传承权限，暂时还没有展开。

### 7.7 晋升方式

当前冻结规则：

- 宗门晋升采用混合制
- 可以通过人事任命晋升
- 也可以通过贡献达标触发自动晋升

当前已明确的人事规则：

- `掌门` 可以直接任命非掌门职位
- `长老` 可以提拔 `外门弟子 -> 内门弟子`

当前已明确的自动晋升规则：

- `外门弟子` 在宗门贡献达标后，可以自动晋升为 `内门弟子`

当前还没有冻结：

- 宗门贡献的具体来源
- 自动晋升的具体阈值
- `内门 -> 长老` 的正式晋升门槛

## 8. 当前已冻结与未冻结内容

### 8.1 已冻结内容

- 宗门在第一版中同时承担成长组织、身份路线和社会系统的入口作用
- 第一版同时支持加入既有宗门、保持散修、以及后续自建宗门
- 练气期提供 4 个固定预设宗门
- 玩家在练气期允许一直做散修
- 玩家到筑基期后可以退宗并开山立派
- 4 个预设宗门采用 2 正道 + 2 魔道
- 4 个预设宗门采用地方性小门派风格
- 练气期加入预设宗门几乎无门槛
- 自建宗门采用轻量版范围
- 开山立派的成立条件为灵石 + 材料，用于建立宗门福地
- 一个角色同一时间只能属于一个宗门
- 第一版宗门职位为 `掌门 / 长老 / 内门弟子 / 外门弟子`
- 自建宗门后，创建者自动成为 `掌门`
- 玩家加入预设宗门后，默认身份是 `外门弟子`
- `掌门` 拥有最高权限，可管理全部非掌门职位
- `长老` 是管理员层，人数随宗门规模限制
- `长老` 可以提拔 `外门弟子 -> 内门弟子`
- `长老` 可以移除 `外门弟子`
- `内门弟子` 与 `外门弟子` 当前至少在宗门任务权限上存在差异
- 宗门晋升采用“人事任命 + 贡献达标自动晋升”的混合制

### 8.2 尚未冻结内容

- 各宗门的具体类型与修行方向
- 宗门资源、贡献和任务系统
- 宗门方向标签是否影响后续功法、任务或突破资源
- 宗门退出的代价与冷却规则
- 自建宗门的维持成本和后续成长规则
- 长老数量和宗门规模的具体换算规则
- 宗门贡献的具体来源与自动晋升阈值
- `内门弟子 -> 长老` 的正式晋升条件

## 9. 下一步建议

最顺的下一步是继续细化宗门内部资源、贡献与任务玩法。

建议顺序：

1. 先定宗门贡献主要从哪里来
2. 再定宗门任务的基础分类
3. 最后再补资源、宝库和更深的职位管理规则

这样推进的好处是，先把宗门真正“能运转起来”的内部循环立住，再慢慢补更重的经营和长期玩法。
