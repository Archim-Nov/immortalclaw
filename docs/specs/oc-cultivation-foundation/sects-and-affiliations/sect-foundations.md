# 宗门基础设定

## 1. 宗门在第一版中的定位

当前讨论里，宗门不是单纯的属性加成表，也不是一次性剧情节点。
它更像一个长期组织系统，主要承担三类作用：

- 成长组织
  - 给玩家提供落脚点、修行资源和后续成长入口
- 身份路线
  - 让玩家决定自己是加入正道、魔道，还是始终做散修
- 社会系统
  - 为后续的成员关系、职位权限、宗门任务和宗门管理留出入口

简单理解：

- 玩家属性、境界，决定“这个人有多强”
- 宗门，决定“这个人站在哪边、跟谁混、以后能走什么路”

在程序上也可以先用很简单的方式理解：

- 角色身上有一条“当前宗门归属”
- 宗门本身是一类独立对象
- 后面再慢慢给宗门挂上资源、任务、职位和路线

## 2. 第一版宗门成长路线

### 2.1 练气期

练气期为新玩家提供 4 个固定预设宗门，作为前期落脚点。

当前冻结规则：

- 练气期可以选择加入预设宗门
- 练气期也允许一直保持散修
- 练气期不开放自建宗门
- 预设宗门主要承担“引导门派”的作用，不要求玩家一开始就做复杂 build 选择

### 2.2 筑基期

当玩家修炼到筑基期后，宗门选择开始变得更自由。

当前冻结规则：

- 玩家可以继续留在原有宗门
- 玩家可以退出宗门后转为散修
- 玩家可以退出宗门后开山立派

### 2.3 金丹期

金丹期当前只保留一个方向性结论：

- 玩家会在已有宗门基础上继续扩大影响力和成长空间

这部分的资源、权限和规模玩法暂时还没有展开。

## 3. 预设宗门入口规则

### 3.1 数量与立场

第一版预设 4 个固定宗门。

当前冻结规则：

- 预设宗门一共 4 个
- 其中 2 个为正道宗门
- 其中 2 个为魔道宗门

这样设计的目的很直接：

- 让世界一开始就有正魔对立感
- 同时保证两边都有去处，不会显得哪边内容明显更少

### 3.2 门派调性

当前已经明确，预设宗门不应设计成天下闻名的大宗门。

当前冻结规则：

- 第一版的预设宗门应采用“地方性小门派”的风格
- 它们更像新手在本地能接触到的修行组织
- 不适合使用过于恢弘、过于顶级仙门感的名字

简单理解：

- 世界里可以有大宗门
- 但新手刚进入服务器时，先接触到的是本地小门派

### 3.3 入门门槛

当前冻结规则：

- 练气期加入预设宗门几乎无门槛
- 宗门不承担过重的新手筛选功能

这样做的原因是：

- 给玩家一个轻量入口
- 不让新手在进入世界初期就被复杂条件拦住

### 3.4 第一版预设宗门

第一版的 4 个预设宗门，当前先作为“新手落脚点”和“世界立场入口”存在。

当前冻结名单：

- `栖云观`
  - 正道
  - 山中小观，门风清静，重规矩，也重心性。
- `白溪门`
  - 正道
  - 依溪而居的小门派，行事务实，待人平和，重日常修行。
- `枯骨堂`
  - 魔道
  - 偏行阴秘之术的小魔门，门人寡言冷厉，行事隐狠。
- `血藤寨`
  - 魔道
  - 盘踞荒野的魔修势力，门风粗烈，崇尚强弱分明。

当前这一层只冻结：

- 宗门名字
- 正魔立场
- 一句话气质

暂时还没有冻结：

- 各宗门的详细历史
- 各宗门的具体修行方向
- 各宗门的正式玩法差异与数值加成

## 4. 散修路线

第一版明确保留散修路线。

当前冻结规则：

- 玩家可以一直不加入任何宗门
- 玩家可以长期以散修身份自行修炼
- 玩家到了筑基期后，也可以在散修状态下准备开山立派

在程序上可以把这件事理解为：

- 角色的“当前宗门归属”允许为空
- 归属为空时，角色就是散修

## 5. 自建宗门

### 5.1 第一版范围

第一版确定支持玩家自建宗门，但从轻量版开始。

当前冻结规则：

- 第一版允许玩家开山立派
- 自建宗门先采用轻量版设计
- 暂时不追求一上来就做完整建筑系统、复杂战争系统和重经营系统

简单理解：

- 先让玩家“能建起来”
- 再考虑宗门“如何做大做强”

### 5.2 解锁时机

当前冻结规则：

- 自建宗门不在练气期开放
- 玩家达到筑基期后，才开放退宗与开山立派

### 5.3 建立条件

当前冻结规则：

- 开山立派的成立条件，第一版只看一笔灵石和材料
- 这笔资源本质上用于建立宗门福地
- 不与境界、声望、复杂人脉系统强绑定

简单理解：

- 创建门槛低
- 真正的难点不在“能不能注册一个宗门”
- 而在“这个宗门后面能不能发展下去”

### 5.4 宗门方向

当前已明确一个设计边界：

- 创建宗门时，未来可能会记录“宗门方向”这一类标签
- 但这一层暂时不做深度冻结
- 目前不急着把宗门方向和具体玩法、数值效果绑死

## 6. 玩家与宗门的归属关系

当前冻结规则：

- 一个角色同一时间只能属于一个宗门
- 退宗之后，才能加入别的宗门
- 退宗之后，才能开山立派

这条规则的好处很简单：

- 容易理解
- 容易实现
- 不会出现一个角色同时吃多个宗门加成的混乱情况

如果用很白的话说，就是：

- 角色同一时间只能挂一块宗门牌子

## 7. 宗门职位与权限

### 7.1 第一版职位结构

第一版宗门内部职位，当前冻结为 4 层：

- `掌门`
- `长老`
- `内门弟子`
- `外门弟子`

简单理解：

- `掌门` 是宗门负责人
- `长老` 是高层管理和管理员层
- `内门弟子` 是核心培养层
- `外门弟子` 是普通成员与新入门成员

### 7.2 自建宗门的初始职位

当前冻结规则：

- 玩家自建宗门后，创建者自动成为 `掌门`

这条规则很自然，也方便实现。
程序上可以理解为：

- 创建宗门时，系统同时创建第一条成员记录
- 这条记录的职位就是 `掌门`

### 7.3 预设宗门的默认入门职位

当前冻结规则：

- 玩家加入预设宗门后，默认身份是 `外门弟子`

简单理解：

- 刚入门先从外围开始
- 后续再通过贡献或任命往上走

### 7.4 掌门权限

当前冻结规则：

- `掌门` 是宗门最高权限
- `掌门` 可以提拔 `长老 / 内门弟子 / 外门弟子`
- `掌门` 可以移除 `长老 / 内门弟子 / 外门弟子`

简单理解：

- 掌门负责核心人事和关键决策

### 7.5 长老权限

当前冻结规则：

- `长老` 是管理员层
- `长老` 的人数不能无限增加
- `长老` 数量应与宗门规模挂钩
- `长老` 可以提拔 `外门弟子 -> 内门弟子`
- `长老` 可以移除 `外门弟子`
- `长老` 不能调整 `长老` 和 `掌门` 层级

简单理解：

- 长老负责日常管理
- 但核心权力仍然留在掌门手里

### 7.6 内门与外门的基础玩法差异

当前冻结规则：

- `外门弟子` 主要接基础宗门任务
- `内门弟子` 可以接更核心、更高阶的宗门任务

当前这一层先只冻结“任务权限差异”。
更细的资源权限、宝库权限和传承权限，暂时还没有展开。

### 7.7 晋升方式

当前冻结规则：

- 宗门晋升采用混合制
- 可以通过人事任命晋升
- 也可以通过贡献达标触发自动晋升

当前已明确的人事规则：

- `掌门` 可以直接任命非掌门职位
- `长老` 可以提拔 `外门弟子 -> 内门弟子`

当前已明确的自动晋升规则：

- `外门弟子` 在宗门贡献达标后，可以自动晋升为 `内门弟子`

当前还没有冻结：

- 宗门贡献的具体来源
- 自动晋升的具体阈值
- `内门 -> 长老` 的正式晋升门槛

## 8. 宗门贡献与任务

### 8.1 宗门贡献的定位

宗门贡献可以先理解成玩家在宗门里的“积分”和“资历”。

它的作用至少包括：

- 作为成员表现的记录
- 作为自动晋升的一部分依据
- 为后续宗门资源、权限和奖励系统预留入口

在程序上也可以先用很简单的方式理解：

- 宗门贡献更适合记录在“成员关系”上
- 也就是记“某个玩家在某个宗门里贡献了多少”
- 而不是只记一个宗门总贡献

### 8.2 第一版贡献来源

当前冻结规则：

- 第一版宗门贡献来源包括：
  - `宗门任务`
  - `捐献丹药`
  - `捐献功法`
- 后期扩展的宗门贡献来源包括：
  - `宗门活动`
  - `战斗表现`

简单理解：

- 做事可以涨贡献
- 上交资源也可以涨贡献

### 8.3 捐献贡献换算规则

当前冻结规则：

- 捐献贡献按品级换算
- 不采用固定表写死每一个物品
- 同品级下，`功法贡献 > 丹药贡献`

简单理解：

- 东西越高级，贡献越高
- 同样都是高品级资源，宗门会更重视“传承类资源”

### 8.4 宗门任务分类

当前冻结规则：

- 第一版宗门任务分为 3 个基础类别：
  - `杂务任务`
  - `修行任务`
  - `讨伐任务`

简单理解：

- `杂务任务` 更偏跑腿、收集、护送和基础宗务
- `修行任务` 更偏采药、炼材、寻法、闭关辅助
- `讨伐任务` 更偏清剿、追杀、镇压和战斗行动

### 8.5 宗门任务等级

当前冻结规则：

- 宗门任务分为 `甲 / 乙 / 丙 / 丁` 四档
- `甲` 为最高档
- `丁` 为最低档

这里的设计思路是：

- 对外表现使用 `甲乙丙丁`
- 让任务等级更有修仙世界的风味

### 8.6 内门与外门的任务权限

当前冻结规则：

- `外门弟子` 可接 `丙 / 丁` 任务
- `内门弟子` 可接 `甲 / 乙 / 丙 / 丁` 任务
- 内门与外门的主要差异，不在任务类别，而在任务等级

这意味着：

- 外门和内门都能参与宗门生活
- 差别主要体现在能接到多高阶的任务

当前这一层还没有冻结：

- 各档任务对应的具体奖励倍率
- 各档任务对应的最低境界建议
- `长老` 和 `掌门` 是否拥有特殊任务池

## 9. 宗门资源系统

### 9.1 设计原则

为了避免宗门系统一开始就过于庞杂，第一版先采用最小闭环设计。

当前建议采用“两库一账”的结构：

- `宗门灵石账`
- `宗门库房`
- `藏经阁`

这样拆开的原因很简单：

- 灵石更像钱，适合单独记成数字池
- 丹药和材料更像消耗品、库存物，适合放在统一库房
- 功法更像传承记录，不适合和普通物资混在一起

### 9.2 两库一账的定义

当前冻结规则：

- `宗门灵石账`
  - 用来记录宗门当前持有的灵石总量
  - 主要承担宗门建设、日常开销和任务奖励的资金池作用
- `宗门库房`
  - 用来存放丹药、材料等可堆叠物资
  - 主要承担任务奖励、日常调拨和资源储备作用
- `藏经阁`
  - 用来记录宗门掌握的功法
  - 主要承担传承保存与后续学习解锁入口作用

简单理解：

- `灵石账` 管钱
- `库房` 管货
- `藏经阁` 管传承

### 9.3 捐献流向

当前冻结规则：

- 捐献灵石时，资源进入 `宗门灵石账`
- 捐献丹药和材料时，资源进入 `宗门库房`
- 捐献功法时，资源进入 `藏经阁`
- 宗门贡献仍然记在成员自己身上，不直接混进宗门库存

这一点很重要，因为它把两类数据分开了：

- `成员贡献` 是成员与宗门关系的数据
- `宗门资源` 是宗门自己持有的数据

### 9.4 最小权限划分

为了先把系统跑顺，当前先冻结一版最小权限规则：

- `掌门`
  - 可以查看 `宗门灵石账 / 宗门库房 / 藏经阁`
  - 可以分配和调拨三者中的资源
- `长老`
  - 可以查看 `宗门灵石账 / 宗门库房 / 藏经阁`
  - 可以处理日常库房调拨和基础任务奖励发放
  - 暂不拥有完整的藏经阁传承分配权
- `内门弟子`
  - 默认不拥有直接调拨权限
  - 主要通过任务奖励、任命授权或后续系统获取资源
- `外门弟子`
  - 默认不拥有直接调拨权限
  - 主要通过任务奖励获取宗门资源

简单理解：

- 掌门管全局
- 长老管日常
- 内外门不直接碰宗门总库存

### 9.5 当前仍未展开的资源细节

当前还没有冻结：

- 灵石账的具体支出分类
- 库房内不同物资的调用优先级
- 藏经阁的学习、复制、借阅或消耗规则
- 长老能处理到什么额度的资源
- 内门弟子是否拥有部分藏经阁阅读权限

## 10. 当前已冻结与未冻结内容

### 10.1 已冻结内容

- 宗门在第一版中同时承担成长组织、身份路线和社会系统的入口作用
- 第一版同时支持加入既有宗门、保持散修、以及后续自建宗门
- 练气期提供 4 个固定预设宗门
- 玩家在练气期允许一直做散修
- 玩家到筑基期后可以退宗并开山立派
- 4 个预设宗门采用 2 正道 + 2 魔道
- 4 个预设宗门采用地方性小门派风格
- 练气期加入预设宗门几乎无门槛
- 自建宗门采用轻量版范围
- 开山立派的成立条件为灵石 + 材料，用于建立宗门福地
- 一个角色同一时间只能属于一个宗门
- 第一版宗门职位为 `掌门 / 长老 / 内门弟子 / 外门弟子`
- 自建宗门后，创建者自动成为 `掌门`
- 玩家加入预设宗门后，默认身份是 `外门弟子`
- `掌门` 拥有最高权限，可管理全部非掌门职位
- `长老` 是管理员层，人数随宗门规模限制
- `长老` 可以提拔 `外门弟子 -> 内门弟子`
- `长老` 可以移除 `外门弟子`
- `内门弟子` 与 `外门弟子` 当前至少在宗门任务权限上存在差异
- 宗门晋升采用“人事任命 + 贡献达标自动晋升”的混合制
- 第一版宗门贡献来源包括宗门任务、捐献丹药、捐献功法
- 后期可再加入宗门活动和战斗表现作为贡献来源
- 捐献贡献按品级换算
- 同品级下，功法贡献高于丹药贡献
- 宗门任务分为 `杂务 / 修行 / 讨伐` 三类
- 宗门任务分为 `甲 / 乙 / 丙 / 丁` 四档
- `外门弟子` 可接 `丙 / 丁` 任务
- `内门弟子` 可接 `甲 / 乙 / 丙 / 丁` 任务
- 宗门资源系统采用“两库一账”
- 灵石进入 `宗门灵石账`
- 丹药和材料进入 `宗门库房`
- 功法进入 `藏经阁`
- 成员贡献与宗门资源分开记录
- `掌门` 可查看并分配三者资源
- `长老` 可查看三者资源，并处理日常库房调拨和基础任务奖励发放

### 10.2 尚未冻结内容

- 各宗门的具体类型与修行方向
- 宗门方向标签是否影响后续功法、任务或突破资源
- 宗门退出的代价与冷却规则
- 自建宗门的维持成本和后续成长规则
- 长老数量和宗门规模的具体换算规则
- 宗门贡献的自动晋升阈值
- `内门弟子 -> 长老` 的正式晋升条件
- 各档任务的奖励、时长和风险差异
- 任务与境界、地区、宗门立场的联动细节
- 灵石账的具体支出结构
- 库房与藏经阁更细的调用权限和额度控制

## 11. 下一步建议

最顺的下一步是等以后需要时，再细化宗门数值和更深的运营规则。

建议顺序：

1. 先定各档任务的奖励结构
2. 再定自动晋升的贡献阈值
3. 最后再补资源额度、宝库和宗门活动规则

这样推进的好处是，先把宗门真正“能运转起来”的内部循环立住，再慢慢补更重的经营和长期玩法。
