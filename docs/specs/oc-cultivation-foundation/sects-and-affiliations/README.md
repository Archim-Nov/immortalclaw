# 宗门设定整理

> 注：本目录中的宗门策划当前仅作为参考方案保留，用于保存讨论思路，不代表当前优先推进方向。

## 目的

这个文件夹用于整理当前已经讨论到相对稳定的宗门设定，作为后续继续细化宗门玩法的入口。

这里的内容是策划整理稿，不代表代码已经实现，也不代表当前一定按此方向推进。
当前阶段应优先把这里视为参考材料；若与当前产品方向或首版范围冲突，应以更轻量的当前方案为准。

- 自建宗门的轻量版范围

- 宗门类型与具体成长方向
- 宗门资源系统的详细数值与细则
- 宗门任务与宗门战争
- 宗门对属性、功法、装备的具体加成规则

## 建议阅读顺序
