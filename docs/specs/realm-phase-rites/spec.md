# 元婴和化神按阶段换做法

化神之后的炼虚、合体、大乘见 `docs/specs/realms-above-spirit/spec.md`。这一份仍停在化神。

## Summary

金丹之后的大境界入口已经分开。这一轮把元婴、化神内部的前期、中期、后期也分开：材料仍走原来的甲级层，做法、地点和失败或反噬不再共用同一颗按钮。

## Problem

线上能走到金丹，元婴和化神的材料和秘境也有了，可是境界一深，做法又并回去了。

- 元婴前期和中期都是回洞府点魂灯再收口。养婴露换成固婴砂，按钮还是那一颗。
- 化神前期和中期都是在宗门驻地铺神纹再落印。神胎露换成化神金章，按钮还是那一颗。
- 金丹后期起的安静摘要按「十二层及以上都是去渡劫」来写。人已经是化神前期或中期，六个时辰的 `nextStep` 仍让他去迎天劫。
- 修为顶满以后，有一条运功回执把内部字段名 `realmPath` 写进了给人看的句子。

## Goals

- 元婴前期走炼婴。地点是宗门驻地或甲级地宫门口，行动是 `refine-nascent`。材料仍是婴火莲、元胎玉、魂灯芯、养婴露，都从甲级四到六层的婴火莲池来。这一阶会成。一个人炼，婴身会挣一下，人挂一点伤。有人在同一处看着，不挂这点伤，见闻里写下这个人。
- 元婴中期才守魂灯。仍是先在自己的洞府点灯，灯亮着再收口，材料在收口时才耗。特殊材料仍是固婴砂。灯灭了不扣材料。
- 元婴后期仍是渡劫。地点仍是荒野或甲级门口。可能失败，材料耗掉，进度退到六成，并留下伤和走火。玩家读到的名字是渡劫，句子里仍能看见天劫。
- 化神前期仍在宗门驻地铺神纹、落印。特殊材料仍是神胎露。一个人落印会挂一点伤。
- 化神中期走守神台。地点是荒野或甲级门口，行动是 `hold-divine-platform`。材料仍是神念晶、天魂丝、神纹石、化神金章，都从甲级七到九层的神纹天隙来。这一阶会成。一个人守会挂一点伤。有人看着则不挂。
- 化神后期仍是目前的顶。安静摘要不再把化神前期、中期送去渡劫。
- `realmPath.sequence`、`goals`、`risk`、`digest.nextStep`、拒绝句、见闻和生平用中文，不写行动标识。行动标识只留在 `recommendedAction` 和行动列表。
- 材料不齐时拒绝，袋子里的东西不动。拿错这一阶的特殊材料，同样过不去。
- 大圆满和化神的兵器、功法门槛不变。句子里仍指向婴火莲池、神纹天隙和对应的贡献档，给后面的秘境和兵器留地点。

## Non-Goals

- 不改各阶材料的种类、数量、坊市是否可卖、地宫掉落层数。
- 不改进元婴、进化神的成功率、气血灵力涨幅、名声和贡献门槛。
- 不改结丹仪、婴火淬体、炼气筑基的洞府破境。
- 不新开兵器表，也不新开炼虚。
- 不强迫单人修士必须找同伴。同伴改变的是反噬，不是把这一阶锁死。

## User-Visible Behavior

元婴前期的 `realmPath.method` 是 `nascent-refine`，`methodName` 是炼婴。人在洞府里看不到这一阶的行动。到了宗门驻地或甲级门口，材料齐了，才能炼。做成以后见闻标题是「破境」，正文和生平是同一句中文。

元婴中期的 `method` 仍是 `soul-vigil`。在驻地提交炼婴会被拒绝，句子指向魂灯。

化神前期的安静摘要写铺神纹，不写「下一阶是化神」。化神中期的 `method` 是 `divine-vigil`，`methodName` 是守神台。驻地里铺神纹会被拒绝。

## Constraints

- 小突破仍然必成。反噬是伤，不是把进度打回六成。
- 身上有伤时，这些破境不做。
- 旧档的境界等级不用迁移。第十层读到的就是炼婴，第十四层读到的就是守神台。

## Acceptance Criteria

- 元婴前期在洞府提交炼婴会被拒绝。在宗门驻地或甲级门口可以做成，境界加一，养婴露被耗掉。一个人做成会挂伤，有人看着则不挂，见闻里有这个人的名字。句子里没有 `refine-nascent`。
- 只有固婴砂、没有养婴露时，炼婴被拒绝，两样东西都还在。
- 元婴中期的 `method` 是 `soul-vigil`。点灯不耗固婴砂，收口才耗。拿炼婴来做会被拒绝。
- 元婴后期的句子同时写到渡劫和迎天劫。成功进入化神的路径不变。
- 化神前期的安静摘要不含「下一阶是化神」，也不让人去迎天劫。
- 化神中期在荒野或甲级门口守神台可以做成，化神金章被耗掉。驻地里这个行动不出现。只有神胎露、没有化神金章时被拒绝，东西还在。一个人做成会挂伤。
- 化神后期仍没有下一阶。

## Open Questions

- 没有。化神后期之上这一轮仍不继续加境。
